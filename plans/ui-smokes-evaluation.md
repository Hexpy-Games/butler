## Root causes and changes

- **#389, fixture:** the fixture expected Full access while the real gateway's controls remained ask-first. Select Full access through the actual menu and check its accessible button name. Keep the product's safe initial default. Lexical text is entered through the real focused editor. Panel close geometry is sampled midway through the real CSS animation, with its duration budget still asserted; wall-clock sleeps could miss the whole animation on this host.
- **#390, DS bug:** the native range input has a 2px inline UA margin in addition to its 100% width. Slider clears only its inline margin. No clipping, size budget or overflow assertion was changed.
- **#390, readiness fixtures:** srcdoc DeviceFrame lifecycle does not reliably reach global network-idle. Wait for the visible viewer, loaded specimens/stylesheets and their fonts. The overflow audit still checks all 308 pages and waits for all 40 FoundationHeroMotion examples before measuring. Fresh WebGL pixels are sampled immediately after an actual draw; reading an already-discarded drawing buffer was not evidence of a failed wallpaper.
- **Deep-link anchor, product bug:** the viewer's 120ms timer could fire before its lazy examples and fonts settled. Resize/mount/font events now align the initial anchor until user interaction takes over. The existing anchor position assertion and 30s timeout are unchanged.
- **#391, fixture contract:** the authored shared SVG construction outlines and annotation paths draw through stroke-dashoffset. The old Color contract allowed only transform/opacity despite the timeline explicitly authoring these SVG tracks. Permit this property only on SVG nodes owned by `data-t` tracks, and fontWeight only on Typography's owned SVG text. Keep CSS-only, offscreen/hidden/reduced-motion, frame rate, long-task, layout and CPU assertions intact.
- **Additional DS bug:** AnimatedNumber's visible intermediate glyphs participated in the grid's intrinsic width despite the hidden endpoint sizers. Loaded font shapes made 111 wider than 128, causing a 2px width jump. Only the endpoint sizers now determine the grid width; all intermediate text remains visible, aligned at the same right edge. Settled MetricCard screenshots are byte-identical.
- **#418, Ledger slow work:** project-root resolution repeatedly read/canonicalized the same root inside one synchronous command. Scope its memoization to a project and a single command; migration/help/install retain their authority-changing behavior. Index mutation reuses the complete index just read under the mutation lock instead of scanning and reading it twice. Existing tests check changed source content and a changed BUTLER_DATA between operations. This is not a claim that the macOS-only full-check timeout was reproduced here.
- **Other app fixtures:** HMR opens the sidebar through its real toggle; the language smoke follows Welcome → Consent → AI selection with current Korean copy; caret coordinates are measured after collapse/reopen finishes. All original focus, IME, language persistence and HMR assertions remain.
- **Context-ring refresh, product bug:** the control subscribed to the complete context object, so an unchanged ratio still rerendered its ring on an unrelated refresh. The ring subscribes to ratio/existence; a separate connected usage child receives every full context update. Theme selection uses shallow equality. The existing live-refresh smoke still verifies the latest ratio and complete submitted draft, and passed 242 frames with zero height drift, zero unchanged-control rerenders and zero usage reads.
- **Send-flight expiry, product bug:** a RAF queued before the 64ms retarget deadline could arrive later and still read layout/compositor progress. Check expiry before these reads. The existing bounded-window unit contract now also asserts zero late layout reads. The three unchanged 80ms travel windows have zero Layout/Paint events after the fix, with 137px actual travel and no long tasks. The failing combined run had six Layout/Paint events; a focused captured trace had two. [Before](evidence/ui-smokes/send-flight-before.json), [after](evidence/ui-smokes/send-flight-fixed.json). A targeted CLI option preserves the full trace for diagnosis; the normal gate still runs every scenario.
- **#454, font fixture:** the English UI initially needs the Latin subset, so its initial load probe checks the locale's real glyphs. The subsequent CDP probes still require actual Latin and Korean Pretendard rendering and IBM Plex Mono code. Electron waits for the real composer rather than the bootstrap root.
