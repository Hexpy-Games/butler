# #26 r4 보정 계획

의도: 사용자 최신 5개 요청을 기준으로 기본 채널의 불변성과 실제 탐색 동작을 바로잡는다.
스펙: UI-SIDEBAR-INFORMATION-ARCHITECTURE r4 §3,6,14,21.
범위 밖: 모델 실행, 스마트 분류, 위임, watchdog 구조 수정.

1. 완료 — 기본 채널 보관/삭제 방지와 기존 보관 복구. API·권한 부수효과·재시작 및 메시지 보존 검사.
2. 완료 — 단일 스크롤 + 탐색 헤더 sticky, 모바일 세로 액션, 빈 설명 정렬, 페이드 복원, 즐겨찾기 제목 아래 8px. DS 슬롯 재사용.
3. 진행 중 — 실제 데스크톱/모바일 화면 검증과 스펙 대비 리뷰 완료. 빌드·커밋·main·운영 반영 진행.

설계 검토: 고유 ID만 판별하므로 같은 제목의 대화와 혼동하지 않는다. 보호는 저장 전뿐 아니라 권한 close 전에도 적용한다. 스크롤 소유자는 하나이며 sticky의 높이 측정만 필요하다. 조건별 수동 스크롤 전환 로직은 도입하지 않는다.
