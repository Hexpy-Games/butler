# PercentInputControl

## What is this component
A numeric percentage input paired with a progress preview.

## When to use this component
Use it for threshold, budget, and percentage settings.

## Where to use this component
Use it in settings and configuration forms.

## Why to use this component
It gives percentage values a visible preview while keeping value logic external.

## How to use this component
Pass a numeric value and change handler.

## Who can use this component
Settings containers.

## Best practice
Validate ranges in the caller and keep labels in `SettingsField`.

## Wrong use cases
Do not use it for read-only progress. Use `ProgressMeter`.

## Tags
settings, percent, input, progress
