# ProgressStepper

## What is this component
A flat, read-only progress step indicator.

## When to use this component
Use it for wizard or setup progress when the steps are not direct navigation.

## Where to use this component
Use it in setup, import, repair, and onboarding flows.

## Why to use this component
It avoids making progress state look like buttons, tabs, or pills.

## How to use this component
Pass ordered steps and the active index.

## Who can use this component
Any product surface that needs non-interactive step progress.

## Best practice
Keep labels short and put the active step content in the main panel.

## Wrong use cases
Do not use it for clickable navigation. Use Tabs or a navigation list instead.
