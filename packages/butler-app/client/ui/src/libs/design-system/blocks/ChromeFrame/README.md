# ChromeFrame

## What is this component
A responsive shell frame for app chrome previews.

## When to use this component
Use it to compose titlebar, sidebar, main, and inspector regions.

## Where to use this component
Use it in shell fixtures, visual QA, and layout previews.

## Why to use this component
It gives the design system a chrome-level layout primitive without app state.

## How to use this component
Pass region nodes and collapsed/open booleans.

## Who can use this component
Shell containers and DS fixtures.

## Best practice
Keep real resize behavior and app routing in product components.

## Wrong use cases
Do not use it for normal cards or panels. Use `SurfacePanel`.

## Tags
chrome, shell, layout, responsive
