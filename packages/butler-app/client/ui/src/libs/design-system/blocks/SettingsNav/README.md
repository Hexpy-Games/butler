# SettingsNav

## What is this component
A settings navigation block composed from navigation rows.

## When to use this component
Use it for settings category lists.

## Where to use this component
Use it in settings sidebars and mobile settings menus.

## Why to use this component
It keeps settings navigation aligned with sidebar navigation primitives.

## How to use this component
Map settings sections into `SettingsNavItem` objects.

## Who can use this component
Settings containers.

## Best practice
Keep active routing state outside the block.

## Wrong use cases
Do not use it for project/session lists. Use navigation blocks or `SessionRow`.

## Tags
settings, navigation, sidebar
