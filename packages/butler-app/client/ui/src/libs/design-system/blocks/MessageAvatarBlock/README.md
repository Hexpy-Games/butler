# MessageAvatarBlock

## What is this component
A role-aware avatar shell for conversation rows.

## When to use this component
Use it for assistant, user, or system message identity.

## Where to use this component
Use it in message lists, activity rows, and conversation previews.

## Why to use this component
It keeps avatar size, shape, and active state consistent while allowing custom marks.

## How to use this component
Pass a role and optional child icon or mark.

## Who can use this component
Conversation containers and reusable activity blocks.

## Best practice
Keep Butler-specific animated marks in the product layer and pass them as children.

## Wrong use cases
Do not use it for project or document thumbnails. Use `ResourceTile`.
