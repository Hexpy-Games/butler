# DashboardHeader

## What is this component
A responsive heading block for dashboard pages.

## When to use this component
Use it for project, automation, and management dashboards.

## Where to use this component
Use it at the top of dashboard main content.

## Why to use this component
It keeps large product headings and primary actions consistent.

## How to use this component
Pass title, optional description, meta, and action.

## Who can use this component
Dashboard containers and management views.

## Best practice
Keep action count to one primary command.

## Wrong use cases
Do not use it for settings pages. Use `SettingsHeader`.

## Tags
dashboard, header, management
