# ActivityFeed

## What is this component
A compact list for activity or status events.

## When to use this component
Use it when timeline entries share one small row pattern.

## Where to use this component
Use it in inspectors, turn activity panels, dashboards, and worker summaries.

## Why to use this component
It gives activity rows consistent spacing, hover affordance, and metadata layout.

## How to use this component
Pass preformatted title, description, meta, and icon nodes.

## Who can use this component
Domain containers that already own activity data.

## Best practice
Keep time formatting and event labels outside the block.

## Wrong use cases
Do not use it for navigation. Use `NavRow` or `SessionRow`.

## Tags
activity, feed, status, inspector
