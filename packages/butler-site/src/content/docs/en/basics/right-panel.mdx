On the right of a conversation's title bar are the **Session info** and **View files** buttons. **Session info** collects the conversation's requests, subtasks, results and schedules beside the conversation. **View files** opens results and attached files beside the conversation.

## Open and close session info

<Steps>
  1. Open a conversation from the sidebar.
  2. Click the **Session info** button on the right of the title bar.
  3. To close it, click the same button again.
</Steps>

- The **Session info** button appears only when there is at least one section to show.
- When a request is waiting for your answer, or a subtask is waiting for approval, the button shows a dot.

## Session info sections

Sections appear in this order, and only when they have content. A section with nothing to show is hidden.

### Awaiting your answer

Shows the approval requests and questions you have not answered yet, with a count. Each row shows **Approval** or **Question** and how long it has waited. A request you put off is marked **Deferred**. Click a row to go to the message with the request.

### Subtasks

Shows the unfinished subtasks Butler handed off, with their state. Click a row to open that subtask's progress details.

### Run order

When Butler works through Epics in order, shows the order that remains.

### Browser

Shows previews of the browser tabs Butler opened in this conversation. With more than three tabs, expand them with **Show N more tabs** and collapse them with **Show less**.

### Environment

Shows the **Working folder** and Git **Branch** this conversation uses.

### Epic

Shows the details of the Epic this conversation works on. You can edit them right here.

### Context

Shows how much of the context sent to the model is in use. Click it to expand a bar chart, the usage of each group (**Conversation**, **Memory & files**, **Rules & settings**, **Basics**, **Reserved**) and the point where automatic compaction happens. Click **Details** to see the items in each group, and **Less** to collapse them again.

### Results

Shows the files Butler delivered in this conversation, with a count. Click a file to open it in the [file viewer](#view-files). To save it as a file, click **Save**.

### Attachments

Shows the files you attached to your messages. Click a file to open it in the file viewer.

### Schedules

Lists the [schedules](/en/help/scheduled-tasks/) that target this conversation. Each item shows its title and frequency. Click an item to open the schedule's detail screen.

## View files

Results, attached files and changed files open in the file viewer on the right of the conversation.

- A file opens when you click a result in a reply, a file under **Results** or **Attachments** in **Session info**, or **Open** in a changed file's menu.
- A document Butler makes in the Library is editable: click the text and type. It saves as you go; **Versions** shows earlier versions and restores one.
- A file Butler saves to a folder is view-only. To edit it, click **Open in default app**.
- Each file gets a tab. With two or more files, tabs appear at the top. Close a tab with its **Close file** button.
- The **View files** button in the title bar appears while files are open. Click it to hide or show the file viewer without closing the files.
- The browser and the file viewer share the same place. The one you opened last is in front.
- Drag the edge between the conversation and the file viewer to change the conversation's width.
- On a narrow screen such as a phone, the file viewer fills the screen. Click **Back to chat** to return to the conversation.

### File viewer buttons

These buttons appear above the file.

- **Version** — Chooses which version to view, for a file with several versions.
- **Open in Library** — Appears only for files Butler delivered. Finds this file under **Documents** in the [Library](/en/help/basics/library/).
- **Save** — Saves the file to your computer. In the desktop app, a save dialog opens.
- **Open in default app** — Appears only in the desktop app. Opens the file in your computer's default app for its type.
- **Show in folder** — Appears instead of **Open in default app** for types that cannot open in the default app. Opens the folder that holds the file.
- **Close** — Closes the file you are viewing.

**Open in default app** works for PDF, Word (`docx`), Excel (`xlsx`), PowerPoint (`pptx`), Hangul (`hwp`, `hwpx`), images (`png`, `jpg`, `jpeg`, `gif`, `webp`), Markdown (`md`, `markdown`), `txt` and `csv`.

The latest version of a file Butler delivered opens from the original place where Butler saved it. Edits you make in the other app stay in that file. An older version, or a file whose original is gone, opens as a stored copy. If **Show in folder** cannot find the original file, the **Original not found** notice appears.

Web pages Butler made have these extra buttons.

- **Open in Browser** — Opens the page in the browser as this conversation's tab.
- **Reload** — Loads the page again.

### Formats you can preview

| Format | Shown as |
| --- | --- |
| Images (`png`, `jpg`, `jpeg`, `webp`, `gif`, `svg`) | Image |
| PDF | Document view |
| Markdown (`md`) | Formatted document |
| Text and code files | Text |
| HTML pages Butler made | The running page |
| HTML files you attached | Source text |

Other formats show **This artifact cannot be previewed in the app**. In the desktop app, an **Open in app** button appears with it. For a type that cannot open in another app, the button is disabled with the tooltip **This type can't open**. Save such a file with **Save** to open it.

## Notes

<Notice tone="info">
  **Session info** is available only on a conversation screen. The button does not appear on the project dashboard, schedules or Settings screens. It also does not appear while the file viewer fills a narrow screen.
</Notice>

<Notice tone="info">
  HTML pages Butler made run on the output host. If no host is set, **Set an output host in Security settings.** appears.
</Notice>
