A project is a set of conversations that share a work folder. As Butler works in project conversations, it keeps Work, plans, Tasks, specifications and reports as project records, and the project dashboard gathers these records in one view. On the dashboard's **Board**, you create and manage the project's tasks and plans.

## Create a project

<Steps>
  1. In the sidebar, open the **Space menu** next to the **Space** heading and choose **New project**.
  2. In the **Create a project** dialog, enter a **Project name**.
  3. Click **Create**. The project is added to the space and a new project conversation opens.
</Steps>

The project folder is created under the **Default project folder** in **Settings → Server**, with the project name as its name. If a folder with that name already exists, a number is added after the name.

## Start a project conversation

- From the project row's menu in the sidebar, choose **New chat**.
- Click **New chat** next to the project dashboard title.
- Send a message from the composer at the bottom of the project dashboard. The message starts a new project conversation.

In a project that is a Git repository, you can choose **Local** or **Worktree** in the composer before you send the first message. If the project is not a Git repository, this choice does not appear. See [Workspace](/en/help/basics/conversation/#workspace).

Click a project row in the sidebar to expand or collapse its list of conversations. To move an existing conversation into a project, see [Sidebar and spaces](/en/help/basics/sidebar-and-spaces/#move-and-reorder-items).

## Open the dashboard

Open it in one of these ways.

- Click the **Project dashboard** icon button on the project row in the sidebar.
- From the project row's menu, choose **Project dashboard**.
- Click a project pinned to favorites.

The top of the dashboard shows the project name and description, with the **Overview**, **Board**, **Materials**, **History** and **Statistics** tabs below. The dashboard refreshes automatically while it is open.

### Project description

Click the **Edit description** button next to the description, write the project description yourself and click **Save**. For a project without a description, Butler fills one in when it creates the first summary.

## Overview

- **Project status** — Shows the current state, which Butler summarizes from a selection of the project records. Expand **View N source records** to open the documents the summary used. If the summary cannot be created, click **Try again**.
- **Execution completed**, **Open work**, **Blocked work** — Show the number of work items registered in the project records.
- **Remaining work** — Shows up to four unfinished Work items as cards. Click a card to open its document. Click the button below to go to the **Board** tab.
- **Important materials** — Shows pinned materials, and the plans, specifications and latest reports linked to remaining work.
- **Worth exploring next** — Shows up to three next questions that Butler suggests. Click **Ask about this** to put the suggestion and its source documents into the dashboard composer.

## Board

The **Board** tab shows the project's Epics by plan. An Epic is one piece of work to handle with Butler, and a plan groups Epics. Epics that are not in a plan collect in **Backlog**.

- Plan selector — Choose the plan to view, or **Backlog**. Enter a name in **Search plans** to find one.
- **Tag filter** — Shows only Epics with the tags you choose.
- **New Epic**, **New Plan** — Create an Epic or a plan.

Next to the plan name, the number of finished Epics appears, such as `3/8 done`, and the due date appears too if the plan has one, such as `Due Nov 20`. Edit a plan with the pencil **Edit** button.

The columns are, in order, **Planned**, **In progress**, **In review**, **Blocked** and **Done**. A cancelled Epic sits in the **Done** column with a **Cancelled** tag. When the columns do not fit on screen, move with the **Previous lanes** and **Next lanes** buttons.

A card shows the title, the assignee, the criteria confirmed such as `2/4 confirmed`, up to three tags, and the order and task progress such as `No. 1 · Tasks 2/3`.

- Drag a card to another column to change the Epic's status. With the keyboard, press <Kbd keys={["Space"]} /> to pick it up, move it with the arrow keys, press <Kbd keys={["Space"]} /> to drop it, and press <Kbd keys={["Esc"]} label="Escape" /> to cancel.
- An Epic whose work is in progress cannot move to **Done**.
- Click a card to open the Epic detail pane.

### Create Epics and plans

<Steps>
  1. On the **Board** tab, click **New Epic**. You can also click the **New Epic** button in the **Planned** column.
  2. Enter a **Title**. If you need to, set the **Description**, **Tags**, **Plan** and **Assignee**.
  3. Click **Create**.
</Steps>

To create a plan, click **New Plan**, enter the **Title**, **Description** and **Due date**, then click **Create**.

### Epic details

Edit an Epic in the Epic detail pane.

- Title and description — Click to edit them in place. The description supports Markdown and attachments. Attachments can be up to 10 MB each, up to 20 files.
- **Status**, **Assignee**, **Plan**, **Tags** — Changes save right away.
- **Open conversation** — Goes to this Epic's conversation.
- **Specs** — Shows the Epic's specs and criteria. You can mark each criterion as confirmed or not.

Choose **Delete Epic** from the menu (⋯) at the top of the pane and confirm to delete the Epic from this device. Linked conversations stay. An Epic whose work is in progress cannot be deleted.

### Plan overview

In the sidebar, expand the project and choose **Plan overview** from a plan group's menu (⋯) to open a screen for that plan. It shows the plan title, due date, description, progress and the list of Epics.

- Change each Epic's status, and choose **Open conversation**, **Change Plan** or **Delete Epic** from its menu (⋯).
- Click **Edit plan** to edit the plan, or **New Epic** to add an Epic to this plan.

### Work with Epics in a conversation

- In an Epic's conversation, you talk about that Epic. The composer shows **Talk about this Epic**, and you can edit the Epic right away in **Epic** under [**Session info**](/en/help/basics/right-panel/).
- When you ask Butler in a conversation to create or change Epics, it shows a proposal card. The card shows where the Epics go and what they contain. Click **Cancel** to leave things as they are. To create, click **Add**. To change or delete, click **Apply** or **Delete Epic**. An applied card turns into a summary of the result. Click **Open** or an Epic card to open that Epic on the board.
- When you ask Butler to work through a plan's Epics in order, it handles them one at a time. The progress appears in **Run order** under **Session info**. Drag to change the order, or choose **Start now**, **Unstack** or **Delete** from the menu.
- If an earlier Epic is blocked, the next ones wait, and a card with **Delete** and **Continue anyway** appears in the conversation. If another conversation owns the Epic, choose **Open that conversation** or **Do it here**.

## Materials

- **Important materials** — Shows pinned documents.
- **Project documents** — Shows the other specifications, plans, reports and similar documents in the project records. Each document shows its type and the date it was last changed.
- **Published results** — Shows result files delivered in project conversations. Each file shows which conversation it came from and the date.

Use the **Pin material** button on a document or result row to pin it to **Important materials**, and **Unpin material** to remove it. Click the **Ask about this** button on a result row to attach that file to the dashboard composer.

## History

Shows what happened in the project records and conversations as a timeline by date. Each entry shows its time and kind (**Created**, **Updated**, **Completion recorded**, **Review recorded**, **Disposition recorded**, **Tool result registered**, **Published reply**). Click an entry to open its document, or click the linked conversation name to go to that conversation.

## Statistics

At the top, choose the period: **Last 7 days**, **Last 30 days** or **Last 90 days**. The default is **Last 30 days**, and dates use this device's time zone.

- **Work overview** — Choose **Work** or **Task** to view.
  - **How work changed** — Shows the work registered and the work recorded as completed during the period.
  - **Where work remains** — Shows the number of items in each stage of the current board: planned, in progress, in review and blocked. Click a stage to list its items.
  - **Work to revisit** — Shows up to five items that have gone a long time since their last update. Blocked items come first.
- **Project activity** — Shows the amount of activity by date. Click a date to list that day's records.
- **Where activity went** — Lists items in order of most changes.
- **Materials and results** — Shows documents registered or changed and attachments delivered. Switch between **By type** and **Changes**.
- **Butler request outcomes**, **Request elapsed time** — Show the outcomes of requests that finished in project conversations and how long they took.
- **Model usage** — This screen does not total tokens or cost per project. Check usage in [**Usage**](/en/help/settings/#usage) in Settings.

## View a document

Click a document or a card on **Overview** to open a read-only document window.

- The top of the document window shows **Document type**, **Document status**, **Last updated** and **Source location**.
- Expand **Source details** to see identifying information such as the ID and revision.
- Click **Reference in conversation** to add the document to the dashboard composer as a reference. If the composer is empty, a default question is filled in with it.
- For a long document, click **Show more** at the end to load the rest.

## Manage a project

From the project row's menu in the sidebar, you can do the following.

- **Rename** — Enter a new name in the **Rename project** dialog and click **Save**.
- **Pin** / **Unpin** — Pins the project to **Favorites** in the sidebar, or unpins it.
- **Archive** — Hides the project and its conversations from the list. Restore it from **Archives** in Settings.
- **Delete project** — Click **Delete** in the confirmation dialog to permanently delete the project from Butler.

## Notes

<Notice tone="warning">
  **Delete project** cannot be undone. Deleting a project does not delete the local project folder.
</Notice>

<Notice tone="info">
  You cannot edit the Work and documents in the project records on the dashboard. Create and edit Epics and plans on the **Board**. **Project status** and **Worth exploring next** are model summaries of selected records, and are not newly verified results. Creating a summary counts toward model usage.
</Notice>
