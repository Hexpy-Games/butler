## Supported platforms

Butler is in preview. Always download the newest preview from [GitHub Releases](https://github.com/Hexpy-Games/butler/releases) (the newest preview is at the top). The stable 0.1.0 release is still to come.

- Apple silicon (M-series) Mac, macOS 12 or later
- Linux x64 / arm64: DEB package
- Arch Linux x64: Arch package
- Windows x64: installer (`ButlerSetup`)

<Notice tone="info">
  The apps include Butler Agent, which runs while the app is open.
</Notice>

## Download

<Tabs
  label="Operating system"
  items={[
    { value: "macos", label: "macOS" },
    { value: "windows", label: "Windows" },
    { value: "linux", label: "Linux" },
  ]}
>
  <TabPanel value="macos">
    <Steps>
      1. Open the newest preview (at the top) on [GitHub Releases](https://github.com/Hexpy-Games/butler/releases) and expand **Assets**.
      2. Download the macOS DMG (`butler-app-<version>-darwin-arm64.dmg`).
      3. Open the DMG and drag `Butler.app` into the Applications folder.
      4. Open Butler. Butler is notarized by Apple. If macOS asks whether to open an app downloaded from the internet, choose **Open**.
    </Steps>
    <Notice tone="info" title="Verify the download (optional)">
      Download the DMG and its `.sha256` file into the same folder, then run `shasum -a 256 -c butler-app-*-darwin-arm64.dmg.sha256`. `OK` means the file matches the release.
    </Notice>
  </TabPanel>
  <TabPanel value="windows">
    <Steps>
      1. Open the newest preview (at the top) on [GitHub Releases](https://github.com/Hexpy-Games/butler/releases) and expand **Assets**.
      2. Download the Windows installer (`ButlerSetup-<version>-x64.exe`).
      3. Run it. If Windows SmartScreen shows "Windows protected your PC", choose **More info**, then **Run anyway**. Preview installers are not signed yet.
      4. Open Butler from the Start menu.
    </Steps>
  </TabPanel>
  <TabPanel value="linux">
    <Steps>
      1. On the newest preview on [GitHub Releases](https://github.com/Hexpy-Games/butler/releases), download the DEB (x64 or arm64) or Arch (x64) package from **Assets**.
      2. In the download folder, install it with the command for your distribution.
      3. Open Butler from your app list.
    </Steps>

    ```bash
    # Debian / Ubuntu (x64; change the file name for arm64)
    sudo apt install ./butler-app-<version>-linux-x64.deb
    # Arch Linux (x64)
    sudo pacman -U ./butler-app-<version>-archlinux-x64.pkg.tar.zst
    ```
  </TabPanel>
</Tabs>

<Notice tone="warning">
  Earlier releases may contain the TypeScript/Bun Agent, which is no longer used. Download a release that includes the native Agent.
</Notice>

Preview builds turn on **Receive preview versions** by default, so later previews arrive in **Settings → Updates**. Before you update, quit Butler and copy `~/.butler`. The first launch of a new version can rewrite the database. Run `butler --version` to see the exact version.

## First-run setup

The first time you run Butler, first-run setup starts in the app. On the welcome screen, choose the interface language, agree, then connect an AI. In the last step of the AI connection, choose the response language. For each step, see [First run](/en/help/getting-started/first-run/).

After setup, press <span data-mod-key><Kbd keys={["⌘", "K"]} label="Command K" /></span> to open the [command palette](/en/help/basics/command-palette/) and find conversations, projects, schedules and settings.

## Use the Agent without the app

<Tabs
  label="Operating system"
  items={[
    { value: "macos", label: "macOS" },
    { value: "windows", label: "Windows" },
    { value: "linux", label: "Linux" },
  ]}
>
  <TabPanel value="macos">
    The headless Agent supports Apple silicon macOS. Replace `<version>` with the newest preview, such as `0.1.0-preview.12`.

    ```bash
    curl -fsSL https://github.com/Hexpy-Games/butler/releases/download/v<version>/install.sh | sh -s -- --version <version>
    ```
  </TabPanel>
  <TabPanel value="windows">
    The headless Agent supports Windows x64. In PowerShell, replace `<version>` with the newest preview, such as `0.1.0-preview.12`.

    ```powershell
    $env:BUTLER_VERSION='<version>'; irm https://github.com/Hexpy-Games/butler/releases/download/v<version>/install.ps1 | iex
    ```
  </TabPanel>
  <TabPanel value="linux">
    The headless Agent supports glibc-based Linux x64 / arm64.

    ```bash
    curl -fsSL https://github.com/Hexpy-Games/butler/releases/download/v<version>/install.sh | sh -s -- --version <version>
    ```
  </TabPanel>
</Tabs>

For the management commands, see [Butler Agent CLI](/en/help/advanced/agent-cli/).
