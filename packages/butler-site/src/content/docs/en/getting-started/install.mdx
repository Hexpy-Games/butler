## Supported platforms

The current version is `0.1.0-preview.5`, a preview. The stable 0.1.0 release is still to come.

- Apple silicon (M-series) Mac, macOS 12 or later
- Linux x64 / arm64: DEB package
- Arch Linux x64: Arch package
- Windows x64 source preview: no downloadable installer in this release

<Notice tone="info">
  The macOS and Linux apps include Butler Agent, which runs while the app is open. Windows has a source preview, but this release has no downloadable installer.
</Notice>

## Download

  label="Operating system"
  items={[
    { value: "macos", label: "macOS" },
    { value: "windows", label: "Windows" },
    { value: "linux", label: "Linux" },
  ]}
>
  <TabPanel value="macos">
    <Steps>
      1. Open the [0.1.0 preview.5 release](https://github.com/Hexpy-Games/butler/releases/tag/v0.1.0-preview.5).
      2. Download the [macOS DMG](https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.5/butler-app-0.1.0-preview.5-darwin-arm64.dmg).
      3. Open the DMG and drag `Butler.app` into the Applications folder.
      4. On first open, if Gatekeeper blocks Butler, right-click it and choose **Open**. If it still does not open, choose **Open Anyway** in **System Settings → Privacy & Security**.
    </Steps>
    <Notice tone="info" title="Verify the download (optional)">
      Download the DMG and its `.sha256` file into the same folder, then run `shasum -a 256 -c butler-app-*-darwin-arm64.dmg.sha256`. `OK` means the file matches the release.
    </Notice>
  </TabPanel>
  <TabPanel value="windows">
    <Notice tone="info" title="Source preview">
      The published `0.1.0-preview.5` release has no downloadable Windows installer. Check [GitHub Releases](https://github.com/Hexpy-Games/butler/releases) for a later Windows package.
    </Notice>
  </TabPanel>
  <TabPanel value="linux">
    <Steps>
      1. Download the [DEB x64](https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.5/butler-app-0.1.0-preview.5-linux-x64.deb), [DEB arm64](https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.5/butler-app-0.1.0-preview.5-linux-arm64.deb) or [Arch x64](https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.5/butler-app-0.1.0-preview.5-archlinux-x64.pkg.tar.zst) package.
      2. In the download folder, install it with the command for your distribution.
      3. Open Butler from your app list.
    </Steps>

    ```bash
    # Debian / Ubuntu (x64; change the file name for arm64)
    sudo apt install ./butler-app-0.1.0-preview.5-linux-x64.deb
    # Arch Linux (x64)
    sudo pacman -U ./butler-app-0.1.0-preview.5-archlinux-x64.pkg.tar.zst
    ```
  </TabPanel>
</Tabs>

<Notice tone="warning">
  Earlier releases may contain the TypeScript/Bun Agent, which is no longer used. Download a release that includes the native Agent.
</Notice>

After you install the `0.1.0-preview.5` app, turn on **Receive preview versions** to get later previews from **Settings → Updates**. Run `butler --version` to see the exact version.

## First-run setup

The first time you run Butler, first-run setup starts in the app. On the welcome screen, choose the interface language, agree, then connect an AI. In the last step of the AI connection, choose the response language. For each step, see [First run](/en/help/getting-started/first-run/).

After setup, press <span data-mod-key><Kbd keys={["⌘", "K"]} label="Command K" /></span> to open the [command palette](/en/help/basics/command-palette/) and find conversations, projects, schedules and settings.

## Use the Agent without the app

<Tabs
  label="Operating system"
  items={[
    { value: "macos", label: "macOS" },
    { value: "windows", label: "Windows" },
    { value: "linux", label: "Linux" },
  ]}
>
  <TabPanel value="macos">
    The headless Agent supports Apple silicon macOS.

    ```bash
    curl -fsSL https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.5/install.sh | sh -s -- --version 0.1.0-preview.5
    # With Node.js
    npx @hexpygames/butler install
    ```
  </TabPanel>
  <TabPanel value="windows">
    The published release has no downloadable Windows Agent installer. Windows builds are in source preview.
  </TabPanel>
  <TabPanel value="linux">
    The headless Agent supports glibc-based Linux x64 / arm64.

    ```bash
    curl -fsSL https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.5/install.sh | sh -s -- --version 0.1.0-preview.5
    # With Node.js
    npx @hexpygames/butler install
    ```
  </TabPanel>
</Tabs>

For the management commands, see [Butler Agent CLI](/en/help/advanced/agent-cli/).
