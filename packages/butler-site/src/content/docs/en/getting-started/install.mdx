Current version: `0.1.0-preview.4`, a preview; stable 0.1.0 is coming.

## Supported platforms

- Apple silicon Mac, macOS 12 or later
- Linux x64 / arm64: DEB packages
- Arch Linux x64: Arch package
- Windows x64 preview: unsigned Agent and browser UI

The App includes the native Butler Agent. Its bundled Agent runs while the App is open. Windows previews ship the Agent with a browser UI.

## Download

Use the [0.1.0 preview.4 release](https://github.com/Hexpy-Games/butler/releases/tag/v0.1.0-preview.4).

### macOS

1. Download the [macOS DMG](https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.4/butler-app-0.1.0-preview.4-darwin-arm64.dmg).
2. Open the DMG and drag `Butler.app` into Applications.

### Linux

Download the [DEB x64](https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.4/butler-app-0.1.0-preview.4-linux-x64.deb), [DEB arm64](https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.4/butler-app-0.1.0-preview.4-linux-arm64.deb), or [Arch x64 package](https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.4/butler-app-0.1.0-preview.4-archlinux-x64.pkg.tar.zst).

From the download folder, install the package for your distribution:

```bash
# Debian / Ubuntu (x64; substitute the arm64 filename when needed)
sudo apt install ./butler-app-0.1.0-preview.4-linux-x64.deb
# Arch Linux (x64)
sudo pacman -U ./butler-app-0.1.0-preview.4-archlinux-x64.pkg.tar.zst
```

Open Butler from your application menu.

### Verify the download (optional)

Each release file has a SHA-256 checksum (`.sha256`). Download both files into the same folder, then verify the DMG:

```bash
cd ~/Downloads
shasum -a 256 -c butler-app-0.1.0-preview.4-darwin-arm64.dmg.sha256
```

`OK` means the download matches the published file. On Linux, use `sha256sum -c` with the package's checksum file.

## First open on macOS

Preview builds are signed but not notarized by Apple. Gatekeeper shows a prompt on first open.

1. In Applications, right-click Butler and choose **Open**.
2. If it is still blocked, choose **System Settings → Privacy & Security → Open Anyway** after trying to open it.

## First-run setup

Choose the interface language on the welcome screen, accept the safety notice, and connect an AI. Choose Butler's reply language at the end of the AI connection step. You can change it later in **Settings → Personalization**.

## Headless Agent

The headless Agent supports Apple silicon macOS and Linux x64 / arm64 with glibc.

```bash
curl -fsSL https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.4/install.sh | sh -s -- --version 0.1.0-preview.4
# Or, with Node.js:
npx @hexpygames/butler install
```

See the [Agent CLI guide](/en/help/advanced/agent-cli/) for service management.

## Windows x64 Agent preview

Windows previews are unsigned and agent-only. Use the Windows ZIP and `install.ps1` from the same preview release that lists `windows-x64` in its Agent manifest. In PowerShell, replace `0.1.0-preview.N` with that release version:

```powershell
$env:BUTLER_VERSION = '0.1.0-preview.N'; irm "https://github.com/Hexpy-Games/butler/releases/download/v$env:BUTLER_VERSION/install.ps1" | iex
butler open
```

The installer verifies SHA-256 checksums, installs under `%LOCALAPPDATA%\Butler`, adds `butler` to your user PATH, and starts the Agent. Open a new terminal if `butler` is not found. The UI runs in your browser. Use `butler start`, `stop`, `restart`, and `status` to manage the background process.

- No autostart; run `butler start` after signing in.
- No LAN remote access.
- No command write sandbox; commands still require approval.
- SmartScreen may warn about the unsigned preview. Choose **More info → Run anyway**.
