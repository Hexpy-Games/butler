## Supported platforms

Butler is in preview. The links below download the newest version. Earlier versions and all release files are on [GitHub Releases](https://github.com/Hexpy-Games/butler/releases). The stable 0.1.0 release is still to come.

- Apple silicon (M-series) Mac, macOS 13 or later
- Linux x64 / arm64: DEB package
- Arch Linux x64: Arch package
- Windows x64: installer (`ButlerSetup`)

<Notice tone="info">
  The apps include Butler Agent, which runs while the app is open.
</Notice>

## Download

  label="Operating system"
  items={[
    { value: "macos", label: "macOS" },

>
  <TabPanel value="macos">
    <Steps>
      1. Download <DownloadLink file="macos" />.
      2. Open the DMG and drag `Butler.app` into the Applications folder.
      3. Open Butler. If macOS asks whether to open an app downloaded from the internet, choose **Open**.
    </Steps>
    <Notice tone="info" title="Verify the download (optional)">
      Download <DownloadLink file="macos" checksum /> into the same folder, then run `shasum -a 256 -c butler-app-*-darwin-arm64.dmg.sha256`. `OK` means the file matches the release.
    </Notice>
  </TabPanel>
  <TabPanel value="windows">
    <Steps>
      1. Download <DownloadLink file="windows" />.
      2. Run it. If Windows SmartScreen shows "Windows protected your PC", choose **More info**, then **Run anyway**. Preview installers are not signed yet.
      3. Open Butler from the Start menu.
    </Steps>
  </TabPanel>
  <TabPanel value="linux">
    <Steps>
      1. Download the package for your distribution.
         - Debian / Ubuntu x64: <DownloadLink file="deb-x64" />
         - Debian / Ubuntu arm64: <DownloadLink file="deb-arm64" />
         - Arch Linux x64: <DownloadLink file="arch-x64" />
      2. In the download folder, install it with the command for your distribution.
      3. Open Butler from your app list.
    </Steps>

    ```bash
    # Debian / Ubuntu (x64; change the file name for arm64)
    sudo apt install ./butler-app-<version>-linux-x64.deb
    # Arch Linux (x64)
    sudo pacman -U ./butler-app-<version>-archlinux-x64.pkg.tar.zst
    ```
  </TabPanel>
</Tabs>

<Notice tone="warning">
  Earlier releases may contain the TypeScript/Bun Agent, which is no longer used. Download a release that includes the native Agent.
</Notice>

Preview builds turn on **Receive preview versions** by default, so later previews arrive in **Settings → Updates**. The app updates itself on macOS, on Windows and from the Linux DEB package. On Windows, only an installation from the installer (`ButlerSetup`) updates in the app. For the portable zip (`butler-app-<version>-windows-x64-portable.zip`), download the new version yourself. To update the Arch package, download the new package and install it yourself. Before you update, quit Butler and copy `~/.butler`. The first launch of a new version can rewrite the database. Run `butler --version` to see the exact version.

## First-run setup

The first time you run Butler, first-run setup starts in the app. On the welcome screen, choose the interface language and agree. Then choose how Butler remembers and connect an AI. In the last step of the AI connection, choose the response language. For each step, see [First run](/en/help/getting-started/first-run/).

After setup, press <span data-mod-key><Kbd keys={["⌘", "K"]} label="Command K" /></span> to open the [command palette](/en/help/basics/command-palette/) and find conversations, projects, schedules and settings.

## Use the Agent without the app

<Tabs
  label="Operating system"
  items={[
    { value: "macos", label: "macOS" },
    { value: "windows", label: "Windows" },
    { value: "linux", label: "Linux" },
  ]}
>
  <TabPanel value="macos">
    The headless Agent supports Apple silicon macOS. Replace `<version>` with the newest preview, such as `0.1.0-preview.14`.

    ```bash
    curl -fsSL https://github.com/Hexpy-Games/butler/releases/download/v<version>/install.sh | sh -s -- --version <version>
    ```
  </TabPanel>
  <TabPanel value="windows">
    The headless Agent supports Windows x64. In PowerShell, replace `<version>` with the newest preview, such as `0.1.0-preview.14`.

    ```powershell
    $env:BUTLER_VERSION='<version>'; irm https://github.com/Hexpy-Games/butler/releases/download/v<version>/install.ps1 | iex
    ```
  </TabPanel>
  <TabPanel value="linux">
    The headless Agent supports glibc-based Linux x64 / arm64.

    ```bash
    curl -fsSL https://github.com/Hexpy-Games/butler/releases/download/v<version>/install.sh | sh -s -- --version <version>
    ```
  </TabPanel>
</Tabs>

For the management commands, see [Butler Agent CLI](/en/help/advanced/agent-cli/).
