Personalization sets Butler's name and tone, the response language, and how much Butler gets to know you from conversations. Change it in **Settings → Personalization**.

## Change the settings

<Steps>
  1. In the sidebar, open **Settings** and select **Personalization**.
  2. Change the items in the **Profile**, **Response style** and **Profile building** sections.
  3. Click **Apply** at the bottom of the screen.
</Steps>

Personalization settings are saved only when you click **Apply**.

## Profile

- **Butler nickname** — Butler's name. Example: Butler, Alfred
- **My name** — Your name.
- **Preferred address** — What Butler calls you. Example: boss, captain

## Response style

- **Response language** — The language Butler uses in chat for final answers and progress updates. Choose **English** or **Korean**.
- **Persona preset** — Choose Butler, Guardian, Demon Butler, Wolf Butler, Neko Servant, Think Tank, Operator, Archivist or Dry Wit. Choosing a preset changes only the **Persona** draft below, and nothing is saved until you click **Apply**.
- **Persona** — How Butler expresses itself and collaborates with you. If you edit the text yourself, the preset changes to **Custom**.
- **EOL** — Butler Operating Ethos. Write long-term preferences, boundaries and operating notes that should last. It is included in the settings Butler refers to when it answers.

Persona and EOL are each saved up to 32,000 characters.

## Profile building

**Level** sets how much Butler gets to know you from local conversations. The default is **Off**.

- **Off** — Butler doesn't build a profile. It uses only the settings it needs to work.
- **Basic** — Butler uses your preferences for tone, explanation style and way of working in personalized replies.
- **Deep** — Butler also uses recent interests, meaningful context and value judgments in personalized replies.

If you choose **Basic** or **Deep** and click **Apply**, Butler records that you consented to profile building.

- **Profile-building model** — The model that extracts the information personalization needs. If you choose **Model default**, it follows the current Butler default model settings. To register a model, see [Cloud models](/en/help/models/cloud/).
- **Reasoning** — The reasoning effort of the profile-building model.
- **Memory** — Click **Manage** to open **Settings → Memory**.

To see when and how profile building finished, check the **Profile building** entries in [**Settings → System events**](/en/help/settings/#system-events).

## Conversation memory

On a fresh installation, you can ask Butler to remember something and ask about it later. Explicit requests to remember information are saved even when profile building is off. Profile building has its own consent setting, separate from conversation memory.

Manage what Butler remembers, by kind, in [**Settings → Memory**](/en/help/settings/#memory).

- **Instructions** — Rules you set in chat. Add and change them in chat, and delete them one by one on this screen. Each applies to **All chats**, a project or **This chat only**. If one has a time limit, it shows as `Expires in 3 hours`.
- **What Butler noticed** — Habits Butler noticed in your conversations. Delete one and Butler won't suggest it again.
- **Reach out first** — How readily Butler suggests things after memory consolidation. Choose **Off**, **Sometimes** or **Often**.
- **Quiet hours** — Butler won't reach out during these hours.
- **Chat memory** — What Butler picked up from your conversations on its own, including project conversations.
- **Memory consolidation** — Settings for merging and tidying the memories collected from conversations.
- **Profile** — What Butler knows about you from profile building. It shows the number of entries and candidates.
- **Project memory** — What Butler remembers about one project.

Conversation records remain as sources, and memory consolidation runs in the background. Memory search can take longer to become ready while the memory model downloads. Check preparation in **Memory model** under **Settings → Memory**. Ask for the source of an older decision and check whether it still applies.

## Import memory

Move the memories another AI service has stored into your Butler profile.

<Steps>
  1. Set **Level** to **Basic** or **Deep** and click **Apply**.
  2. In the **Import from other AI tools** section, click **Import** for **Import memory**.
  3. Click **Copy prompt** under **Import prompt**, then send the copied prompt to the other AI service.
  4. Paste what that service returns into **Imported profile content**.
  5. Click **Import profile**. The import runs on this screen right away and the result appears.
</Steps>

- If any information was applied, the number of applied items appears, and Butler uses them from the next reply.
- Information that is not certain yet is only stored. Butler applies it once it is certain enough.
- The import prompt appears in the app's language.

## What Butler stores

Personalization data is stored in the data folder (`~/.butler` by default).

- Profile: `~/.butler/personalization/profile.json`
- Persona: `~/.butler/personas/active.md`
- EOL: `~/.butler/eol.md`
- Personal information Butler learned: `~/.butler/cognition/profile/profile.sqlite`

Personal information accumulates only when profile building is on.

When you change the persona or the EOL, the previous text is backed up to `~/.butler/personalization/backups/`. Butler keeps the 20 most recent backups of each.

While Butler is running, it runs regular memory consolidation once a day, after 4 a.m. in this computer's time zone. Check the result in **Settings → System events**.

## Erase the profile

<Steps>
  1. Open **Settings → Memory**.
  2. In the **Profile** section, click **Reset** for **Erase profile**.
  3. In the **Reset profile?** dialog, check what will be removed and what stays, then click **Reset**.
</Steps>

- The entries and candidates Butler learned are deleted. This cannot be undone.
- Your chats, instructions, chat memory, project memory, the values in the **Profile** section, the persona and the EOL are not deleted.
- If profile building is on, Butler starts learning again from new conversations.
- Changing **Level** to **Off** deletes the summary used in replies, but the candidates already collected and the stored profile remain. To delete everything, also run **Erase profile**.

## Notes

<Notice tone="info" title="The app does not show learned entries one by one">
  **Profile** in **Settings → Memory** shows only the number of entries and candidates. To delete them, use **Erase profile**, which deletes all of them at once.
</Notice>

<Notice tone="warning" title="Conversation content is sent to the profile-building model">
  Profile building and memory import call the **Profile-building model**. If you choose a cloud model, the content to analyze is sent to that provider.
</Notice>

<Notice tone="info">
  If **Level** is **Off**, imported memories are not applied to the profile.
</Notice>

To send logs with a bug report, use **Export diagnostics** in [**Settings → About**](/en/help/settings/#about).
