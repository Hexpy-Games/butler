Butler Agent CLI는 데스크톱 앱 없이 Butler 런타임을 설치하고 실행하는 명령줄 도구입니다. 설치 스크립트나 standalone Agent 아카이브로 설치하며, 서비스 시작과 중지, 설치 점검, 모델과 설정 관리, MCP 서버 실행을 명령으로 처리합니다.

<Notice tone="info">
  Butler 앱을 쓴다면 CLI를 따로 설치하지 않아도 됩니다. 앱에 포함된 Agent는 앱이 직접 관리합니다.
</Notice>

## 지원 환경

- Apple Silicon Mac(`darwin-arm64`)과 Linux x64·arm64(glibc)를 지원합니다.
- Intel Mac, Alpine 같은 musl 기반 Linux는 실행되지 않습니다. Windows는 준비 중입니다.
- 네이티브 Agent 아카이브(`butler-agent-<버전>-<플랫폼>.tar.gz`)를 게시한 릴리스가 필요합니다.

## 설치

서버나 원격 PC처럼 앱 없이 쓸 때는 설치 스크립트 한 줄이면 됩니다.

```bash
curl -fsSL https://github.com/Hexpy-Games/butler/releases/latest/download/install.sh | sh
```

Node.js가 있다면 npx로도 같은 설치를 실행할 수 있습니다.

```bash
npx @hexpygames/butler install
```

설치 스크립트는 다음 순서로 진행합니다.

<Steps>
  1. 운영체제와 CPU를 확인하고 최신 릴리스(또는 지정한 버전)의 아카이브와 `butler-<버전>-SHA256SUMS`를 내려받습니다.
  2. 체크섬이 맞는지 확인한 뒤 새 버전 폴더에 풉니다. 검증이 끝나기 전에는 기존 설치를 바꾸지 않습니다.
  3. `current` 링크를 새 버전으로 바꾸고 `~/.local/bin/butler` 실행 파일을 만듭니다.
  4. `butler doctor --check installation`으로 설치를 점검한 뒤 Butler를 시작합니다.
</Steps>

같은 명령을 다시 실행해도 안전합니다. 이미 설치된 버전은 다시 풀지 않고, 데이터 폴더는 건드리지 않습니다. 이미 Butler가 실행 중이라면 `butler restart`로 새 버전을 적용합니다.

옵션은 `sh -s --` 뒤에 붙입니다(npx는 `install` 뒤에 붙입니다).

```bash
curl -fsSL https://github.com/Hexpy-Games/butler/releases/latest/download/install.sh | sh -s -- --version X.Y.Z --no-start
```

| 옵션 | 설명 |
| --- | --- |
| `--version X.Y.Z` | 최신 릴리스 대신 이 버전을 설치합니다. `BUTLER_VERSION` 환경 변수로도 지정할 수 있습니다. |
| `--no-start` | 설치만 하고 Butler를 시작하지 않습니다. |
| `--modify-path` | `~/.local/bin`이 `PATH`에 없을 때 셸 설정 파일에 추가합니다. 옵션이 없으면 추가할 줄을 안내만 합니다. |

`BUTLER_AGENT_HOME`으로 설치 폴더를, `BUTLER_BIN_DIR`로 `butler` 실행 파일 위치를 바꿀 수 있습니다. 두 값은 절대 경로여야 합니다. root로는 실행되지 않으며(`BUTLER_ALLOW_ROOT=1`로 허용), `~/.local/bin/butler`에 Butler의 실행 파일이 아닌 파일이 있으면 설치를 멈춥니다. 이전(네이티브 이전) 실행 파일은 `butler.previous`로 옮겨 둡니다.

### 설치 위치

| 항목 | macOS | Linux |
| --- | --- | --- |
| 설치 폴더 | `~/Applications/ButlerAgent` | `~/.local/share/butler/agent` |
| `butler` 명령 | `~/.local/bin/butler` | `~/.local/bin/butler` |

설치 폴더 안에는 버전마다 `<버전>-<해시 8자리>` 폴더가 생기고, `current`가 사용 중인 버전을, `previous`가 직전 버전을 가리킵니다. 오래된 버전은 최근 3개까지만 남기며(사용 중인 버전, 직전 버전, 실행 중인 버전은 항상 남깁니다) 나머지는 `butler update`나 `butler install`이 정리합니다. 데이터는 설치 폴더가 아니라 데이터 폴더(기본값 `~/.butler`)에 저장합니다. 데스크톱 앱과 CLI는 같은 설치 구조를 씁니다.

### 수동 설치

설치 스크립트를 쓸 수 없다면 아카이브를 직접 풀어 쓸 수 있습니다. 아카이브는 버전마다 새 폴더에 풀어 쓰는 설치 패키지입니다.

<Steps>
  1. [GitHub Releases](https://github.com/Hexpy-Games/butler/releases)에서 네이티브 Agent 아카이브가 올라간 버전을 확인합니다.
  2. 아래 스크립트를 파일(예: `install-butler-agent.sh`)로 저장하고 `VERSION`과 `PLATFORM`을 바꿉니다.
  3. `bash install-butler-agent.sh`로 실행합니다. 아카이브와 `butler-<버전>-SHA256SUMS`를 내려받아 체크섬을 확인한 뒤 새 버전 폴더에 풉니다.
  4. 마지막의 `version`과 `doctor` 명령이 오류 없이 끝나면 설치가 완료됩니다.
</Steps>

```bash
set -euo pipefail
VERSION=X.Y.Z # 네이티브 Agent 아카이브가 있는 릴리스 버전으로 바꿉니다.
PLATFORM=darwin-arm64 # darwin-arm64, linux-x64, linux-arm64 중 하나입니다.
ARCHIVE="butler-agent-${VERSION}-${PLATFORM}.tar.gz"
RELEASE_URL="https://github.com/Hexpy-Games/butler/releases/download/v${VERSION}"
DOWNLOAD_DIR="$HOME/Downloads/butler-agent-${VERSION}"
INSTALL_ROOT="$HOME/.local/opt/butler-agent"
INSTALL_DIR="$INSTALL_ROOT/$VERSION"
export BUTLER_DATA="${BUTLER_DATA:-$HOME/.butler}"

mkdir -p "$DOWNLOAD_DIR" "$INSTALL_ROOT" "$BUTLER_DATA"
cd "$DOWNLOAD_DIR"
curl -fL --retry 3 -o "$ARCHIVE" "$RELEASE_URL/$ARCHIVE"
SUMS="butler-${VERSION}-SHA256SUMS"
curl -fL --retry 3 -o "$SUMS" "$RELEASE_URL/$SUMS"
EXPECTED_SHA256="$(awk -v name="$ARCHIVE" '$2 == name { print $1 }' "$SUMS")"
test "${#EXPECTED_SHA256}" -eq 64
printf '%s  %s\n' "$EXPECTED_SHA256" "$ARCHIVE" | shasum -a 256 -c -

if [ -e "$INSTALL_DIR" ]; then
  printf 'Installation already exists; choose a new version directory: %s\n' "$INSTALL_DIR" >&2
  exit 1
fi
mkdir "$INSTALL_DIR"
tar -xzf "$ARCHIVE" -C "$INSTALL_DIR"
"$INSTALL_DIR/butler" --data "$BUTLER_DATA" version --json
"$INSTALL_DIR/butler" --data "$BUTLER_DATA" doctor --check installation --json
```

아카이브에는 다음 파일이 들어 있습니다.

- `butler-agent`: 실행 파일입니다.
- `butler`: `butler-agent`를 가리키는 링크입니다. 이 문서의 명령은 `butler`로 적습니다.
- `resources/`: 실행에 필요한 리소스입니다.
- `native-agent-manifest.json`: 버전과 SHA-256 정보를 담은 설치 매니페스트입니다.

수동으로 설치했다면 전체 경로 없이 `butler`로 실행하기 위해 설치 폴더를 `PATH`에 추가합니다. 셸 설정 파일(`~/.zshrc` 등)에 넣으면 새 터미널에서도 적용됩니다.

```bash
export PATH="$HOME/.local/opt/butler-agent/X.Y.Z:$PATH"
butler version
```

## 명령

`butler --help`와 `butler help schedule`로 한국어·영어 도움말을 봅니다.

| 명령 | 용도 |
| --- | --- |
| `install --from ARCHIVE\|URL` | 내려받은 아카이브를 설치합니다. 첫 설치는 위의 npx 경로를 씁니다. |
| `start`, `stop`, `restart` | 서비스를 시작·중지·재시작합니다. |
| `status`, `open`, `doctor` | 상태 확인, 브라우저 열기, 설치 점검 |
| `update --check`, `update --apply --yes` | 업데이트 확인·설치 |
| `rollback`, `uninstall --yes` | 이전 버전 복원·제거 |
| `startup enable\|disable\|status` | 로그인 시 자동 시작 관리 |
| `auth login\|logout\|status` | 모델 계정 연결 관리 |
| `model list\|status\|set MODEL` | 모델 확인·선택 |
| `logs [--follow]` | 서비스 로그 |
| `schedule list\|show\|create\|update\|run\|delete` | 예약 작업 관리 |
| `mcp list\|add\|enable\|disable\|delete\|test` | MCP 서버 연결 관리 |
| `skills list`, `skills import PATH` | 스킬 조회·가져오기 |
| `config get KEY`, `config set KEY VALUE` | 설정 조회·변경 |
| `help`, `version` | 도움말·버전 |

예약 작업은 서비스가 실행 중일 때 동작합니다. `schedule create`와 `update`의 옵션은 `butler help schedule`에서 확인합니다. `schedule list --status STATUS`는 상태별로 거르고, `--include-deleted`는 삭제한 예약 작업도 보여 줍니다.

```bash
butler startup enable
butler auth login
butler model list
butler model set openai/gpt-6-luna
butler schedule list
butler mcp add --id docs --transport http --url https://example.com/mcp
butler skills import ./skill.zip
butler config set system.defaultModel openai/gpt-6-luna
```

개인화, 기억 관리, 원격 접근 설정은 앱에서 처리합니다. CLI가 대화·개인화·기억 DB를 직접 수정하는 유지보수 명령은 제공하지 않습니다.

## 데이터와 업데이트

데이터는 `BUTLER_DATA`(기본값 `~/.butler`)에 저장합니다. 다른 폴더를 쓰려면 `--data PATH`를 붙입니다. 설치 폴더와 데이터 폴더는 겹칠 수 없습니다.

```bash
butler update --check
butler update --apply --yes
butler rollback --yes
```

업데이트는 새 버전을 별도 폴더에 설치하고 실행 중인 서비스를 재시작합니다. `rollback`은 직전 버전으로 돌아갑니다. `uninstall --keep-data --yes`는 설치만 제거하며, `--purge-data`를 지정하면 데이터도 삭제합니다.
