대화에서 그림을 만들어 달라고 하거나 이미 있는 그림을 고쳐 달라고 하면 버틀러가 이미지 모델로 처리합니다. 버틀러가 만든 그림은 이미지 편집기에서 칠한 부분만 바꿀 수도 있습니다.

## 이미지 모델 고르기

이미지를 만들려면 이미지 모델과 그 모델의 API 키가 필요합니다. 처음에는 **사용 안 함**으로 되어 있습니다.

<Steps>
  1. **설정 → 모델 → 이미지 모델**을 엽니다.
  2. **모델**에서 쓸 모델을 고릅니다.
  3. 그 제공자의 API 키를 저장한 적이 있으면 키가 자동으로 선택됩니다. 없으면 **API 키**에 키를 입력하고 **추가**를 누릅니다.
  4. 필요하면 **기본 품질**을 고릅니다.
</Steps>

바꾼 내용은 바로 저장됩니다. 이미지 모델은 API 키로만 쓸 수 있고, ChatGPT 로그인으로는 쓸 수 없습니다. 고를 수 있는 모델과 품질은 [설정 레퍼런스](/help/settings/#이미지-모델)를 참고합니다.

이미지 모델을 끄려면 **모델**에서 **사용 안 함**을 고릅니다.

## 이미지 만들기

대화에서 원하는 그림을 설명합니다. 예를 들어 "카페 로고 시안 세 가지 만들어 줘"라고 보냅니다.

- 크기와 품질은 버틀러가 정합니다. 원하는 값이 있으면 요청에 적습니다. 품질을 정하지 않으면 **기본 품질**을 씁니다.
- 이 대화의 그림이나 첨부한 이미지를 참고 그림으로 함께 쓸 수 있습니다.
- 다 만든 그림은 버틀러의 답변에 카드로 표시됩니다.

이미지 모델이 **사용 안 함**이거나 대화 권한이 **읽기 전용**이면 버틀러는 이미지를 만들지 않습니다.

### 이미지 카드

그림을 누르면 [이미지 뷰어](#이미지-뷰어)에서 크게 봅니다. 카드에는 다음 버튼이 있습니다.

- **편집** — [이미지 편집기](#이미지-편집기)를 엽니다. 대화 권한이 **읽기 전용**이거나 이미지 모델이 없으면 비활성화되고, 툴팁에 **읽기 전용** 또는 **이미지 모델 없음**이 표시됩니다.
- **서랍에 저장** — 그림을 [서랍](/help/basics/library/)의 **스크랩**에 저장합니다. 저장하면 **서랍에 저장했어요**로 바뀝니다.
- **다운로드** — 그림을 파일로 저장합니다. 데스크톱 앱에서는 저장 창이 열립니다.

## 허용 요청

이미지를 만들거나 고칠 때마다 허용을 묻는지는 대화의 [권한](/help/basics/conversation/#권한)에 따라 다릅니다.

| 권한 | 동작 |
| --- | --- |
| **전체 권한**, **알아서 진행** | 묻지 않고 진행 |
| **모두 확인**, **먼저 확인** | 요청마다 허용 여부 확인 |
| **읽기 전용** | 이미지를 만들거나 고치지 않음 |

허용 요청의 제목은 **이미지 만들기** 또는 **이미지 편집**입니다. 요청에는 **모델**, **크기**, **품질**, **프롬프트** 전체와 참고 그림이 표시되고, 위험도는 **위험 높음**입니다. **이번만 허용**이나 **거절**로 답합니다. 이미지 요청에는 **이 대화에서 계속 허용**을 고를 수 없습니다.

이미지 편집기에서 보낸 편집은 보내는 동작이 곧 허용이므로 허용 요청이 다시 나타나지 않습니다.

## 이미지 고치기

대화에서 고칠 그림과 바꿀 내용을 말하면 버틀러가 그림을 고칩니다. 이 대화에서 만든 그림과 첨부한 이미지 모두 고칠 수 있습니다. 이렇게 고치면 그림 전체가 바뀔 수 있습니다. 일부만 바꾸려면 이미지 편집기를 씁니다.

### 이미지 편집기

이미지 편집기는 버틀러가 만든 그림에서만 열 수 있습니다.

<Steps>
  1. 이미지 카드나 이미지 뷰어에서 **편집**을 누릅니다. 대화 옆에 **이미지 편집**이 열립니다.
  2. **브러시**로 바꿀 부분을 칠합니다. 잘못 칠한 곳은 **지우개**로 지웁니다.
  3. **무엇을 바꿀까요?** 입력란에 바꿀 내용을 입력합니다.
  4. **보내기**를 누릅니다.
</Steps>

- 아무 곳도 칠하지 않고 보내면 그림 전체를 고칩니다.
- **브러시 크기** 막대로 브러시 굵기를 4부터 160까지 바꿉니다.
- **실행 취소**로 마지막으로 칠한 것을 되돌립니다.
- **원본**을 누르고 있는 동안 처음 그림과 비교합니다.
- 편집하는 동안 칠한 부분이 반짝이고, 끝나면 새 그림이 나타나 현재 버전이 됩니다.
- **버전** 줄에 지금까지의 버전이 **버전 N**으로 쌓입니다. 버전을 누르면 그 버전에서 이어서 고칩니다.
- 편집에 실패하면 **편집하지 못했어요** 알림이 표시됩니다.
- 닫으려면 **닫기** 버튼을 누릅니다.

좁은 화면에서는 이미지 편집기가 화면 전체를 채웁니다.

편집기 단축키입니다.

| 키 | 동작 |
| --- | --- |
| <Kbd keys={["B"]} /> | 브러시 |
| <Kbd keys={["E"]} /> | 지우개 |
| <Kbd keys={["["]} /> / <Kbd keys={["]"]} /> | 브러시 크기 4씩 줄이기 / 늘리기 |
| <span data-mod-key><Kbd keys={["⌘", "Z"]} label="Command Z" /></span> | 실행 취소 |
| <Kbd keys={["Esc"]} label="Escape" /> | 편집기 닫기 |

## 이미지 뷰어

이미지 카드, 작업 내역의 이미지, 답변 속 이미지를 누르면 이미지 뷰어가 열립니다.

- 더블클릭, 핀치, <span data-mod-key><Kbd keys={["⌘"]} label="Command" /></span>를 누른 채 스크롤, **확대**와 **축소** 버튼으로 4배까지 확대합니다. 확대한 상태에서는 끌어서 움직입니다.
- 그림이 여러 장이면 **이전 이미지**, **다음 이미지**나 <Kbd keys={["←"]} label="왼쪽 화살표" />, <Kbd keys={["→"]} label="오른쪽 화살표" />로 넘깁니다.
- 버틀러가 만든 그림에는 카드와 같은 **편집**, **서랍에 저장**, **다운로드** 버튼이 있습니다.
- 웹 페이지에서 가져온 그림에는 **원본 페이지 열기**, **서랍에 저장**, **이미지 복사** 버튼이 있습니다.
- 그림을 불러오지 못하면 **이미지를 불러오지 못했어요**가 표시됩니다.
- **닫기**로 뷰어를 닫습니다.

## 하위 작업의 이미지

버틀러가 맡긴 하위 작업도 같은 이미지 모델과 같은 권한 규칙으로 그림을 만들고 고칩니다. 작업 내역의 이미지 도구 기록에는 결과 그림이 작게 표시되고, 누르면 이미지 뷰어가 열립니다.

## 주의 사항

<Notice tone="info">
  Google 모델은 칠한 모양을 그대로 받지 않고, 칠한 부분을 감싸는 사각형 범위만 전달받습니다. 그래서 사각형 안에서 칠하지 않은 부분도 바뀔 수 있습니다. OpenAI 모델은 칠한 모양 그대로 전달받습니다.
</Notice>

<Notice tone="info">
  이미지 생성과 편집 횟수, 추정 비용은 [**설정 → 사용량**](/help/settings/#사용량)에서 봅니다.
</Notice>
