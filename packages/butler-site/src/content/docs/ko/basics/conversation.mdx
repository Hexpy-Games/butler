대화 화면에서 Butler에게 요청을 보내고 결과를 받습니다. 화면 아래의 컴포저에서 메시지를 쓰고, 파일을 첨부하고, 모델과 권한을 고릅니다.

## 새 대화 시작하기

- 사이드바 맨 위의 **새 대화**를 누릅니다.
- 프로젝트 안에서 시작하려면 사이드바에서 프로젝트 메뉴를 열고 **새 대화**를 고르거나, 프로젝트 대시보드의 **새 대화**를 누릅니다.
- 명령 팔레트에서 프로젝트를 고르면 그 프로젝트의 새 대화가 열립니다.

새 대화 화면에는 바로 시작할 수 있는 제안이 나옵니다. 제안을 누르면 그 내용이 메시지로 전송됩니다. 첫 메시지를 보내면 대화가 만들어지고 사이드바에 추가됩니다.

## 메시지 보내기

<Steps>
  1. 컴포저의 입력창에 요청을 씁니다.
  2. 필요하면 파일을 첨부하고 모델과 권한을 고릅니다.
  3. <span data-mod-key><Kbd keys={["⌘", "Enter"]} label="Command Enter" /></span>를 누르거나 **전송** 버튼을 누릅니다.
</Steps>

대화 중에는 컴포저가 한 줄로 접힐 수 있습니다. 컴포저를 누르면 입력창과 도구 모음이 펼쳐지고, 컴포저 밖을 누르면 다시 접힙니다.

### 보내기 키

- 기본 설정에서는 <span data-mod-key><Kbd keys={["⌘", "Enter"]} label="Command Enter" /></span>로 보내고 <Kbd keys={["Enter"]} />로 줄을 바꿉니다.
- **설정 → 일반**의 **대화 입력**에서 **메시지 보내기**를 **Enter 전송, Shift Enter 줄바꿈**으로 바꾸면 <Kbd keys={["Enter"]} />로 보내고 <Kbd keys={["Shift", "Enter"]} label="Shift Enter" />로 줄을 바꿉니다.
- <span data-mod-key><Kbd keys={["⌘", "Enter"]} label="Command Enter" /></span>는 어느 설정에서나 메시지를 보냅니다.
- 한글을 조합하는 중에 누른 <Kbd keys={["Enter"]} />로는 전송되지 않습니다.
- 모델이나 권한 메뉴가 열려 있을 때 <Kbd keys={["Esc"]} label="Escape" />를 누르면 메뉴가 닫힙니다.

## 컴포저 도구 모음

- **추가 기능**(+) — 파일과 프로젝트 문서를 첨부하고 응답 방식을 고릅니다.
- **권한** — 이 대화에서 Butler가 할 수 있는 작업의 범위를 고릅니다.
- **작업 위치** — 새 대화에서만 나타납니다. **로컬** 또는 **워크트리**를 고릅니다.
- **계획** — 계획 모드가 켜져 있을 때 나타납니다.
- 컨텍스트 사용량 — 원 모양 표시에 마우스를 올리면 사용량이 나옵니다. 누르면 [오른쪽 패널](/help/basics/right-panel/#맥락)의 **맥락** 탭이 열립니다.
- 모델 — 현재 모델과 추론 강도를 보여 줍니다.
- **전송** / **중지** — 메시지를 보내거나 진행 중인 작업을 멈춥니다.

## 모델과 추론 강도

컴포저의 모델 버튼을 누르면 모델 메뉴가 열립니다.

- 검색 칸(**모델 검색...**)에 모델 이름, 모델 ID, 제공자 이름을 입력해 찾습니다.
- **전체** 또는 제공자 이름을 눌러 목록을 제공자별로 거릅니다.
- 목록은 제공자별로 묶여 있고, 모델마다 컨텍스트 크기가 함께 표시됩니다.
- 메뉴 아래의 **추론**에서 추론 강도를 고릅니다. 고를 수 있는 값은 모델마다 다릅니다.

선택은 이 대화에만 적용됩니다. 새 대화는 **설정 → 모델**의 **버틀러 모델**에서 정한 모델로 시작합니다. 모델을 바꿀 때 지금 추론 강도를 새 모델이 지원하지 않으면 그 모델의 기본값으로 바뀝니다.

모델 버튼에 **모델 확인 중**, **선택한 모델 사용 불가**, **모델 상태 오류**가 표시되면 메시지를 보낼 수 없습니다. **설정 → 모델**에서 사용할 모델을 확인합니다. 모델을 등록하고 기본 모델을 고르는 방법은 [클라우드 모델](/help/models/cloud/)을 참고합니다.

## 권한

**권한** 메뉴에서 이 대화의 접근 권한을 고릅니다.

- **전체 권한** — 파일을 읽고 쓰고 명령을 실행할 수 있습니다.
- **먼저 확인** — 파일을 수정하거나 명령을 실행하기 전에 허용 여부를 묻습니다.
- **읽기 전용** — 파일을 읽기만 할 수 있습니다.

선택은 이 대화에만 적용됩니다. 새 대화는 **먼저 확인**으로 시작하며, 이 기본값은 **설정 → 모델 → 권한**의 **접근 권한**에서 바꿉니다.

### 허용 요청에 답하기

**먼저 확인**에서 Butler가 파일을 수정하거나 명령을 실행하려고 하면 상태에 **허용 여부를 기다리고 있습니다.** 문구가 표시되고, 컴포저 자리에 허용 요청이 나타납니다.

- **이번만 허용** — 이번 요청만 실행합니다.
- **이 대화에서 계속 허용** — **이번만 허용** 옆의 화살표(**허용 범위 선택**)를 눌러 고릅니다. 현재 요청을 실행하고, 이 대화의 하위 작업에도 적용합니다.
- **거절** — 요청을 실행하지 않습니다.
- **나중에 결정하고 메시지 작성** — 요청 오른쪽의 아래 화살표를 누르면 결정을 미루고 메시지를 쓸 수 있습니다. 입력창 위에 **허용 대기 N개** 표시가 남아 있어 다시 요청으로 돌아갈 수 있습니다.

계속 허용한 항목은 **권한** 버튼에 **허용 N개**로 표시됩니다. **권한** 메뉴의 **이 대화에서 허용 중**에서 항목을 누르면 허용이 해제됩니다.

## 계획 모드

계획 모드에서는 Butler가 바로 작업하지 않고 먼저 계획을 세워 대화에 보여 줍니다. 프로젝트 대화에서만 쓸 수 있습니다.

<Steps>
  1. **추가 기능**(+)을 누르고 **응답 방식**에서 **계획**을 고릅니다. 컴포저에 **계획** 표시가 나타납니다.
  2. 요청을 보냅니다. Butler가 대화에 계획을 올리면 컴포저 자리에 계획 결정이 나타납니다.
  3. 계획을 검토하고 **수락**, **거절**, **직접 입력** 중 하나를 누릅니다.
</Steps>

- **수락** — 계획을 확정하고 계획 모드를 끈 뒤 계획대로 작업을 이어 갑니다.
- **거절** — 계획을 거절하고 계획 모드를 끕니다.
- **직접 입력** — 입력창에 수정할 내용을 써서 보냅니다. 계획 모드는 켜진 채로 유지되고 Butler가 계획을 고칩니다.

계획 결정에서 계획 제목을 누르면 대화 속 계획으로 이동합니다. 계획 모드를 끄려면 **계획** 표시의 X 버튼을 누르거나 **응답 방식**에서 **일반**을 고릅니다. 프로젝트 대화를 항상 계획 모드로 시작하려면 **설정 → 모델**에서 **기본으로 계획 모드 사용**을 켭니다.

## 파일 첨부

- **추가 기능**(+)에서 **파일 첨부**를 누르고 파일을 고릅니다. 여러 파일을 한 번에 고를 수 있습니다.
- 파일을 Butler 창으로 끌어다 놓아도 첨부됩니다.
- 프로젝트 대화에서는 **추가 기능**(+)의 **프로젝트 문서**에서 프로젝트 문서를 제목으로 찾아 첨부할 수 있습니다.
- 첨부한 파일은 입력창 아래에 표시되며, 각 파일의 제거 버튼으로 뺄 수 있습니다.

다른 대화를 메시지에 참조하려면 사이드바에서 대화를 컴포저로 끌어다 놓거나, 대화 메뉴에서 **작성 중인 메시지에 참조**를 고릅니다.

## 작업 위치

새 대화의 첫 메시지를 보내기 전에 **작업 위치**를 고를 수 있습니다.

- **로컬** — 기본값입니다.
- **워크트리** — 새 프로젝트 대화에서만 고를 수 있습니다. 대화를 만들 때 이 대화 전용 Git 워크트리를 준비해 그곳에서 작업합니다.

## 진행 상황 보기와 중지

Butler가 작업하는 동안 대화에는 **응답 생성 중**, **허용 여부를 기다리고 있습니다.** 같은 현재 상태가 표시됩니다. 진행 내역을 펼치면 단계별 활동과 도구 사용 내역을 볼 수 있습니다.

작업을 멈추려면 입력창을 비운 상태에서 전송 버튼 자리에 나타나는 **중지** 버튼을 누릅니다. 중지한 답변에는 **중지됨**이 표시됩니다.

### 작업 중에 메시지 보내기

작업이 진행되는 동안 보낸 메시지는 **대기 중인 메시지**로 쌓였다가 순서대로 전달됩니다.

- 대기 메시지에는 **대기 중** 또는 **대기 중 · 3개 중 2번째** 같은 순서가 표시됩니다.
- **대기 메시지 수정**을 누르면 메시지를 컴포저로 다시 불러오고 대기열에서 뺍니다.
- **대기 메시지 삭제**를 누르면 대기열에서 지웁니다.
- 보내지 못한 메시지에는 **전송 실패**가 표시되며, **다시 작성** 또는 **실패 메시지 삭제**를 고릅니다.

## 메시지 동작

- **메시지 복사** — 답변과 내가 보낸 메시지 아래에 있습니다.
- **코드 복사** — 답변 속 코드 블록마다 있습니다.
- 답변 아래에는 작업에 걸린 시간(**N 동안 작업**), 완료 시각, **답변 완료**·**답변 중지**·**답변 실패** 중 하나가 표시됩니다.
- Butler가 파일을 바꾼 답변에는 **파일 변경** 목록이 붙습니다. 파일이 많으면 **더보기**로 나머지를 펼칩니다.
- 긴 메시지는 **더보기**와 **접기**로 펼치고 접습니다.
- 다시 시도할 수 있는 오류로 요청이 실패하면 **원래 설정으로 다시 시도** 또는 **현재 설정으로 새로 시도**를 고릅니다. **원래 설정으로 다시 시도**는 처음 보낸 설정 그대로, **현재 설정으로 새로 시도**는 지금 이 대화에 선택된 모델과 권한 설정으로 다시 요청합니다.
- 위로 스크롤한 상태에서는 **최신으로 이동** 버튼이 나타납니다. 새 메시지가 도착하면 **새 메시지**로 바뀝니다.

### 답변에서 새 대화로 이어 가기

사이드바의 **일반** 대화에서는 완료된 답변 아래에 **새 주제대화 시작**과 **새 프로젝트 시작** 버튼이 있습니다. 이 답변까지의 요청과 결정을 정리해 새 대화나 새 프로젝트로 이어 가며, 원래 대화는 그대로 남습니다.

<Steps>
  1. 답변 아래에서 **새 주제대화 시작** 또는 **새 프로젝트 시작**을 누릅니다.
  2. **대화 제목** 또는 **프로젝트 이름**을 입력합니다.
  3. **만들기**를 누릅니다.
</Steps>

## 주의 사항

<Notice tone="warning">
  **전체 권한**에서는 Butler가 허용 여부를 묻지 않고 파일을 수정하고 명령을 실행합니다. 중요한 파일이 있는 곳에서는 **먼저 확인**이나 **읽기 전용**으로 작업합니다.
</Notice>

<Notice tone="info">
  첨부 파일은 파일당 10.0 MB까지입니다. 더 큰 파일은 **파일이 첨부 가능한 크기를 초과했습니다.** 알림과 함께 첨부되지 않습니다. 파일을 올리는 동안에는 메시지를 보낼 수 없습니다.
</Notice>

<Notice tone="info">
  작업을 마무리하는 단계처럼 중지할 수 없는 구간에서는 **중지** 버튼이 나타나지 않습니다. 실시간 연결이 끊기면 전송 버튼이 **실시간 연결 복구 중** 상태로 바뀌고, 연결이 돌아올 때까지 보낼 수 없습니다.
</Notice>
