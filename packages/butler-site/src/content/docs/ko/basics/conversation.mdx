대화 화면에서 버틀러에게 요청을 보내고 결과를 받습니다. 화면 아래의 컴포저에서 메시지를 쓰고, 파일을 첨부하고, 모델과 권한을 고릅니다.

## 새 대화 시작하기

- 사이드바 맨 위의 **새 대화**를 누릅니다.
- 프로젝트 안에서 시작하려면 사이드바에서 프로젝트 메뉴를 열고 **새 대화**를 고르거나, 프로젝트 대시보드의 **새 대화**를 누릅니다.
- 명령 팔레트에서 프로젝트를 고르면 그 프로젝트의 새 대화가 열립니다.

새 대화 화면에는 바로 시작할 수 있는 제안이 나옵니다. 제안을 누르면 그 내용이 바로 전송되거나, 이어 쓸 수 있게 컴포저에 채워집니다. 컴포저에 쓰던 내용이 있으면 채우지 않습니다. 첫 메시지를 보내면 대화가 만들어지고 사이드바에 추가됩니다.

## 메시지 보내기

<Steps>
  1. 컴포저의 입력창에 요청을 씁니다.
  2. 필요하면 파일을 첨부하고 모델과 권한을 고릅니다.
  3. <span data-mod-key><Kbd keys={["⌘", "Enter"]} label="Command Enter" /></span>를 누르거나 **전송** 버튼을 누릅니다.
</Steps>

대화 중에는 컴포저가 한 줄로 접힐 수 있습니다. 컴포저를 누르면 입력창과 도구 모음이 펼쳐지고, 컴포저 밖을 누르면 다시 접힙니다.

### 보내기 키

- 기본 설정에서는 <span data-mod-key><Kbd keys={["⌘", "Enter"]} label="Command Enter" /></span>로 보내고 <Kbd keys={["Enter"]} />로 줄을 바꿉니다.
- **설정 → 일반**의 **대화 입력**에서 **메시지 보내기**를 **Enter 전송, Shift Enter 줄바꿈**으로 바꾸면 <Kbd keys={["Enter"]} />로 보내고 <Kbd keys={["Shift", "Enter"]} label="Shift Enter" />로 줄을 바꿉니다.
- <span data-mod-key><Kbd keys={["⌘", "Enter"]} label="Command Enter" /></span>는 어느 설정에서나 메시지를 보냅니다.
- 한글을 조합하는 중에 누른 <Kbd keys={["Enter"]} />로는 전송되지 않습니다.
- 모델이나 권한 메뉴가 열려 있을 때 <Kbd keys={["Esc"]} label="Escape" />를 누르면 메뉴가 닫힙니다.

## 컴포저 도구 모음

- **추가 기능**(+) — 파일과 프로젝트 문서를 첨부하고 응답 방식을 고릅니다.
- **권한** — 이 대화에서 버틀러가 할 수 있는 작업의 범위를 고릅니다.
- **작업 위치** — Git 저장소로 확인된 프로젝트의 새 대화에서만 나타납니다. **로컬** 또는 **워크트리**를 고릅니다.
- **계획** — 계획 모드가 켜져 있을 때 나타납니다.
- 컨텍스트 사용량 — 원 모양 표시에 마우스를 올리면 컨텍스트와 모델 사용량이 나오고, 누르면 닫을 때까지 계속 표시됩니다. **자세히**를 누르면 [**설정 → 사용량**](/help/settings/#사용량)이 열립니다.
- 모델 — 현재 모델과 추론 강도를 보여 줍니다.
- **전송** / **중지** — 메시지를 보내거나 진행 중인 작업을 멈춥니다.

## 모델과 추론 강도

컴포저의 모델 버튼을 누르면 모델 메뉴가 열립니다.

- 검색 칸(**모델 검색...**)에 모델 이름, 모델 ID, 제공자 이름을 입력해 찾습니다.
- **전체** 또는 제공자 이름을 눌러 목록을 제공자별로 거릅니다.
- 목록은 제공자별로 묶여 있고, 모델마다 컨텍스트 크기가 함께 표시됩니다.
- 메뉴 아래의 **추론**에서 추론 강도를 고릅니다. 고를 수 있는 값은 모델마다 다릅니다.

선택은 이 대화에만 적용됩니다. 새 대화는 **설정 → 모델**의 **버틀러 모델**에서 정한 모델로 시작합니다. 모델을 바꿀 때 지금 추론 강도를 새 모델이 지원하지 않으면 그 모델의 기본값으로 바뀝니다.

모델 버튼에 **모델 확인 중**이나 **모델 없음**이 표시되거나, ChatGPT 모델에 **ChatGPT 플랜에 없는 모델** 또는 **ChatGPT에 다시 로그인하세요** 툴팁이 표시되면 메시지를 보낼 수 없습니다. **설정 → 모델**에서 사용할 모델을 확인합니다. 모델을 등록하고 기본 모델을 고르는 방법은 [클라우드 모델](/help/models/cloud/)을 참고합니다.

## 권한

**권한** 메뉴에서 이 대화의 접근 권한을 고릅니다. 메뉴에는 다섯 단계가 있고, **알아서 진행**에 **권장**이 표시됩니다.

- **알아서 진행** — 위험한 작업만 허용 여부를 묻습니다.
- **읽기 전용** — 파일을 읽기만 할 수 있습니다.
- **먼저 확인** — 파일을 수정하거나 명령을 실행하기 전에 허용 여부를 묻습니다.
- **모두 확인** — 모든 작업 전에 허용 여부를 묻습니다.
- **전체 권한** — 확인 없이 파일을 읽고 쓰고 명령을 실행합니다.

선택은 이 대화에만 적용됩니다. 새 대화와 새 예약 작업이 쓸 권한은 [**설정 → 일반 → 기본 권한**](/help/settings/#일반)의 **새 대화**와 **새 예약 작업**에서 정합니다. 예약 작업마다 편집 화면의 **권한**에서 따로 고를 수도 있습니다.

- 새로 설치한 버틀러에서 새 대화의 기본값은 **먼저 확인**, 새 예약 작업의 기본값은 **알아서 진행**입니다.
- 이전 버전부터 쓰던 버틀러는 권한을 저장한 적이 없으면 **전체 권한**을 그대로 씁니다.
- 저장한 권한은 업데이트해도 바뀌지 않습니다.

**먼저 확인**에서도 다음 작업은 허용 여부를 묻지 않고 진행합니다.

- [첫 대화 온보딩](/help/getting-started/first-run/#설정을-마친-뒤)에서 답한 내용 저장
- 기억 저장
- 메시지에 첨부한 이미지 분석

MCP 서버의 도구는 이 예외에 들지 않습니다. 이미지를 분석하는 도구라도 실행하기 전에 허용 여부를 묻습니다.

### 허용 요청에 답하기

**먼저 확인**처럼 허용 여부를 묻는 권한에서 버틀러가 파일을 수정하거나 명령을 실행하려고 하면 상태에 **허용 여부를 기다리고 있습니다.** 문구가 표시되고, 대화에 허용 요청 카드가 나타납니다. 요청을 기다리는 동안에도 컴포저에서 메시지를 쓸 수 있습니다.

허용 요청은 버틀러가 하려는 일을 질문 한 문장으로 보여 줍니다. 기다리는 요청이 더 있으면 카드에 `+N`이 표시됩니다.

- 질문 — 무엇을 어디서 하려는지 묻습니다. 파일 수정과 명령 실행에는 작업 폴더 이름이 함께 나옵니다.
- 대상 — 수정할 파일이나 실행할 명령을 세 개까지 보여 주고, 나머지는 **외 N개**로 표시합니다. 파일은 작업 폴더 기준의 상대 경로로, 명령은 실행할 그대로 표시됩니다.
- 위험도 — **위험 낮음**, **위험 보통**, **위험 높음** 중 하나로 표시됩니다.

대상이 네 줄을 넘으면 **더보기**로 표시된 내용을 펼치고 **접기**로 다시 접습니다. 명령은 길어도 전체를 표시합니다. 크기 한도에서 잘린 내용은 끝에 `…`이 붙습니다.

작업 폴더 안의 읽기는 대개 낮음, 폴더 안 수정은 보통, 폴더 밖 수정·셸 리다이렉션·MCP 도구는 높음입니다.

요청에 답하는 버튼입니다.

- **이번만 허용** — 이번 요청만 실행합니다.
- **이 대화에서 계속 허용** — **이번만 허용** 옆의 화살표(**허용 범위 선택**)를 눌러 고릅니다. 현재 요청을 실행하고, 이 대화의 하위 작업에도 적용합니다. 메뉴에 계속 허용할 범위가 함께 표시됩니다.
- **거절** — 요청을 실행하지 않습니다.

사이트 로그인이나 결제를 쓰는 요청에서는 주 버튼이 **이 대화에서 허용**이고, 화살표 메뉴에 **이 사이트는 항상 허용** 또는 **이 사이트 결제는 항상 허용**이 있습니다.

계속 허용한 항목은 **권한** 버튼에 **허용 N개**로 표시됩니다. **권한** 메뉴의 **이 대화에서 허용 중**에서 항목을 누르면 허용이 해제됩니다.

## 질문에 답하기

버틀러가 추가 정보가 필요하면 대화에 질문 카드가 나타납니다. 질문에 따라 하나 또는 여러 선택지를 고르거나 직접 답변을 입력합니다. **직접 입력…** 항목이 있으면 선택지 대신 내용을 씁니다. 추천 선택지는 답변을 자동으로 제출하지 않습니다.

여러 질문은 **다음**과 **이전**로 이동하고, 검토한 뒤 **보내기**로 제출합니다. **건너뛰기**로 답변을 생략할 수 있습니다. **나중에 답하기**로 미룬 질문은 [**세션 정보**](/help/basics/right-panel/)의 **답을 기다리는 요청**에 남습니다. 제출한 답변은 대화에 남고 버틀러가 작업을 이어 갑니다. 질문 답변과 작업 실행 허용은 별도입니다.

질문 카드는 한 대화에 하나만 열립니다. 카드가 열려 있는 동안 생긴 다른 질문은 버틀러가 답변 글에서 묻습니다.

## 계획 모드

계획 모드에서는 버틀러가 바로 작업하지 않고 먼저 계획을 세워 대화에 보여 줍니다. 프로젝트 대화에서만 쓸 수 있습니다.

<Steps>
  1. **추가 기능**(+)을 누르고 **응답 방식**에서 **계획**을 고릅니다. 컴포저에 **계획** 표시가 나타납니다.
  2. 요청을 보냅니다. 버틀러가 대화에 계획을 올리면 그 아래에 계획 결정 카드가 나타납니다.
  3. 계획을 검토하고 **수락**, **거절**, **직접 입력** 중 하나를 누릅니다.
</Steps>

- **수락** — 계획을 확정하고 계획 모드를 끈 뒤 계획대로 작업을 이어 갑니다.
- **거절** — 계획을 거절하고 계획 모드를 끕니다.
- **직접 입력** — 입력창에 수정할 내용을 써서 보냅니다. 계획 모드는 켜진 채로 유지되고 버틀러가 계획을 고칩니다.

계획 결정에서 계획 제목을 누르면 대화 속 계획으로 이동합니다. 계획 모드를 끄려면 **계획** 표시의 X 버튼을 누르거나 **응답 방식**에서 **일반**을 고릅니다. 프로젝트 대화를 항상 계획 모드로 시작하려면 **설정 → 일반**의 **대화 입력**에서 **기본으로 계획 모드 사용**을 켭니다.

## 파일 첨부

- **추가 기능**(+)에서 **파일 첨부**를 누르고 파일을 고릅니다. 여러 파일을 한 번에 고를 수 있습니다.
- 파일을 버틀러 창으로 끌어다 놓아도 첨부됩니다.
- 프로젝트 대화에서는 **추가 기능**(+)의 **프로젝트 문서**에서 프로젝트 문서를 제목으로 찾아 첨부할 수 있습니다.
- 첨부한 파일은 입력창 아래에 표시되며, 각 파일의 제거 버튼으로 뺄 수 있습니다.

다른 대화를 메시지에 참조하려면 사이드바에서 대화를 컴포저로 끌어다 놓거나, 대화 메뉴에서 **작성 중인 메시지에 참조**를 고릅니다.

컴포저에 `@`를 입력하면 대화와 프로젝트 목록이 나옵니다. 이어서 이름을 입력해 찾고 <Kbd keys={["Enter"]} />나 <Kbd keys={["Tab"]} />으로 참조를 넣습니다.

## 작업 위치

Git 저장소로 확인된 프로젝트에서는 새 대화의 첫 메시지를 보내기 전에 **작업 위치**를 고를 수 있습니다. 프로젝트 대시보드 아래 입력창에서도 고를 수 있습니다. 프로젝트 밖 대화와 Git 저장소가 아닌 프로젝트에서는 나타나지 않습니다.

- **로컬** — 기본값입니다.
- **워크트리** — 대화를 만들 때 이 대화 전용 Git 워크트리를 준비해 그곳에서 작업합니다.

## 진행 상황 보기와 중지

버틀러가 작업하는 동안 대화에는 **응답 생성 중**, **허용 여부를 기다리고 있습니다.** 같은 현재 상태가 표시됩니다. 진행 내역을 펼치면 단계별 활동과 도구 사용 내역을 볼 수 있습니다.

작업을 멈추려면 입력창을 비운 상태에서 전송 버튼 자리에 나타나는 **중지** 버튼을 누릅니다. 중지한 답변에는 **중지됨**이 표시됩니다.

### 작업 중에 메시지 보내기

작업이 진행되는 동안 보낸 메시지는 **대기 중인 메시지**로 쌓였다가 순서대로 전달됩니다.

- 대기 메시지에는 **대기 중** 또는 **대기 중 · 3개 중 2번째** 같은 순서가 표시됩니다.
- 첫 번째 대기 메시지의 **지금 보내기**를 누르면 진행 중인 답변을 멈추고 이 메시지를 바로 보냅니다. 보내는 동안 **보내는 중…** 상태가 표시되고, 나머지 대기 메시지는 순서를 유지합니다. 보내지 못하면 **보내지 못했습니다** 알림이 나옵니다.
- **대기 메시지 수정**을 누르면 메시지를 컴포저로 다시 불러오고 대기열에서 뺍니다.
- **대기 메시지 삭제**를 누르면 대기열에서 지웁니다.
- 보내지 못한 메시지에는 **전송 실패**가 표시되며, **다시 작성** 또는 **실패 메시지 삭제**를 고릅니다.

## 하위 작업

버틀러가 일을 하위 작업으로 나누어 맡기면, 그 일을 시작한 답변에 작업 카드가 붙습니다. 카드에는 하위 작업 제목과 상태가 표시되고, 펼치면 활동 목록이 나옵니다.

- **작업 중** — 진행 중입니다. 계획이 있으면 `완료 2/5 · 지금: …`처럼 단계 진행이 함께 표시됩니다.
- **완료됨** — 하위 작업이 최종 답변을 내고 끝났습니다. 그 답변이 막힌 상황을 알리는 내용이어도 **완료됨**으로 표시됩니다.
- **실패함** — 시스템 오류로 끝났습니다. 계획이 있으면 멈춘 단계 이름이 함께 표시됩니다.
- **중단됨** — 중간에 멈췄습니다.
- **대기 중** — 시작을 기다리고 있습니다.

계획의 각 단계는 **대기 중**, **진행 중**, **완료**, **막힘**, **건너뜀** 중 하나로 표시됩니다. **막힘**은 단계에만 쓰이고 하위 작업 자체의 상태로는 표시되지 않습니다.

카드의 **진행 상세 보기**(눈 모양)를 누르면 작업 기록 창이 열리고, 여기서 **중지**하거나 **이어서 진행**할 수 있습니다. 중간에 끊긴 하위 작업에는 카드에도 **이어서 진행** 버튼이 나타납니다.

사이드바의 **대화**에서 맡긴 일은 끝나면 답변 하나로 돌아옵니다. 답변의 **작업 보기**를 누르면 같은 작업 기록 창이 열립니다. 예약 작업처럼 사용자가 없을 때 건너뛴 작업은 **확인 필요** 표시와 함께 대화에 남습니다.

끝나지 않은 하위 작업은 두 곳에도 나타납니다.

- 사이드바 **전체보기**에서 해당 대화 아래 한 줄씩 표시됩니다. 자세한 내용은 [사이드바와 스페이스](/help/basics/sidebar-and-spaces/#하위-작업-표시)를 참고합니다.
- 제목 표시줄의 [**세션 정보**](/help/basics/right-panel/)를 열면 **하위 작업** 섹션에 모입니다.

두 곳에서는 상태가 **작업 중**, **멈춤**, **허용 대기**, **대기** 중 하나로 표시됩니다.

## 메시지 동작

- **메시지 복사** — 답변과 내가 보낸 메시지 아래에 있습니다.
- **코드 복사** — 답변 속 코드 블록마다 있습니다.
- 답변 아래에는 작업에 걸린 시간(**N 동안 작업**), 완료 시각, **답변 완료**·**답변 중지**·**답변 실패** 중 하나가 표시됩니다.
- 버틀러가 파일을 바꾼 답변에는 **파일 변경** 목록이 붙습니다. 파일이 많으면 **더보기**로 나머지를 펼칩니다.
- 긴 메시지는 **더보기**와 **접기**로 펼치고 접습니다.
- 다시 시도할 수 있는 오류로 요청이 실패하면 **원래 설정으로 다시 시도** 또는 **현재 설정으로 새로 시도**를 고릅니다. **원래 설정으로 다시 시도**는 처음 보낸 설정 그대로, **현재 설정으로 새로 시도**는 지금 이 대화에 선택된 모델과 권한 설정으로 다시 요청합니다.
- 위로 스크롤한 상태에서는 **최신으로 이동** 버튼이 나타납니다. 새 메시지가 도착하면 **새 메시지**로 바뀝니다.
- 표, 차트 같은 답변 카드는 준비하는 동안 **답변 카드 준비 중**이 표시됩니다. 카드마다 **더 보기** 메뉴에서 **서랍에 저장**, **문서로 만들기**, **복사**를 고릅니다.

### 답변에서 새 대화로 이어 가기

사이드바의 **대화**와 프로젝트 대화에서는 완료된 답변 아래에 **새 주제대화 시작**과 **새 프로젝트 시작** 아이콘 버튼이 있습니다. 이 답변까지의 요청과 결정을 정리해 새 대화나 새 프로젝트로 이어 가며, 원래 대화는 그대로 남습니다.

<Steps>
  1. 답변 아래에서 **새 주제대화 시작** 또는 **새 프로젝트 시작**을 누릅니다.
  2. **대화 제목** 또는 **프로젝트 이름**을 입력합니다.
  3. **만들기**를 누릅니다.
</Steps>

## 버틀러가 먼저 건네는 제안

버틀러가 대화에서 반복되는 습관을 알아채면 사이드바의 **대화**에 예약 작업 제안 카드를 보냅니다. 카드에는 만들 예약 작업의 주기와 내용이 그대로 표시됩니다.

- **좋아요** — 그 예약 작업을 만듭니다.
- **괜찮아요** — 만들지 않습니다.

예약 작업의 결과를 여러 번 연속으로 열어 보지 않으면 계속 받을지 묻는 카드가 옵니다. **좋아요**를 누르면 계속 받고, **괜찮아요**를 누르면 그 예약 작업을 멈춥니다. 답한 카드는 결과 한 줄로 바뀝니다. 예약 작업이 있으면 그 줄을 눌러 엽니다.

제안은 **설정 → 기억**의 **조용한 시간**과 메시지를 쓰는 동안에는 오지 않습니다. 제안 빈도는 같은 화면의 **먼저 말 걸기**에서 정합니다.

## 주의 사항

<Notice tone="warning">
  **전체 권한**에서는 버틀러가 허용 여부를 묻지 않고 파일을 수정하고 명령을 실행합니다. 중요한 파일이 있는 곳에서는 **먼저 확인**이나 **읽기 전용**으로 작업합니다.
</Notice>

<Notice tone="info">
  첨부 파일은 파일당 10.0 MB까지입니다. 더 큰 파일은 **파일이 첨부 가능한 크기를 초과했습니다.** 알림과 함께 첨부되지 않습니다. 파일을 올리는 동안에는 메시지를 보낼 수 없습니다.
</Notice>

<Notice tone="info">
  작업을 마무리하는 단계처럼 중지할 수 없는 구간에서는 **중지** 버튼이 나타나지 않습니다. 실시간 연결이 끊기면 전송 버튼이 **실시간 연결 복구 중** 상태로 바뀌고, 연결이 돌아올 때까지 보낼 수 없습니다.
</Notice>
