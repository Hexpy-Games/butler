서랍은 버틀러가 전달한 파일과 만든 웹 페이지, 직접 저장한 이미지와 스크랩, 북마크를 모아 두는 곳입니다. 사이드바의 **서랍**을 눌러 엽니다.

## 서랍 열기

- 사이드바의 **서랍**을 누릅니다.
- [파일 보기](/help/basics/right-panel/#파일-보기)에서 **서랍에서 열기**를 누르면 서랍의 **문서**가 그 파일 이름으로 검색된 채 열립니다.

## 서랍 구성

첫 화면에는 **스크랩**, **문서**, **북마크**, **결과물**이 차례로 표시됩니다. 각 영역에는 항목 수와 최근 항목이 보이고, **모두 보기**를 누르면 그 종류의 전체 목록이 열립니다.

- **스크랩** — 브라우저에서 저장한 페이지 일부와, **서랍에 저장**으로 저장한 이미지와 답변 카드입니다. 그룹으로 묶을 수 있습니다.
- **문서** — 버틀러가 전달한 파일과 편집할 수 있는 문서입니다.
- **북마크** — 브라우저 북마크입니다. 폴더로 묶을 수 있습니다.
- **결과물** — 버틀러가 만든 웹 페이지입니다.

## 찾기

<Steps>
  1. 위쪽의 **서랍 검색**에 검색어를 입력합니다.
  2. **전체**, **스크랩**, **문서**, **북마크**, **결과물** 중 하나를 골라 종류를 좁힙니다.
  3. 필요하면 **태그**, **사이트**, **기간**, **정렬** 메뉴로 목록을 거릅니다.
</Steps>

적용한 필터는 검색 창 아래에 표시됩니다. **모두 지우기**를 누르면 필터를 한꺼번에 지웁니다.

## 서랍에 저장되는 항목

| 항목 | 저장 위치 | 저장 방법 |
| --- | --- | --- |
| 버틀러가 답변에 전달한 파일 | **문서** | 자동 |
| 버틀러가 만든 웹 페이지 | **결과물** | 자동 |
| 변경 파일 | **문서** | 변경 파일 메뉴의 **서랍에 저장** |
| 버틀러가 만든 이미지 | **스크랩** | 이미지의 **서랍에 저장** |
| 답변 카드 | **스크랩** | 카드 메뉴의 **서랍에 저장** |

버틀러가 만든 이미지는 자동으로 저장되지 않습니다. 남기려면 [이미지 카드](/help/basics/images/#이미지-카드)나 이미지 뷰어에서 **서랍에 저장**을 누릅니다.

## 버전

버틀러가 같은 대화에서 같은 파일을 다시 전달하면 새 항목이 생기지 않고 그 문서의 새 버전으로 쌓입니다.

- 문서마다 최근 버전 20개까지 보관합니다. 더 오래된 버전은 지워집니다.
- 내용이 이전 버전과 같으면 새 버전이 생기지 않습니다.
- 파일 보기의 **버전**에서 이전 버전을 골라 봅니다.

## 파일 열기

항목을 누르면 서랍 안에서 [파일 보기](/help/basics/right-panel/#파일-보기)로 열립니다. 파일을 닫으면 필터와 스크롤 위치가 그대로인 목록으로 돌아옵니다.

- 편집할 수 있는 문서는 문서 편집기로 열립니다.
- 스크랩은 저장한 내용의 상세 화면으로 열립니다.

항목의 **더 보기** 메뉴에서 다음 작업을 합니다.

- **이름 변경** — 항목 이름을 바꿉니다.
- **그룹으로 이동…** / **폴더로 이동…** — 스크랩을 그룹으로, 북마크를 폴더로 옮깁니다.
- **태그 편집…** — 태그를 붙이거나 뺍니다.
- **대화에 첨부** — 항목을 대화에 첨부합니다.
- **대화로 이동** — 파일, 문서, 웹 페이지를 만든 대화를 엽니다.
- **원본 열기** — 스크랩이나 북마크를 가져온 원래 페이지나 대화를 엽니다.
- **삭제** — 항목을 서랍에서 지웁니다.

## 주의 사항

<Notice tone="warning">
  항목 메뉴의 **삭제**는 확인 없이 바로 지웁니다. 지운 항목은 되돌릴 수 없습니다.
</Notice>

<Notice tone="info">
  버틀러가 한 번에 전달하는 파일은 12개, 파일당 10MB까지입니다.
</Notice>
