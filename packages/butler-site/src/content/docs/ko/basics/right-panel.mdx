대화 화면의 제목 표시줄 오른쪽에는 **세션 정보**와 **파일 보기** 버튼이 있습니다. **세션 정보**는 이 대화의 요청, 하위 작업, 결과물, 예약 작업을 대화 옆에 모아 보여 줍니다. **파일 보기**는 결과물과 첨부 파일을 대화 옆에서 엽니다.

## 세션 정보 열고 닫기

<Steps>
  1. 사이드바에서 대화를 엽니다.
  2. 제목 표시줄 오른쪽의 **세션 정보** 버튼을 누릅니다.
  3. 닫으려면 같은 버튼을 다시 누릅니다.
</Steps>

- **세션 정보** 버튼은 보여 줄 항목이 하나라도 있을 때만 나타납니다.
- 답을 기다리는 요청이 있거나 허용을 기다리는 하위 작업이 있으면 버튼에 점이 표시됩니다.

## 세션 정보 항목

항목은 내용이 있을 때만 다음 순서로 나타납니다. 내용이 없는 항목은 표시되지 않습니다.

### 답을 기다리는 요청

아직 답하지 않은 허용 요청과 질문을 개수와 함께 보여 줍니다. 각 줄에 **승인** 또는 **질문**과 기다린 시간이 표시되고, 미뤄 둔 요청에는 **나중에 답하기로 함**이 붙습니다. 줄을 누르면 요청이 있는 메시지로 이동합니다.

### 하위 작업

버틀러가 맡긴 하위 작업 가운데 끝나지 않은 것을 상태와 함께 보여 줍니다. 줄을 누르면 그 하위 작업의 진행 상세가 열립니다.

### 진행 순서

버틀러가 과제를 차례로 처리할 때 남은 순서를 보여 줍니다.

### 브라우저

버틀러가 이 대화에서 연 브라우저 탭을 미리보기로 보여 줍니다. 탭이 세 개를 넘으면 **탭 N개 더 보기**로 펼치고 **접기**로 접습니다.

### 환경

이 대화가 쓰는 **작업 폴더**와 Git **브랜치**를 보여 줍니다.

### 과제

이 대화가 맡은 과제의 상세 내용을 보여 줍니다. 여기서 바로 고칠 수 있습니다.

### 컨텍스트

모델에 전달되는 컨텍스트의 사용 비율을 보여 줍니다. 누르면 막대 그래프와 **대화**, **기억·파일**, **규칙·설정**, **기본 정보**, **예약** 묶음별 사용량, 자동 압축이 일어나는 지점이 펼쳐집니다. **자세히**를 누르면 묶음 안의 항목이 보이고, **간단히**로 다시 접습니다.

### 결과물

버틀러가 이 대화에서 전달한 파일을 개수와 함께 보여 줍니다. 파일을 누르면 [파일 보기](#파일-보기)에서 열립니다. 파일로 받으려면 **저장하기**를 누릅니다.

### 첨부

내가 메시지에 첨부한 파일을 보여 줍니다. 파일을 누르면 파일 보기에서 열립니다.

### 예약 작업

이 대화를 대상으로 하는 [예약 작업](/help/scheduled-tasks/) 목록입니다. 각 항목에 제목과 실행 주기가 표시되며, 항목을 누르면 예약 작업 상세 화면이 열립니다.

## 파일 보기

결과물, 첨부 파일, 변경 파일은 대화 오른쪽의 파일 보기에서 열립니다.

- 답변의 결과물, **세션 정보**의 **결과물**과 **첨부**, 변경 파일 메뉴의 **열기**를 누르면 파일이 열립니다.
- 버틀러가 만든 편집용 문서는 문서 편집기로 열립니다.
- 파일마다 탭이 생깁니다. 파일이 두 개 이상이면 위쪽에 탭이 표시되고, 탭의 **파일 닫기**로 닫습니다.
- 제목 표시줄의 **파일 보기** 버튼은 열린 파일이 있을 때 나타납니다. 누르면 파일을 닫지 않고 파일 보기를 숨기거나 다시 보여 줍니다.
- 브라우저와 파일 보기는 같은 자리를 씁니다. 나중에 연 쪽이 앞에 표시됩니다.
- 대화와 파일 보기 사이의 경계를 끌어 대화 너비를 바꿉니다.
- 휴대폰처럼 좁은 화면에서는 파일 보기가 화면 전체를 채웁니다. **대화로 돌아가기**를 누르면 대화로 돌아갑니다.

### 파일 보기 버튼

파일 위쪽에 다음 버튼이 표시됩니다.

- **버전** — 버전이 여러 개인 파일에서 볼 버전을 고릅니다.
- **서랍에서 열기** — 버틀러가 전달한 파일에만 나타납니다. [서랍](/help/basics/library/)의 **문서**에서 이 파일을 찾아 보여 줍니다.
- **저장하기** — 파일을 내 컴퓨터에 저장합니다. 데스크톱 앱에서는 저장 창이 열립니다.
- **기본 앱으로 열기** — 데스크톱 앱에서만 나타납니다. 컴퓨터에서 이 형식을 여는 기본 앱으로 파일을 엽니다.
- **폴더에서 보기** — 기본 앱으로 열 수 없는 형식에서 **기본 앱으로 열기** 대신 나타납니다. 파일이 있는 폴더를 엽니다.
- **닫기** — 보고 있는 파일을 닫습니다.

**기본 앱으로 열기**를 쓸 수 있는 형식은 PDF, Word(`docx`), Excel(`xlsx`), PowerPoint(`pptx`), 한글(`hwp`, `hwpx`), 이미지(`png`, `jpg`, `jpeg`, `gif`, `webp`), Markdown(`md`, `markdown`), `txt`, `csv`입니다.

버틀러가 전달한 파일의 최신 버전은 버틀러가 파일을 저장한 원래 위치에서 열립니다. 그래서 다른 앱에서 고친 내용이 그 파일에 그대로 남습니다. 이전 버전이나 원래 파일이 없는 파일은 보관된 사본으로 열립니다. **폴더에서 보기**에서 원래 파일을 찾지 못하면 **원본을 찾지 못했습니다** 알림이 표시됩니다.

버틀러가 만든 웹 페이지에는 다음 버튼이 더 있습니다.

- **브라우저에서 열기** — 페이지를 브라우저에서 이 대화의 탭으로 엽니다.
- **새로고침** — 페이지를 다시 불러옵니다.

### 미리 볼 수 있는 형식

| 형식 | 표시 |
| --- | --- |
| 이미지(`png`, `jpg`, `jpeg`, `webp`, `gif`, `svg`) | 이미지 |
| PDF | 문서 화면 |
| Markdown(`md`) | 서식을 적용한 문서 |
| 텍스트와 코드 파일 | 텍스트 |
| 버틀러가 만든 HTML 페이지 | 실행된 페이지 |
| 내가 첨부한 HTML 파일 | 소스 텍스트 |

그 밖의 형식은 **앱 안에서 미리 볼 수 없는 아티팩트입니다** 문구가 표시됩니다. 데스크톱 앱에서는 **다른 앱으로 열기** 버튼이 함께 나타납니다. 다른 앱으로 열 수 없는 형식이면 버튼이 비활성화되고 **열 수 없는 형식입니다** 툴팁이 표시됩니다. 이런 파일은 **저장하기**로 받아서 엽니다.

## 주의 사항

<Notice tone="info">
  **세션 정보**는 대화 화면에서만 쓸 수 있습니다. 프로젝트 대시보드, 예약 작업, 설정 화면에서는 버튼이 나타나지 않습니다. 좁은 화면에서 파일 보기가 화면 전체를 채우는 동안에도 나타나지 않습니다.
</Notice>

<Notice tone="info">
  버틀러가 만든 HTML 페이지는 결과물 호스트에서 실행됩니다. 호스트가 지정되지 않았으면 **보안 설정에서 결과물 호스트를 지정해 주세요.** 문구가 표시됩니다.
</Notice>
