오른쪽 패널은 열려 있는 대화의 진행 상황, 컨텍스트 사용량, 결과물, 연결된 예약 작업, Worker 활동을 대화 옆에 보여 줍니다. 패널은 **요약**, **맥락**, **아티팩트**, **예약 작업**, **Worker** 탭으로 나뉩니다.

## 패널 열고 닫기

<Steps>
  1. 사이드바에서 대화를 엽니다.
  2. 제목 표시줄 오른쪽의 **오른쪽 패널 보기** 버튼을 누릅니다.
  3. 패널 위쪽 탭을 눌러 원하는 정보를 봅니다.
  4. 닫으려면 같은 자리의 **오른쪽 패널 숨기기** 버튼을 누릅니다.
</Steps>

- 대화 메시지에 붙은 결과물을 누르면 패널이 **아티팩트** 탭으로 열리고 해당 파일의 미리보기가 표시됩니다.
- 패널 왼쪽 경계를 끌어 너비를 바꿉니다. 경계에 키보드 포커스를 둔 상태에서 <Kbd keys={["←"]} label="왼쪽 화살표" />, <Kbd keys={["→"]} label="오른쪽 화살표" />로도 조절할 수 있습니다.
- 창이 좁아지면 패널이 자동으로 닫히고, 창을 다시 넓히면 이전 상태로 돌아옵니다.

## 요약

대화가 지금 어디까지 진행됐는지와 작업공간 상태를 보여 줍니다.

- **진행 상황** — 최근 요청의 진행 단계를 순서대로 보여 줍니다. 각 단계에 진행 중, 완료, 실패, 취소 상태가 표시됩니다. 기록이 없으면 **대화 진행 내역이 없습니다**가 표시됩니다.
- **브랜치 상세**
  - **게이트웨이** — 앱의 현재 처리 상태입니다.
  - **Git 브랜치** — 작업공간의 현재 브랜치입니다. Git 저장소가 아니면 **Git 작업공간이 아닙니다**로 표시됩니다.
  - **작업공간** — 이 대화가 쓰는 작업공간 종류입니다. **워크트리**, **로컬**, **프로젝트 폴더** 같은 값이 표시됩니다.
  - **변경사항** — 작업공간에 커밋하지 않은 변경이 있는지 **변경 있음** / **변경 없음**으로 표시합니다.
  - **컨텍스트** — 사용한 컨텍스트와 한도를 짧게 보여 줍니다.
- **스킬** — 이 대화에서 사용한 스킬 목록입니다.

## 맥락

모델에 전달되는 컨텍스트의 사용량을 자세히 보여 줍니다.

- **컨텍스트 창** — 한도 대비 사용 비율, 사용한 토큰, 한도를 표시합니다.
- **작업 컨텍스트** — 작업 컨텍스트 사용량과 자동 압축 전까지 쓸 수 있는 양, 자동 압축이 일어나는 지점을 표시합니다. 해당 정보가 있는 대화에서만 나타납니다.
- 막대 차트와 항목 목록 — 컨텍스트를 차지하는 항목별 토큰 수와 비율입니다. 많이 쓰는 항목부터 표시됩니다.

정보를 받지 못하면 **컨텍스트를 확인할 수 없습니다**가 표시됩니다.

## 아티팩트

대화에서 만들어지거나 전달된 파일을 모아 보여 줍니다. 각 항목에는 종류, 크기, 생성 시점이 표시됩니다.

<Steps>
  1. 목록에서 아티팩트를 누르면 패널 안에서 미리 봅니다.
  2. 파일로 받으려면 **저장하기**를 누릅니다.
  3. 목록으로 돌아가려면 **아티팩트 목록**을 누릅니다.
</Steps>

앱 안에서 미리 볼 수 있는 형식은 이미지, PDF, Markdown, 텍스트와 코드 파일입니다. 그 밖의 형식은 **앱 안에서 미리 볼 수 없는 아티팩트입니다**로 표시되며, 저장해서 열 수 있습니다.

## 예약 작업

이 대화를 대상으로 하는 [예약 작업](/docs/scheduled-tasks/) 목록입니다. 각 항목에 제목과 실행 간격이 표시되며, 항목을 누르면 예약 작업 상세 화면이 열립니다. 예약 작업이 없으면 **이 세션을 대상으로 하는 예약 작업이 없습니다**가 표시됩니다.

## Worker

이 대화에서 Butler가 맡긴 Worker의 활동을 보여 줍니다. 하위 Worker는 상위 Worker 아래에 들여 쓰여 표시됩니다.

- **상세** — Worker가 거친 작업 단계와 사용한 도구를 펼칩니다. **닫기**로 접습니다.
- **재개 요청**, **취소 요청** — Worker가 지원하는 경우에만 나타나며, 해당 Worker에 재개나 취소를 요청합니다.

Worker 기록이 없으면 **Worker 내역이 없습니다**가 표시됩니다.

## 주의 사항

<Notice tone="info">
  오른쪽 패널은 저장된 대화를 열었을 때만 쓸 수 있습니다. 첫 메시지를 보내기 전의 새 대화, 프로젝트 대시보드, 예약 작업, 설정 화면에서는 **오른쪽 패널 보기** 버튼이 나타나지 않습니다.
</Notice>
