버틀러에는 앱 안에서 쓰는 브라우저가 있습니다. 직접 웹을 볼 수 있고, 버틀러도 대화마다 자기 탭을 열어 페이지를 읽고 조작합니다.

## 브라우저 열기

- 사이드바의 **브라우저**를 누르면 모든 탭을 모아 보는 브라우저 화면이 열립니다.
- 대화 화면의 제목 표시줄에서 지구본 버튼(**브라우저 열기**)을 누르면 그 대화의 탭이 대화 옆에 열립니다. 다시 누르면(**브라우저 닫기**) 닫힙니다.

버틀러가 대화의 탭을 쓰는 동안에는 지구본 버튼이 빛나고, 버튼 이름이 상태에 따라 바뀝니다.

- **브라우저 보기 · 버틀러가 사용 중**
- **브라우저 보기 · 직접 확인 필요**
- **브라우저 보기 · 오류**

## 탭

탭은 묶음으로 나뉩니다. 직접 연 탭은 **내 탭**에, 버틀러가 대화에서 연 탭은 그 대화의 묶음에 들어갑니다.

- **새 탭**으로 탭을 열고 **탭 닫기**로 닫습니다.
- 대화 옆에 연 브라우저에서 **내 탭 가져오기**를 누르면 **내 탭**의 탭을 이 대화로 옮깁니다.
- 사이드바의 **브라우저** 화면에서 **대화로 가져가기**를 누르면 지금 탭을 고른 대화나 **새 대화**로 옮깁니다.
- 탭을 대화로 끌어다 놓아도 옮길 수 있습니다.

주소 표시줄에는 **뒤로**, **앞으로**, **새로고침**과 **검색 또는 URL 입력** 칸이 있습니다. 오른쪽에는 **북마크 추가**, **요소 선택**, **북마크**, **더 보기** 버튼이 있습니다. **요소 선택**으로 고른 페이지 일부는 대화에 끌어다 놓아 첨부하거나 [서랍](/help/basics/library/)에 저장합니다.

## 버틀러가 일하는 모습 보기

버틀러가 탭을 다루는 동안 탭 위에 **버틀러가 조작 중** 띠가 표시됩니다. 띠에는 다음 버튼이 있습니다.

- **직접 조작** — 탭을 넘겨받아 직접 클릭하고 입력합니다. 띠가 **직접 조작 중**으로 바뀝니다.
- **버틀러에게 돌려주기** — 직접 조작을 마치고 탭을 버틀러에게 돌려줍니다.
- **작업 중지** — 버틀러가 하던 작업을 멈춥니다.

버틀러가 허용을 기다리면 띠에 **승인 대기**가, 직접 해야 하는 단계를 기다리면 **버틀러가 기다리는 중**이 표시됩니다. 버틀러가 넘겨준 탭에는 **탭을 떠나면 버틀러에게 돌아감**이 표시되고, 다른 탭으로 옮기면 탭이 버틀러에게 돌아갑니다.

페이지가 팝업을 열려고 하면 **팝업 차단됨**이 표시됩니다. 열어도 되는 팝업이면 **허용**을 누릅니다.

## 로그인

직접 연 탭은 내 로그인 상태를 그대로 씁니다. 버틀러가 연 탭은 로그아웃 상태로 시작합니다.

버틀러가 내 로그인 상태로 사이트를 쓰려면 사이트마다 허용 카드로 한 번 묻습니다.

- **이 대화에서 허용** — 이 대화에서 그 사이트를 로그인 상태로 씁니다.
- **이 사이트는 항상 허용** — 버튼 옆 메뉴에서 고릅니다. 모든 대화에서 그 사이트를 로그인 상태로 씁니다. **설정 → 브라우저 → 로그인**에서 그 사이트의 **모든 대화에서 사용**을 끄면 해제됩니다.
- **거절** — 로그인 상태로 쓰지 않습니다.

로그인 상태로 쓰는 대화 탭에는 **더 보기** 옆에 **로그인 사용**이 표시됩니다.

### 저장한 로그인 입력

사이트에 로그인해야 할 때 **설정 → 브라우저**의 **로그인**에 그 사이트의 로그인이 저장되어 있으면 버틀러가 입력합니다. 아이디와 비밀번호는 모델에 전달되지 않습니다. 로그인마다 정한 **버틀러 로그인** 값에 따라 동작이 다릅니다.

| **버틀러 로그인** | 동작 |
| --- | --- |
| **항상** | 묻지 않고 입력합니다. |
| **묻기** | 입력하기 전에 허용 카드로 묻습니다. |
| **안 함** | 입력하지 않습니다. |

### 직접 해야 하는 로그인 단계

2단계 인증, 패스키, 자동입력 방지, 보안 키패드처럼 버틀러가 할 수 없는 단계가 나오면 버틀러가 탭을 넘겨줍니다.

<Steps>
  1. 탭 위에 **로그인 확인 필요**와 함께 **2단계 인증**, **패스키**, **자동입력 방지**, **보안 키패드** 중 하나가 표시됩니다. 대화에는 **탭에서 마친 뒤 버틀러에게 돌려주세요** 카드가 나타납니다.
  2. 카드에서 **열어서 확인**을 눌러 탭을 엽니다.
  3. 탭에서 그 단계를 마칩니다.
  4. **버틀러에게 돌려주기**를 누릅니다. 버틀러가 이어서 진행합니다.
</Steps>

그만두려면 카드나 탭 위의 **작업 중지**를 누릅니다.

## 결제

결제에 카드가 필요하면 버틀러가 **설정 → 브라우저**의 **결제 수단**에 저장한 카드를 입력합니다. 버틀러에게는 카드 별칭과 번호 끝 네 자리만 보입니다. **내 정보**에 저장한 이름, 연락처, 주소도 같은 방식으로 입력합니다.

- 카드를 입력하기 전에 사이트와 금액을 보여 주는 허용 카드가 나타납니다. 카드의 **확인 없이 입력할 사이트**에 둔 사이트에서는 묻지 않고 입력합니다.
- 결제를 마치기 전에도 묻습니다. **설정 → 브라우저**의 **확인 없이 결제**에 둔 사이트에서는 묻지 않습니다.
- 보안 키패드나 카드사 인증처럼 직접 해야 하는 단계가 나오면 탭 위에 **결제 확인 필요**가 표시됩니다. 탭에서 그 단계를 마치고 **버틀러에게 돌려주기**를 누릅니다.

## 방문 기록

<Steps>
  1. 브라우저의 **더 보기**에서 **방문 기록**을 고릅니다. **설정 → 브라우저**의 **방문한 페이지**에서 **보기**를 눌러도 열립니다.
  2. **방문 기록 검색**에 검색어를 입력합니다. **버틀러가 방문**을 켜면 버틀러가 방문한 페이지만 표시됩니다.
</Steps>

기록을 지우려면 **방문 기록 지우기**를 누르고 **지난 1시간**, **오늘**, **지난 7일**, **전체** 중에서 기간을 고른 뒤 **삭제**를 누릅니다. **버틀러가 방문**을 켜면 버틀러가 방문한 기록만 지웁니다.

## 사이트 데이터 지우기

<Steps>
  1. **설정 → 브라우저**를 엽니다.
  2. **사이트 데이터**의 **쿠키 및 캐시**에서 **지우기**를 누릅니다.
  3. 확인 창에서 **지우기**를 누릅니다.
</Steps>

모든 사이트에서 로그아웃되고 캐시된 이미지와 파일이 지워집니다. 저장한 로그인, 결제 수단, 방문 기록, 북마크는 남습니다.

## 주의 사항

<Notice tone="info">
  브라우저는 데스크톱 앱에만 있습니다. 다른 컴퓨터의 웹 브라우저로 버틀러에 접속하면 사이드바의 **브라우저**와 지구본 버튼이 나타나지 않습니다.
</Notice>

<Notice tone="info">
  저장한 로그인, 결제 수단, 내 정보는 시스템 암호 저장소가 있어야 쓸 수 있습니다. 저장소를 켜는 방법은 [설정 레퍼런스](/help/settings/#브라우저)를 참고합니다.
</Notice>
