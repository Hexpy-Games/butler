개인화는 Butler의 이름과 말투, 답변 언어, 대화에서 사용자에 대해 학습할 범위를 정하는 설정입니다. **설정 → 개인화**에서 바꿉니다.

## 설정 바꾸기

<Steps>
  1. 사이드바에서 **설정**을 열고 **개인화**를 선택합니다.
  2. **프로필**, **응답 스타일**, **학습** 섹션의 항목을 바꿉니다.
  3. 화면 아래의 **적용**을 누릅니다.
</Steps>

개인화 설정은 **적용**을 눌러야 저장됩니다.

## 프로필

- **버틀러 닉네임** — Butler의 이름입니다. 예: Butler, 알프레드
- **내 이름** — 사용자의 이름입니다.
- **나를 부를 호칭** — Butler가 사용자를 부를 때 쓸 호칭입니다. 예: 선생님, 대표님

## 응답 스타일

- **답변 언어** — Butler가 채팅에서 최종 답변과 진행 상태를 말할 때 쓸 언어입니다. **영어**와 **한국어** 중에서 고릅니다.
- **페르소나 프리셋** — Butler, Guardian, Demon Butler, Wolf Butler, Neko Servant, Think Tank, Operator, Archivist, Dry Wit 중에서 고릅니다. 프리셋을 고르면 아래 **페르소나** 초안만 바뀌고, **적용**을 누르기 전에는 저장되지 않습니다.
- **페르소나** — Butler가 자신을 표현하고 사용자와 협업하는 방식입니다. 내용을 직접 고치면 프리셋이 **직접 편집**으로 바뀝니다.
- **EOL** — Butler Operating Ethos입니다. 장기 선호, 경계, 오래 유지할 운영 메모를 적습니다. Butler가 답변할 때 참고하는 설정에 함께 들어갑니다.

페르소나와 EOL은 각각 32,000자까지 저장합니다.

## 학습

**사용자 정보 분석**은 Butler가 로컬 대화에서 사용자에 대해 학습하는 범위입니다. 기본값은 **끄기**입니다.

- **끄기** — 사용자 정보를 분석하지 않습니다. 기능상 필요한 현재 설정만 사용합니다.
- **기본** — 말투, 설명 방식, 작업 방식 선호를 맞춤 응답에 사용합니다.
- **깊게** — 최근 관심사, 의미 있는 맥락, 가치 판단까지 맞춤 응답에 사용합니다.

**기본**이나 **깊게**를 고르고 **적용**하면 분석에 동의한 것으로 기록됩니다.

- **사용자 정보 분석 모델** — 개인화에 필요한 정보를 읽어낼 때 쓸 모델입니다. **모델 기본값**을 고르면 현재 버틀러 기본 모델 설정을 그대로 따릅니다. 모델 등록은 [클라우드 모델](/docs/models/cloud/)을 참고합니다.
- **추론** — 분석 모델의 추론 강도입니다.

분석이 언제 어떻게 끝났는지는 [**설정 → 시스템 이벤트**](/docs/settings/#시스템-이벤트)의 **사용자 정보 분석** 항목에서 확인합니다.

## 외부 AI 기억 가져오기

다른 AI 서비스가 저장한 기억을 Butler 프로필로 옮깁니다.

<Steps>
  1. **사용자 정보 분석**을 **기본** 또는 **깊게**로 두고 **적용**합니다.
  2. **가져오기** 섹션의 **외부 AI 기억 가져오기**에서 **가져오기**를 누릅니다.
  3. **가져오기 프롬프트**의 **프롬프트 복사**를 누르고, 복사한 프롬프트를 다른 AI 서비스에 보냅니다.
  4. 그 서비스가 돌려준 내용을 **가져온 프로필 내용**에 붙여넣습니다.
  5. **프로필 가져오기**를 누릅니다. 이 화면에서 바로 처리되고 결과가 표시됩니다.
</Steps>

- 반영한 정보가 있으면 반영한 개수가 표시되고, 다음 답변부터 사용됩니다.
- 아직 확실하지 않은 정보는 저장만 해 두었다가 충분히 확실해지면 반영합니다.
- 가져오기 프롬프트는 앱 언어에 맞춰 표시됩니다.

## Butler가 저장하는 정보

개인화 정보는 데이터 폴더(기본값 `~/.butler`)에 저장됩니다.

- 프로필: `~/.butler/personalization/profile.json`
- 페르소나: `~/.butler/personas/active.md`
- EOL: `~/.butler/eol.md`
- 학습한 사용자 정보: `~/.butler/cognition/profile/profile.sqlite`

학습한 사용자 정보는 **사용자 정보 분석**을 켠 경우에만 쌓입니다.

페르소나나 EOL을 바꾸면 이전 내용이 `~/.butler/personalization/backups/`에 백업됩니다. 항목마다 최근 20개까지 보관합니다.

Butler는 실행 중일 때 하루 한 번, 이 Mac의 시간대 기준 오전 4시 이후에 정기 기억 정리를 실행합니다. 결과는 **설정 → 시스템 이벤트**에서 확인합니다.

## 학습한 정보 지우기

<Steps>
  1. **설정 → 개인화** 화면 아래의 **프로필 데이터 삭제**를 누릅니다. 버튼이 **삭제 예정**으로 바뀝니다.
  2. **적용**을 누릅니다.
</Steps>

- 분석으로 모은 후보, 저장된 프로필, 답변에 쓰던 요약이 삭제됩니다.
- **프로필** 섹션의 입력값, 페르소나, EOL은 지워지지 않습니다. 필요하면 칸을 비우고 **적용**합니다.
- **사용자 정보 분석**을 **끄기**로 바꾸면 답변에 쓰던 요약은 지워지지만, 이미 모은 후보와 저장된 프로필은 남습니다. 모두 지우려면 **프로필 데이터 삭제**도 함께 실행합니다.

## 주의 사항

<Notice tone="info" title="학습한 내용은 앱에서 항목별로 볼 수 없습니다">
  학습한 사용자 정보는 앱 화면에 원문으로 표시되지 않습니다. 지울 때는 **프로필 데이터 삭제**로 한꺼번에 지웁니다.
</Notice>

<Notice tone="warning" title="분석 모델로 대화 내용이 전송됩니다">
  사용자 정보 분석과 기억 가져오기는 **사용자 정보 분석 모델**을 호출합니다. 클라우드 모델을 고르면 분석할 내용이 해당 제공자에게 전송됩니다.
</Notice>

<Notice tone="info">
  **사용자 정보 분석**이 꺼져 있으면 기억을 가져와도 프로필에 반영하지 않습니다.
</Notice>

진단 정보 수집은 [**설정 → 개인정보**](/docs/settings/#개인정보)의 **진단**에서 켜고 끕니다.
