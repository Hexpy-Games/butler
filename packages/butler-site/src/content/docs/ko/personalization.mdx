개인화는 버틀러의 이름과 말투, 답변 언어, 대화하면서 사용자를 알아가는 범위를 정하는 설정입니다. **설정 → 개인화**에서 바꿉니다.

## 설정 바꾸기

<Steps>
  1. 사이드바에서 **설정**을 열고 **개인화**를 선택합니다.
  2. **프로필**, **응답 스타일**, **알아가기** 섹션의 항목을 바꿉니다.
  3. 화면 아래의 **적용**을 누릅니다.
</Steps>

개인화 설정은 **적용**을 눌러야 저장됩니다.

## 프로필

- **버틀러 닉네임** — 버틀러의 이름입니다. 예: 버틀러, 알프레드
- **내 이름** — 사용자의 이름입니다.
- **나를 부를 호칭** — 버틀러가 사용자를 부를 때 쓸 호칭입니다. 예: 선생님, 대표님

## 응답 스타일

- **답변 언어** — 버틀러가 채팅에서 최종 답변과 진행 상태를 말할 때 쓸 언어입니다. **영어**와 **한국어** 중에서 고릅니다.
- **페르소나 프리셋** — Butler, Guardian, Demon Butler, Wolf Butler, Neko Servant, Think Tank, Operator, Archivist, Dry Wit 중에서 고릅니다. 프리셋을 고르면 아래 **페르소나** 초안만 바뀌고, **적용**을 누르기 전에는 저장되지 않습니다.
- **페르소나** — 버틀러가 자신을 표현하고 사용자와 협업하는 방식입니다. 내용을 직접 고치면 프리셋이 **직접 편집**으로 바뀝니다.
- **얼** — Butler Operating Ethos입니다. 장기 선호, 경계, 오래 유지할 운영 메모를 적습니다. 버틀러가 답변할 때 참고하는 설정에 함께 들어갑니다.

페르소나와 얼은 각각 32,000자까지 저장합니다.

## 알아가기

**범위**는 버틀러가 로컬 대화에서 사용자를 알아가는 정도입니다. 기본값은 **끄기**입니다.

- **끄기** — 사용자를 알아가지 않습니다. 기능상 필요한 현재 설정만 사용합니다.
- **기본** — 말투, 설명 방식, 작업 방식 선호를 맞춤 응답에 사용합니다.
- **깊게** — 최근 관심사, 의미 있는 맥락, 가치 판단까지 맞춤 응답에 사용합니다.

**기본**이나 **깊게**를 고르고 **적용**하면 알아가기에 동의한 것으로 기록됩니다.

- **알아가기 모델** — 개인화에 필요한 정보를 읽어낼 때 쓸 모델입니다. **모델 기본값**을 고르면 현재 버틀러 기본 모델 설정을 그대로 따릅니다. 모델 등록은 [클라우드 모델](/help/models/cloud/)을 참고합니다.
- **추론** — 알아가기 모델의 추론 강도입니다.
- **기억** — **열기**를 누르면 **설정 → 기억**이 열립니다.

알아가기가 언제 어떻게 끝났는지는 [**설정 → 시스템 이벤트**](/help/settings/#시스템-이벤트)의 **알아가기** 항목에서 확인합니다.

## 대화 기억

새로 설치한 버틀러에서도 기억할 내용을 말하고 나중에 다시 물어볼 수 있습니다. 명시적으로 기억해 달라고 한 내용은 알아가기가 꺼져 있어도 저장합니다. 알아가기는 대화 기억과 별도의 동의 설정입니다.

버틀러가 기억하는 내용은 [**설정 → 기억**](/help/settings/#기억)에서 종류별로 관리합니다.

- **지침** — 채팅에서 정한 규칙입니다. 채팅에서 추가하고 고치며, 이 화면에서 하나씩 지울 수 있습니다. 적용 범위는 **모든 채팅**, 프로젝트, **이 채팅에서만** 중 하나이고, 기한이 있으면 `3시간 후 만료`처럼 표시됩니다.
- **버틀러가 알아챈 것** — 대화에서 버틀러가 알아챈 습관입니다. 지우면 다시 제안하지 않습니다.
- **먼저 말 걸기** — 기억 정리 때 버틀러가 먼저 제안하는 정도입니다. **끄기**, **가끔**, **자주** 중에서 고릅니다.
- **조용한 시간** — 이 시간에는 버틀러가 먼저 말을 걸지 않습니다.
- **대화 기억** — 대화에서 버틀러가 스스로 기억한 내용입니다. 프로젝트 채팅도 포함합니다.
- **기억 정리** — 대화에서 쌓인 기억을 합치고 다듬는 작업의 설정입니다.
- **프로필** — 알아가기로 알게 된 사용자 정보입니다. 항목과 후보 수가 표시됩니다.
- **프로젝트 기억** — 프로젝트 하나에 대해 버틀러가 기억하는 내용입니다.

대화 기록은 원본으로 남고, 기억 정리는 백그라운드에서 진행합니다. 기억 모델을 받는 동안에는 기억 검색 준비가 늦어질 수 있습니다. 준비 상태는 **설정 → 기억**의 **기억 모델**에서 확인합니다. 오래된 결정은 출처와 함께 찾아 달라고 요청하고 현재 상황과 맞는지 확인합니다.

## 기억 가져오기

다른 AI 서비스가 저장한 기억을 버틀러 프로필로 옮깁니다.

<Steps>
  1. **범위**를 **기본** 또는 **깊게**로 두고 **적용**합니다.
  2. **다른 AI에서 가져오기** 섹션의 **기억 가져오기**에서 **가져오기**를 누릅니다.
  3. **가져오기 프롬프트**의 **프롬프트 복사**를 누르고, 복사한 프롬프트를 다른 AI 서비스에 보냅니다.
  4. 그 서비스가 돌려준 내용을 **가져온 프로필 내용**에 붙여넣습니다.
  5. **프로필 가져오기**를 누릅니다. 이 화면에서 바로 처리되고 결과가 표시됩니다.
</Steps>

- 반영한 정보가 있으면 반영한 개수가 표시되고, 다음 답변부터 사용됩니다.
- 아직 확실하지 않은 정보는 저장만 해 두었다가 충분히 확실해지면 반영합니다.
- 가져오기 프롬프트는 앱 언어에 맞춰 표시됩니다.

## 버틀러가 저장하는 정보

개인화 정보는 데이터 폴더(기본값 `~/.butler`)에 저장됩니다.

- 프로필: `~/.butler/personalization/profile.json`
- 페르소나: `~/.butler/personas/active.md`
- 얼: `~/.butler/eol.md`
- 알아낸 사용자 정보: `~/.butler/cognition/profile/profile.sqlite`

알아낸 사용자 정보는 알아가기를 켠 경우에만 쌓입니다.

페르소나나 얼을 바꾸면 이전 내용이 `~/.butler/personalization/backups/`에 백업됩니다. 항목마다 최근 20개까지 보관합니다.

버틀러는 실행 중일 때 하루 한 번, 이 컴퓨터의 시간대 기준 오전 4시 이후에 정기 기억 정리를 실행합니다. 결과는 **설정 → 시스템 이벤트**에서 확인합니다.

## 프로필 지우기

<Steps>
  1. **설정 → 기억**을 엽니다.
  2. **프로필** 섹션의 **프로필 지우기**에서 **초기화**를 누릅니다.
  3. **프로필을 초기화할까요?** 확인 창에서 지워질 항목과 남는 항목을 확인하고 **초기화**를 누릅니다.
</Steps>

- 알아낸 항목과 후보가 삭제됩니다. 되돌릴 수 없습니다.
- 채팅, 지침, 대화 기억, 프로젝트 기억, **프로필** 섹션의 입력값, 페르소나, 얼은 지워지지 않습니다.
- 알아가기가 켜져 있으면 새 대화부터 다시 알아갑니다.
- **범위**를 **끄기**로 바꾸면 답변에 쓰던 요약은 지워지지만, 이미 모은 후보와 저장된 프로필은 남습니다. 모두 지우려면 **프로필 지우기**도 함께 실행합니다.

## 주의 사항

<Notice tone="info" title="알아낸 항목은 앱에서 하나씩 볼 수 없습니다">
  **설정 → 기억**의 **프로필**에는 항목과 후보의 수만 표시됩니다. 지울 때는 **프로필 지우기**로 한꺼번에 지웁니다.
</Notice>

<Notice tone="warning" title="알아가기 모델로 대화 내용이 전송됩니다">
  알아가기와 기억 가져오기는 **알아가기 모델**을 호출합니다. 클라우드 모델을 고르면 분석할 내용이 해당 제공자에게 전송됩니다.
</Notice>

<Notice tone="info">
  **범위**가 **끄기**이면 기억을 가져와도 프로필에 반영하지 않습니다.
</Notice>

문제 보고에 로그를 첨부하려면 [**설정 → 정보**](/help/settings/#정보)의 **진단 내보내기**를 씁니다.
