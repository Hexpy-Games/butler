예비 모델은 현재 모델이 일시적으로 응답하지 않을 때 같은 작업을 이어받는 모델입니다. 등록한 모델 중에서 최대 5개까지 골라 시도할 순서를 정합니다.

## 설정하기

<Steps>
  1. 예비로 쓸 모델을 먼저 **모델 관리**에서 등록합니다([클라우드 모델](/help/models/cloud/#모델-등록하기), [Custom 모델](/help/models/custom/#연결하기)). 예비 모델로는 등록한 모델만 고를 수 있습니다.
  2. 사이드바에서 **설정**을 열고 **모델**을 선택합니다.
  3. **예비 모델** 섹션에서 **편집**을 누릅니다.
  4. **예비 모델 사용**을 켭니다.
  5. **예비 모델 추가**를 누르고 **예비 모델 선택** 창에서 모델을 고릅니다. 검색창이나 제공자 필터로 목록을 좁힐 수 있습니다.
  6. 필요한 만큼 모델을 더 추가합니다.
  7. **완료**를 누르면 편집 항목이 접힙니다.
</Steps>

변경 내용은 바로 저장되며, 새 작업부터 적용됩니다.

**예비 모델** 섹션에는 설정 상태가 한 줄로 표시됩니다.

- 예비 모델을 쓰면 등록한 모델이 시도하는 순서대로 표시됩니다.
- **예비 모델 사용**이 꺼져 있으면 **사용 안 함**이 표시됩니다.
- 켜져 있지만 고른 모델이 없으면 **등록된 예비 모델이 없습니다.** 문구가 표시됩니다.

### 순서 바꾸기와 빼기

- 카드 왼쪽의 손잡이를 끌어 순서를 바꿉니다. 위에 있는 모델부터 차례로 시도합니다.
- 카드 오른쪽의 X 버튼을 누르면 목록에서 뺍니다.

## 예비 모델로 넘어가는 경우

모델 요청이 실패하면 Butler는 오류 종류에 따라 다르게 처리합니다.

| 오류 | 처리 |
| --- | --- |
| 제공자 사용 한도 소진, 모델을 찾을 수 없음, 모델 지원 종료, 모델을 쓸 수 없음, 지원하지 않는 모델 | 바로 다음 모델로 넘어갑니다. |
| 네트워크 오류, 요청 한도 초과(HTTP 429), 시간 초과(HTTP 408), 서버 오류(HTTP 5xx), 응답 스트림 중단, 빈 응답, 프로토콜 오류 | 같은 모델로 정해진 횟수만큼 다시 시도하고, 그래도 실패하면 다음 모델로 넘어갑니다. |
| 인증 오류, 권한 오류, 잘못된 요청, 컨텍스트 한도 초과, 안전 정책에 따른 거부 | 넘어가지 않고 오류를 표시합니다. |

마지막 예비 모델까지 실패하면 오류를 표시합니다.

## 동작 방식

- 한 번 예비 모델로 넘어가면 그 요청의 나머지 처리는 예비 모델이 이어 갑니다. 다음 요청은 다시 현재 모델부터 시작합니다.
- 예비 모델이 현재 추론 강도를 지원하면 같은 강도를, 지원하지 않으면 그 모델의 기본 추론 강도를 씁니다.
- 현재 모델과 같은 모델(같은 제공자의 같은 모델 ID)은 예비 모델 목록에 나타나지 않습니다.
- **모델 관리**에서 삭제한 모델은 예비 모델 목록에서도 빠집니다.
- 사용 한도 소진이나 제공자 장애에 대비하려면 다른 제공자의 모델을 예비 모델로 둡니다.

### 대화 기억 정리 모델

**기억 정리** 섹션의 **대화 기억 정리 모델**과 **추론**은 예비 모델과 별개입니다. 대화 기억을 정리할 때 쓸 모델을 정하며, **모델 기본값**을 고르면 현재 버틀러 기본 모델 설정을 그대로 따릅니다.

**기억 정리** 섹션은 **설정 → 모델**의 **고급**에서 **기억 정리 모델과 Worker 프로필**을 누르면 나타납니다.

## 주의 사항

<Notice tone="warning" title="이미지가 포함된 요청은 넘어가지 않습니다">
  이미지를 첨부한 요청은 예비 모델로 넘어가지 않고 오류를 표시합니다.
</Notice>

<Notice tone="info">
  **예비 모델 사용**이 꺼져 있으면 목록에 모델이 있어도 예비 모델을 쓰지 않습니다. 이때도 일시적인 오류는 같은 모델로 다시 시도합니다.
</Notice>
