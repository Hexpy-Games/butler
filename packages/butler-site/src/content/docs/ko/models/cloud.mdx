클라우드 모델은 OpenAI, Anthropic 같은 제공자가 호스팅하는 모델입니다. **모델 관리**에서 제공자와 모델을 고르고 인증을 연결해 등록한 뒤, 버틀러 모델로 선택해 씁니다.

## 지원하는 제공자

| 제공자 | 인증 방식 |
| --- | --- |
| **OpenAI** | API 키 또는 OAuth(OpenAI 계정 로그인) |
| **Anthropic** | API 키 |
| **Google** | API 키 |
| **xAI / Grok** | API 키 |
| **Qwen Cloud** | API 키 |
| **Moonshot / Kimi** | API 키 |
| **Z.AI Coding Plan** | API 키 |
| **Z.AI API** | API 키 |
| **OpenCode Go** | API 키 |

제공자별 모델 목록은 Butler에 포함된 모델 카탈로그에서 가져오며, 현재 실행 가능한 모델만 표시합니다. 목록에 없는 모델이나 직접 운영하는 서버는 [Custom 모델](/docs/models/custom/)로 연결합니다.

## 모델 등록하기

<Tabs
  label="인증 방식"
  items={[
    { value: "api-key", label: "API 키" },
    { value: "oauth", label: "OAuth (OpenAI)" },
  ]}
>
  <TabPanel value="api-key">
    <Steps>
      1. 사이드바에서 **설정**을 열고 **모델**을 선택합니다.
      2. **버틀러 모델** 섹션에서 **모델 관리**를 누릅니다.
      3. **모델 추가**를 누릅니다.
      4. **제공자**와 **모델**을 고릅니다. OpenAI라면 **인증 방식**을 **API 키**로 둡니다.
      5. **저장된 인증**에서 **새로 작성**을 고르고 **API 키**를 입력합니다. **인증 이름**은 여러 키를 구분할 때 쓰며 비워 두어도 됩니다.
      6. **추가**를 누릅니다. 등록이 끝나면 **등록된 모델** 목록으로 돌아갑니다.
    </Steps>

    같은 제공자의 키를 이미 저장했다면 **저장된 인증**에서 그 키를 고르면 됩니다. 키를 다시 입력하지 않아도 됩니다.
  </TabPanel>
  <TabPanel value="oauth">
    <Steps>
      1. 사이드바에서 **설정**을 열고 **모델**을 선택합니다.
      2. **버틀러 모델** 섹션에서 **모델 관리**를 누르고 **모델 추가**를 누릅니다.
      3. **제공자**를 **OpenAI**로 두고 **모델**을 고릅니다.
      4. **인증 방식**을 **OAuth**로 바꿉니다. 브라우저에 OpenAI 로그인 페이지가 열립니다.
      5. 브라우저에서 로그인을 마치고 Butler로 돌아옵니다. Butler가 인증 완료를 확인하면 모델을 자동으로 등록합니다.
    </Steps>

    이미 로그인한 적이 있으면 **OAuth 인증 완료**가 표시되고 브라우저는 열리지 않습니다. 이때는 **추가**를 누르면 등록됩니다.

    - 브라우저가 열리지 않으면 **OAuth 링크** 아래의 **브라우저에서 열기**를 누르거나, **링크 복사**로 주소를 복사해 직접 엽니다.
    - 로그인을 마쳤는데 화면이 그대로면 **인증 완료 확인**을 누릅니다.
    - 인증에 실패했거나 처음부터 다시 하려면 **다시 인증**을 누릅니다.
  </TabPanel>
</Tabs>

[첫 실행](/docs/getting-started/first-run/#모델) 설정의 모델 단계에서도 같은 화면으로 모델을 등록할 수 있습니다.

## 기본 모델 고르기

<Steps>
  1. **설정 → 모델**의 **버틀러 모델** 섹션에서 **모델** 목록을 엽니다.
  2. 사용할 모델을 고릅니다. 변경 내용은 바로 저장됩니다.
</Steps>

- 목록에는 제공자, 모델 이름, 컨텍스트 크기가 함께 표시됩니다. 모델을 하나 이상 등록하면 등록한 모델만 표시됩니다.
- **추론**은 선택한 모델이 지원하는 추론 강도 중에서 고릅니다. 모델을 바꿀 때 지금 추론 강도를 새 모델이 지원하지 않으면 그 모델의 기본값으로 바뀝니다.
- **컨텍스트 한도**는 Butler가 실제로 쓰는 컨텍스트 예산입니다. 1,000 토큰부터 모델 최대값까지 지정할 수 있고, 모델을 바꾸면 새 모델의 최대값을 넘지 않도록 조정됩니다.
- 대화 입력창의 모델 메뉴에도 같은 모델 목록이 표시됩니다.

## 등록한 모델 관리

**모델 관리**의 **등록된 모델** 목록에는 모델마다 `API 키 · sk-...x`처럼 인증 방식과 가린 키가 표시됩니다.

- **편집** — 인증 방식, 저장된 인증, API 기본 URL을 바꾸고 **저장**을 누릅니다.
- **삭제** — 확인 창에서 **삭제**를 누르면 선택 가능한 모델 목록에서 빠집니다.

### API 기본 URL

다음 제공자는 **API 기본 URL** 입력란이 함께 표시되고 기본 주소가 미리 채워져 있습니다. 기본 주소와 다른 엔드포인트를 써야 할 때만 바꿉니다. 주소는 `http` 또는 `https` URL이어야 합니다.

| 제공자 | 기본 주소 |
| --- | --- |
| xAI / Grok | `https://api.x.ai/v1` |
| Qwen Cloud | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1` |
| Moonshot / Kimi | `https://api.moonshot.ai/v1` |
| Z.AI Coding Plan | `https://api.z.ai/api/coding/paas/v4` |
| Z.AI API | `https://api.z.ai/api/paas/v4` |
| OpenCode Go | `https://opencode.ai/zen/go/v1` |

## 인증 정보 저장 위치

인증 정보는 데이터 폴더(기본값 `~/.butler`)에 저장됩니다. `BUTLER_DATA` 환경 변수로 데이터 폴더를 바꿨다면 그 폴더를 기준으로 합니다.

- API 키: `~/.butler/auth/model-provider-credentials.json`
- OpenAI OAuth 로그인 정보: `~/.butler/auth/openai-codex.json`
- 등록한 모델 목록: `~/.butler/butler.config.json`

OpenAI OAuth 로그인 정보는 만료가 가까워지면 Butler가 자동으로 갱신합니다.

앱 화면에는 키 전체를 표시하지 않고 앞 세 글자와 마지막 글자만 보여 줍니다.

## 주의 사항

<Notice tone="warning" title="키는 암호화되지 않은 파일에 저장됩니다">
  API 키는 데이터 폴더의 JSON 파일에 평문으로 저장됩니다. 데이터 폴더를 다른 사람과 공유하거나 백업하면 키도 함께 복사됩니다.
</Notice>

<Notice tone="info">
  등록한 모델을 삭제해도 저장한 API 키는 지워지지 않습니다. 같은 제공자의 모델을 다시 추가할 때 **저장된 인증**에서 고를 수 있습니다. 앱에는 저장한 키를 지우는 메뉴가 없습니다.
</Notice>

<Notice tone="info">
  OAuth는 OpenAI에서만 쓸 수 있습니다. 다른 제공자는 API 키로 연결합니다.
</Notice>
