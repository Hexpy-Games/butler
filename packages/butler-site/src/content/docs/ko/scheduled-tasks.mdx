예약 작업은 정해진 간격마다, 또는 매일·평일·매주 정한 시간에 지정한 대화에 프롬프트를 보냅니다. 보낸 프롬프트는 그 대화에 메시지로 들어가고, Butler는 같은 대화에서 답합니다.

## 예약 작업 화면 열기

- 사이드바에서 **스페이스** 제목 옆 메뉴(⋯)를 열고 **예약 작업**을 선택합니다.
- [명령 팔레트](/help/basics/command-palette/)(<span data-mod-key><Kbd keys={["⌘", "K"]} label="Command K" /></span>)에서 예약 작업 제목으로 검색해 바로 열 수 있습니다.
- 대화의 [오른쪽 패널](/help/basics/right-panel/#예약-작업) **예약 작업** 탭에서 그 대화를 대상으로 하는 예약 작업을 누릅니다.

**예약 작업** 화면에는 **예약된 프롬프트 N개**와 예약 작업 목록이 표시됩니다. 각 항목에는 권한 아이콘, 제목, 대상 대화와 함께 상태, 주기, 다음 실행 시각, 권한(예: `켜짐 · 30분마다 · 다음: 10월 2일 오전 9:00 · 먼저 확인`)이 나옵니다. 다음 실행 시각은 상태가 **켜짐**일 때만 표시됩니다.

## 예약 작업 만들기

<Steps>
  1. **예약 작업** 화면에서 **새 예약 작업**을 누릅니다.
  2. **제목**과 **프롬프트**를 입력합니다. 둘 다 비워 둘 수 없습니다.
  3. **세부 정보**의 **대상 대화**에서 프롬프트를 보낼 대화를 고릅니다. 프로젝트 대화는 `프로젝트 이름 / 대화 제목` 형식으로 표시됩니다.
  4. **대상 대화** 아래의 **권한**에서 예약 작업이 실행될 때 쓸 권한을 고릅니다.
  5. **주기**를 고르고 간격이나 시간을 정합니다.
  6. **저장**을 누릅니다.
</Steps>

저장한 예약 작업은 **예약 작업** 목록에 나타납니다. 주기가 **간격**이면 첫 실행은 저장한 시점부터 간격만큼 지난 뒤이고, 그 밖의 주기는 다음으로 돌아오는 시간에 처음 실행합니다. 목록으로 돌아가려면 왼쪽 화살표 버튼(**예약 작업 목록으로 돌아가기**)이나 화면 위쪽 경로의 **예약 작업**을 누릅니다.

## 권한

**권한**에서 이 예약 작업의 실행에 쓸 접근 권한을 고릅니다. 선택지는 컴포저의 **권한** 메뉴와 같은 **먼저 확인**, **전체 권한**, **읽기 전용**입니다. 권한별 동작은 [대화와 컴포저](/help/basics/conversation/#권한)를 참고합니다.

- 새 예약 작업은 **대상 대화**의 현재 권한으로 시작합니다. **권한**을 직접 고르기 전에는 **대상 대화**를 바꾸면 권한도 그 대화의 권한으로 바뀝니다.
- 대상 대화의 권한을 읽지 못하면 **먼저 확인**이 선택됩니다.
- 예약 작업을 수정할 때는 저장된 권한이 표시됩니다.
- **먼저 확인**을 고르면 **먼저 확인이면 자리를 비운 동안 승인을 기다립니다.** 안내가 나타납니다.
- 고른 권한은 이 예약 작업의 실행에만 적용되며, 대상 대화의 권한은 바뀌지 않습니다.

## 주기

**주기**에서 예약 작업을 언제 실행할지 고릅니다. 새 예약 작업의 기본값은 **간격**입니다.

| 주기 | 함께 정하는 항목 | 실행 시점 |
| --- | --- | --- |
| **간격** | **간격** | 정한 간격마다 |
| **매일** | **시간** | 매일 정한 시간 |
| **평일** | **시간** | 월요일부터 금요일까지 정한 시간 |
| **매주** | **시간**, **요일** | 매주 고른 요일의 정한 시간 |

- **시간**의 기본값은 오전 8시이고, **요일**의 기본값은 월요일입니다.
- 시간은 예약 작업을 만든 컴퓨터의 시간대를 따릅니다.
- 목록과 상세 화면에는 주기가 `30분마다`, `매일 오전 8:00`, `평일 오전 8:00`, `매주 월요일 오전 8:00`처럼 표시됩니다.

### 간격

주기가 **간격**이면 **간격** 목록에서 다음 중 하나를 고릅니다. 기본값은 `30분마다`입니다.

- `10분마다`
- `30분마다`
- `1시간마다`
- `2시간마다`
- `24시간마다`
- **직접 지정**

**직접 지정**을 고르면 **사용자 지정 분** 입력란에 분 단위로 입력합니다. 5분부터 1440분(24시간)까지 설정할 수 있습니다.

## 예약 작업 수정하기

<Steps>
  1. **예약 작업** 목록에서 예약 작업을 누릅니다.
  2. **제목**, **프롬프트**, **대상 대화**, **권한**, **주기**를 바꿉니다.
  3. **저장**을 누릅니다.
</Steps>

**세부 정보**의 **상태**에는 예약 작업이 켜져 있으면 **켜짐**, 일시정지했으면 **꺼짐**이 표시됩니다. **켜짐** 상태인 예약 작업을 저장하면 다음 실행 시각을 저장한 시점 기준으로 다시 계산합니다.

## 지금 실행, 일시정지, 삭제

예약 작업 상세 화면 위쪽에 다음 버튼이 있습니다.

- **지금 실행** — 예약과 관계없이 바로 한 번 실행합니다. 일시정지한 예약 작업도 실행할 수 있습니다. **켜짐** 상태라면 다음 실행 시각도 이 시점부터 다시 계산됩니다.
- **일시정지** — 예약 실행을 멈춥니다. **상태**가 **꺼짐**으로 바뀝니다.
- **재개** — 일시정지한 예약 작업에 표시됩니다. 누르면 **상태**가 **켜짐**으로 바뀌고, 다음 실행 시각을 재개한 시점 기준으로 다시 계산합니다.
- **삭제** — 예약 작업을 삭제하고 목록으로 돌아갑니다.

## 실행 기록

예약 작업 상세 화면의 **실행 기록**에 최근 실행 6개가 상태와 시점과 함께 표시됩니다.

- **대기 중** — 대상 대화에서 다른 요청을 처리하고 있어 프롬프트를 아직 보내지 않았습니다. 그 대화의 요청이 끝나면 보냅니다.
- **실행 중** — 프롬프트를 보내는 중입니다.
- **성공** — 프롬프트를 대상 대화에 전달했습니다.
- **실패** — 프롬프트를 전달하지 못했습니다.
- **대상을 사용할 수 없음** — 기다리는 동안 대상 대화를 찾을 수 없게 되어 실행을 건너뛰었습니다.

실행 기록이 없으면 **아직 실행 기록이 없습니다**가 표시됩니다.

## 주의 사항

<Notice tone="warning">
  **삭제**는 확인 창 없이 바로 적용됩니다. **성공**은 프롬프트를 대화에 전달했다는 뜻이며, 요청한 작업이 성공했다는 뜻은 아닙니다. 결과는 대상 대화에서 확인합니다.
</Notice>

<Notice tone="info">
  **권한**이 **먼저 확인**인 예약 작업은 Butler가 파일을 수정하거나 명령을 실행하기 전에 대상 대화에서 허용 여부를 묻고, 허용할 때까지 기다립니다. 저장한 뒤 대상 대화의 권한을 바꿔도 예약 작업의 권한은 바뀌지 않습니다.
</Notice>

<Notice tone="info">
  예약 작업은 Butler Agent가 실행 중일 때만 동작합니다. 앱에 포함된 Agent를 쓰면 Butler가 열려 있어야 합니다. 데스크톱 앱에서는 **설정 → 일반**의 **로그인 시 시작**을 켜면 컴퓨터에 로그인할 때 Butler가 열립니다. 예약 시각은 30초 간격으로 확인하므로 실행이 조금 늦어질 수 있고, Butler가 꺼져 있던 동안 놓친 실행은 다시 켰을 때 한 번만 실행됩니다.
</Notice>
