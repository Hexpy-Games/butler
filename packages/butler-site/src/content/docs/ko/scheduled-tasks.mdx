예약 작업은 정해진 간격마다, 또는 매일·평일·매주 정한 시간에 지정한 대화에 프롬프트를 보냅니다. 보낸 프롬프트는 그 대화에 메시지로 들어가고, 버틀러는 같은 대화에서 답합니다.

## 예약 작업 화면 열기

- 사이드바에서 **새 대화**, **검색** 아래의 **예약 작업**을 누릅니다.
- [명령 팔레트](/help/basics/command-palette/)(<span data-mod-key><Kbd keys={["⌘", "K"]} label="Command K" /></span>)에서 예약 작업 제목으로 검색해 바로 열 수 있습니다.
- 대화의 [세션 정보](/help/basics/right-panel/#예약-작업)에 있는 **예약 작업** 항목에서 그 대화를 대상으로 하는 예약 작업을 누릅니다.

**예약 작업** 화면에는 **예약된 프롬프트 N개**와 예약 작업 목록이 표시됩니다. 각 항목에는 권한 아이콘, 제목, 대상 대화와 함께 상태, 주기, 다음 실행 시각, 권한(예: `켜짐 · 30분마다 · 다음: 10월 2일 오전 9:00 · 알아서 진행`)이 나옵니다. 다음 실행 시각은 상태가 **켜짐**일 때만 표시됩니다.

## 예약 작업 만들기

<Steps>
  1. **예약 작업** 화면에서 **새 예약 작업**을 누릅니다.
  2. **제목**과 **프롬프트**를 입력합니다. 둘 다 비워 둘 수 없습니다.
  3. **세부 정보**의 **대상 대화**에서 프롬프트를 보낼 대화를 고릅니다. 프로젝트 대화는 `프로젝트 이름 / 대화 제목` 형식으로 표시됩니다.
  4. **모델**에서 실행에 쓸 모델을 고릅니다. **모델 기본값**은 대상 대화의 모델을 따릅니다.
  5. **권한**에서 예약 작업이 실행될 때 쓸 권한을 고릅니다.
  6. **주기**를 고르고 간격이나 시간을 정합니다.
  7. 브라우저에서 로그인이나 결제가 필요하면 **브라우저**의 스위치를 켭니다.
  8. **저장**을 누릅니다.
</Steps>

저장한 예약 작업은 **예약 작업** 목록에 나타납니다. 주기가 **간격**이면 첫 실행은 저장한 시점부터 간격만큼 지난 뒤이고, 그 밖의 주기는 다음으로 돌아오는 시간에 처음 실행합니다. 목록으로 돌아가려면 왼쪽 화살표 버튼(**예약 작업 목록으로 돌아가기**)이나 화면 위쪽 경로의 **예약 작업**을 누릅니다.

## 권한

**권한**에서 이 예약 작업의 실행에 쓸 접근 권한을 고릅니다. 선택지는 컴포저의 **권한** 메뉴와 같은 **알아서 진행**, **읽기 전용**, **모두 확인**, **먼저 확인**, **전체 권한**입니다. 권한별 동작은 [대화와 컴포저](/help/basics/conversation/#권한)를 참고합니다.

- 새 예약 작업은 **설정 → 일반 → 기본 권한**의 **새 예약 작업**에 정한 권한으로 시작합니다. 기본값은 **알아서 진행**입니다.
- 예약 작업을 수정할 때는 저장된 권한이 표시됩니다.
- 고른 권한은 이 예약 작업의 실행에만 적용되며, 대상 대화의 권한은 바뀌지 않습니다.

예약 실행은 허용을 기다리지 않습니다. **읽기 전용**과 **전체 권한**이 아니면 **예약 실행 중 확인이 필요한 단계는 건너뛰고 알려 드립니다.** 안내가 나타납니다.

- 확인이 필요한 단계는 실행하지 않고 건너뜁니다. 그 실행은 **실행 기록**에 **권한 필요**로 남습니다.
- 사이드바의 **대화**에 **확인 필요** 표시와 함께 건너뛴 작업과 예약 작업 제목이 나타납니다. 누르면 그 예약 작업이 열립니다.
- **설정 → 일반**의 **데스크톱 알림**을 켰다면 **예약 작업이 권한이 필요한 단계를 건너뛰었습니다.** 알림도 표시됩니다.

## 모델

**모델**에서 이 예약 작업을 실행할 모델을 고릅니다. **모델 기본값**을 고르면 대상 대화의 모델을 따릅니다. 등록한 모델 중 하나를 고르면 그 모델로 실행합니다.

## 브라우저

**브라우저**에는 실행 중 [브라우저](/help/basics/browser/)에서 저장한 정보를 쓸지 정하는 스위치가 두 개 있습니다. 둘 다 처음에는 꺼져 있습니다.

- **로그인 정보 사용** — 켜면 허용한 사이트에 로그인 상태로 접속합니다.
- **결제 정보 사용** — 켜면 **설정 → 브라우저**의 **확인 없이 결제**에 둔 사이트에서 결제합니다. 이 컴퓨터에 시스템 암호 저장소가 없으면 켤 수 없고 **이 컴퓨터에서 사용 불가** 안내가 표시됩니다.

스위치가 꺼져 있는데 실행 중 로그인이나 결제가 필요하면 그 단계를 건너뜁니다. 그 실행은 **실행 기록**에 **로그인 정보 꺼짐** 또는 **결제 정보 꺼짐**으로 남습니다.

## 주기

**주기**에서 예약 작업을 언제 실행할지 고릅니다. 새 예약 작업의 기본값은 **간격**입니다.

| 주기 | 함께 정하는 항목 | 실행 시점 |
| --- | --- | --- |
| **간격** | **간격** | 정한 간격마다 |
| **매일** | **시간** | 매일 정한 시간 |
| **평일** | **시간** | 월요일부터 금요일까지 정한 시간 |
| **매주** | **시간**, **요일** | 매주 고른 요일의 정한 시간 |

- **시간**의 기본값은 오전 8시이고, **요일**의 기본값은 월요일입니다.
- 시간은 예약 작업을 만든 컴퓨터의 시간대를 따릅니다.
- 목록과 상세 화면에는 주기가 `30분마다`, `매일 오전 8:00`, `평일 오전 8:00`, `매주 월요일 오전 8:00`처럼 표시됩니다.
- 버틀러가 대화에서 한 번만 실행하도록 만든 예약 작업은 주기가 **한 번**으로 표시됩니다. 새 예약 작업에서는 **한 번**을 고를 수 없습니다.

### 간격

주기가 **간격**이면 **간격** 목록에서 다음 중 하나를 고릅니다. 기본값은 `30분마다`입니다.

- `10분마다`
- `30분마다`
- `1시간마다`
- `2시간마다`
- `24시간마다`
- **직접 지정**

**직접 지정**을 고르면 **사용자 지정 분** 입력란에 분 단위로 입력합니다. 5분부터 1440분(24시간)까지 설정할 수 있습니다.

## 예약 작업 수정하기

<Steps>
  1. **예약 작업** 목록에서 예약 작업을 누릅니다.
  2. **제목**, **프롬프트**, **대상 대화**, **모델**, **권한**, **주기**, **브라우저** 항목을 바꿉니다.
  3. **저장**을 누릅니다.
</Steps>

**세부 정보**의 **상태**에는 예약 작업이 켜져 있으면 **켜짐**, 일시정지했으면 **꺼짐**이 표시됩니다. **켜짐** 상태인 예약 작업을 저장하면 다음 실행 시각을 저장한 시점 기준으로 다시 계산합니다.

## 지금 실행, 일시정지, 삭제

예약 작업 상세 화면 위쪽에 다음 버튼이 있습니다.

- **지금 실행** — 예약과 관계없이 바로 한 번 실행합니다. 일시정지한 예약 작업도 실행할 수 있습니다. **켜짐** 상태라면 다음 실행 시각도 이 시점부터 다시 계산됩니다.
- **일시정지** — 예약 실행을 멈춥니다. **상태**가 **꺼짐**으로 바뀝니다.
- **재개** — 일시정지한 예약 작업에 표시됩니다. 누르면 **상태**가 **켜짐**으로 바뀌고, 다음 실행 시각을 재개한 시점 기준으로 다시 계산합니다.
- **삭제** — 확인 창에서 **삭제**를 누르면 예약 작업을 삭제하고 목록으로 돌아갑니다.

## 대화로 받는 예약 작업

**대상 대화**가 사이드바의 **대화**이면 버틀러의 답만 표시되고 보낸 프롬프트는 표시되지 않습니다.

- 예약된 실행은 입력창에 글을 쓰는 동안이나 **조용한 시간**에는 기다렸다가 보냅니다. **조용한 시간**은 **설정 → 기억**의 **버틀러가 알아챈 것**에서 정하며, 기본값은 오후 10시부터 오전 7시까지입니다.
- **지금 실행**은 진행 중인 응답이 끝날 때만 기다립니다.
- **조용한 시간** 동안 미뤄진 실행이 여러 번이어도 보고는 한 번만 보냅니다.
- 예약된 보고를 3번 연속 열어 보지 않으면 버틀러가 그 예약 작업을 멈추고 계속 받을지 묻습니다. **좋아요**를 누르면 다시 켜고, **괜찮아요**를 누르면 멈춘 채로 둡니다.

## 실행 기록

예약 작업 상세 화면의 **실행 기록**에 최근 실행 6개가 상태와 시점과 함께 표시됩니다.

- **대기 중** — 대상 대화에서 다른 요청을 처리하고 있어 프롬프트를 아직 보내지 않았습니다. 그 대화의 요청이 끝나면 보냅니다.
- **실행 중** — 프롬프트를 보내는 중입니다.
- **성공** — 프롬프트를 대상 대화에 전달했습니다.
- **실패** — 프롬프트를 전달하지 못했습니다.
- **대상을 사용할 수 없음** — 기다리는 동안 대상 대화를 찾을 수 없게 되어 실행을 건너뛰었습니다.
- **권한 필요** — 확인이 필요한 단계를 건너뛰었습니다.
- **로그인 정보 꺼짐** — **로그인 정보 사용**이 꺼져 있어 로그인이 필요한 단계를 건너뛰었습니다.
- **결제 정보 꺼짐** — **결제 정보 사용**이 꺼져 있어 결제가 필요한 단계를 건너뛰었습니다.
- **취소됨** — 실행이 취소되었습니다.
- **실행 전** — 프롬프트를 아직 보내지 않았습니다.

실행 기록이 없으면 **아직 실행 기록이 없습니다**가 표시됩니다.

## 주의 사항

<Notice tone="warning">
  **성공**은 프롬프트를 대화에 전달했다는 뜻이며, 요청한 작업이 성공했다는 뜻은 아닙니다. 결과는 대상 대화에서 확인합니다.
</Notice>

<Notice tone="info">
  예약 실행은 허용을 기다리지 않고 확인이 필요한 단계를 건너뜁니다. 그 단계까지 실행하려면 **권한**을 **전체 권한**으로 둡니다. 저장한 뒤 대상 대화의 권한을 바꿔도 예약 작업의 권한은 바뀌지 않습니다.
</Notice>

<Notice tone="info">
  예약 작업은 버틀러가 실행 중일 때만 동작합니다. 앱을 쓴다면 버틀러가 열려 있어야 합니다. 데스크톱 앱에서는 **설정 → 일반**의 **로그인 시 시작**을 켜면 컴퓨터에 로그인할 때 버틀러가 열립니다. 버틀러가 꺼져 있던 동안 놓친 실행은 다시 켰을 때 한 번만 실행됩니다.
</Notice>
