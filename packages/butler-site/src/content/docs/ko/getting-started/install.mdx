## 지원 환경

현재 버전은 `0.1.0-preview.5` 프리뷰이며, 정식 0.1.0은 출시 예정입니다.

- Apple Silicon(M 시리즈 칩) Mac, macOS 12 이상
- Linux x64 / arm64: DEB 패키지
- Arch Linux x64: Arch 패키지
- Windows 11 x64: 서명되지 않은 데스크톱 프리뷰

<Notice tone="info">
  macOS와 Linux에서는 Butler Agent가 앱에 포함되어 있어 따로 설치하지 않습니다. 앱에 포함된 Agent는 Butler가 열려 있는 동안에만 실행됩니다.
</Notice>

    <Steps>

      2. `ButlerSetup-<version>-x64.exe`를 다운로드하고 두 번 클릭합니다.
      3. SmartScreen이 나타나면 **추가 정보 → 실행**을 선택합니다. 프리뷰는 서명되지 않은 빌드입니다.
      4. 현재 사용자 계정에 설치된 뒤 버틀러가 자동으로 열립니다. 관리자 권한이나 설치 마법사가 필요하지 않습니다.
    </Steps>
  </TabPanel>
  <TabPanel value="linux">
    <Steps>
      1. [DEB x64](https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.5/butler-app-0.1.0-preview.5-linux-x64.deb), [DEB arm64](https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.5/butler-app-0.1.0-preview.5-linux-arm64.deb) 또는 [Arch x64](https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.5/butler-app-0.1.0-preview.5-archlinux-x64.pkg.tar.zst)를 내려받습니다.
      2. 내려받은 폴더에서 배포판에 맞는 명령으로 설치합니다.

    ```bash
    # Debian / Ubuntu (x64; arm64는 파일명을 바꿉니다)
    sudo apt install ./butler-app-0.1.0-preview.5-linux-x64.deb

    sudo pacman -U ./butler-app-0.1.0-preview.5-archlinux-x64.pkg.tar.zst
    ```

<Notice tone="warning">
  이전 릴리스에는 지금은 쓰지 않는 TypeScript/Bun Agent가 들어 있을 수 있습니다. 네이티브 Agent가 포함된 릴리스를 받습니다.
</Notice>

`0.1.0-preview.5` 앱을 설치한 뒤 **미리보기 버전 받기**를 켜면 다음 프리뷰를 **설정 → 업데이트**에서 받을 수 있습니다. `butler --version`으로 정확한 버전을 확인합니다.

### 파일 확인 (선택)

릴리스에는 파일마다 SHA-256 체크섬(`.sha256`)이 함께 올라갑니다. DMG와 체크섬 파일을 같은 폴더에 받은 뒤 확인합니다.

```bash
cd ~/Downloads
shasum -a 256 -c butler-app-*-darwin-arm64.dmg.sha256
```

`OK`가 나오면 내려받은 파일이 게시된 파일과 같습니다.

## 처음 열기

macOS 프리뷰 빌드는 서명되어 있지만 Apple 공증(notarization)을 거치지 않습니다. 처음 열 때 Gatekeeper 안내가 표시됩니다.

<Steps>
  1. 응용 프로그램 폴더에서 Butler를 마우스 오른쪽 버튼으로 클릭하고 **열기**를 선택합니다.
  2. 열리지 않으면 **시스템 설정 → 개인정보 보호 및 보안**에서 **그래도 열기**를 선택합니다.
</Steps>

## 첫 실행 설정

처음 실행하면 앱 안에서 첫 실행 설정이 진행됩니다. 환영 화면에서 인터페이스 언어를 고르고 동의한 뒤 AI를 연결합니다. AI 연결 마지막 단계에서 답변 언어를 선택합니다. 단계별 안내는 [첫 실행](/help/getting-started/first-run/)을 참고합니다.

설정을 마치면 <span data-mod-key><Kbd keys={["⌘", "K"]} label="Command K" /></span>로 [명령 팔레트](/help/basics/command-palette/)를 열어 대화, 프로젝트, 예약 작업, 설정을 찾을 수 있습니다.

## 앱 없이 Agent만 쓰기

헤드리스 Agent는 Apple Silicon macOS와 glibc 기반 Linux x64 / arm64를 지원합니다.

```bash
curl -fsSL https://github.com/Hexpy-Games/butler/releases/download/v0.1.0-preview.5/install.sh | sh -s -- --version 0.1.0-preview.5
# Node.js 사용 시
npx @hexpygames/butler install
```

자세한 관리 명령은 [Butler Agent CLI](/help/advanced/agent-cli/)를 참고합니다.

## Windows 데스크톱 프리뷰

Squirrel 설치 프로그램은 `%LOCALAPPDATA%\butler-app`에 설치하고 시작 메뉴와 바탕 화면에 바로 가기를 만듭니다. 설치 없이 실행하는 portable ZIP도 제공합니다. 앱 내 업데이트를 사용하려면 Setup으로 설치합니다.

**설정 → 업데이트**에서 프리뷰 업데이트를 켜고 **업데이트**를 누릅니다. 선택한 버전을 다운로드한 뒤 번들 Agent를 종료하고 새 앱과 Agent로 다시 실행합니다. 대화와 설정은 같은 데이터 폴더에 유지합니다. Squirrel은 롤백을 위해 이전 버전도 보관합니다.

제거하려면 **Windows 설정 → 앱 → 설치된 앱 → Butler → 제거**를 선택합니다. 앱, 바로 가기, `butler://` 연결과 로그인 시작 항목을 제거합니다. 버틀러 데이터 폴더는 유지합니다.
