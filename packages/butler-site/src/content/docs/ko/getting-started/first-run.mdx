Butler를 처음 열면 메인 화면 대신 첫 실행 설정이 나타납니다. **언어**, **안전고지**, **설치**, **모델** 네 단계를 마치면 Butler를 쓸 수 있습니다.

## 진행 순서

<Steps>
  1. **언어 선택**에서 언어를 고르고 **계속**을 누릅니다.
  2. **안전고지**의 기준을 확인하고 **동의**를 누릅니다.
  3. **Butler Agent를 준비합니다** 화면에서 준비가 끝날 때까지 기다립니다. **준비 완료**가 표시되면 다음 단계로 넘어갑니다.
  4. **모델 설정**에서 사용할 모델을 추가합니다. 추가한 모델이 기본 모델로 저장되면 설정이 끝납니다.
</Steps>

## 언어

**한국어**와 **영어** 중에서 고릅니다.

- 처음에는 시스템 언어를 따릅니다. 시스템의 선호 언어에 한국어가 있으면 한국어, 없으면 영어가 선택되어 있습니다.
- 언어를 바꾸면 설정 화면이 바로 그 언어로 바뀝니다.
- 고른 언어는 앱 언어로 저장됩니다. 나중에 **설정 → 일반**의 **언어**에서 바꿀 수 있습니다.

## 안전고지

Butler는 사용자가 요청한 로컬 작업을 대신 실행합니다. 이 단계에서는 다음 기준을 안내합니다.

- 파일 변경, 명령 실행, 외부 요청은 사용자의 지시 안에서만 진행됩니다.
- 민감한 경로나 토큰이 포함된 요청은 실행 전에 한 번 더 확인하세요. {/* prose-lint-disable-line sentence-ending -- quotes the onboarding safety notice (ko.ts safetyItems) verbatim */}
- 예약 작업 결과는 App 안의 기록과 진단 로그로 확인할 수 있습니다.

**동의**를 누르면 바로 설치 단계가 시작됩니다. **이전**을 누르면 언어 선택으로 돌아갑니다.

## 설치

앱에 포함된 Butler Agent를 시작하고 연결 상태를 확인합니다. 진행 중에는 **상태 확인 중**, 끝나면 **준비 완료**가 표시됩니다. 따로 누를 것은 없습니다.

준비하지 못하면 **Butler Agent를 준비하지 못했습니다.** 메시지와 함께 다음 버튼이 나타납니다.

- **다시 시도** — 같은 확인을 다시 실행합니다.
- **복구** — 실행 중인 Butler Agent를 멈추고 상태를 초기화한 뒤 다시 시작합니다.
- **진단 복사** — 확인 항목별 결과와 오류 정보를 클립보드에 복사합니다. 문제를 보고할 때 붙여 넣습니다.
- **종료** — 앱을 종료합니다.

## 모델

**모델 설정** 화면에서 Butler가 쓸 모델을 하나 추가합니다.

<Steps>
  1. **제공자**를 고릅니다. 목록에는 API 키나 OAuth로 연결하는 [클라우드 제공자](/docs/models/cloud/)와 **Custom**이 있습니다.
  2. **모델**을 고릅니다.
  3. 제공자가 여러 인증 방식을 지원하면 **인증 방식**에서 **API 키** 또는 **OAuth**를 고릅니다.
  4. **API 키**라면 키를 입력하고 **추가**를 누릅니다. **OAuth**라면 나타난 링크를 **브라우저에서 열기**로 열어 인증을 마칩니다. 인증이 끝나면 모델이 추가되며, 추가되지 않으면 **인증 완료 확인**을 누릅니다.
</Steps>

**Custom**을 고르면 모델을 직접 설정하는 항목이 나옵니다. 자세한 내용은 [Custom 모델](/docs/models/custom/)을 참고합니다.

모델이 추가되면 그 모델이 기본 모델로 저장되고 첫 실행 설정이 끝납니다. 이미 등록한 모델이 있으면 새로 추가하지 않아도 이 단계가 자동으로 끝납니다.

모델 목록을 불러오지 못하거나 설정을 저장하지 못하면 **다시 불러오기**를 누릅니다. **지금은 이 모델을 사용할 수 없습니다.** 메시지가 나오면 다른 모델을 선택합니다.

## 설정을 마친 뒤

메인 화면이 열리고 새 대화 화면이 나타납니다.

첫 대화 온보딩을 마치기 전에는 새 대화 화면에 **반갑습니다. 당신을 모시게 되어 기쁩니다.** 인사와 **버틀러와 알아가기** 제안이 나옵니다. 제안을 누르면 Butler가 대화로 이름, 호칭, 응대 방식 같은 기본 정보를 한 번에 하나씩 묻습니다. 원하지 않는 질문은 건너뛸 수 있습니다.

**버틀러 닉네임**, **내 이름**, **나를 부를 호칭**, **페르소나 프리셋**은 나중에 **설정 → 개인화**에서 바꿀 수 있습니다. 자세한 내용은 [개인화](/docs/personalization/)를 참고합니다.

## 주의 사항

<Notice tone="info">
  첫 실행 설정은 건너뛸 수 없습니다. 중간에 앱을 닫으면 다음에 열 때 마지막으로 진행한 단계부터 이어집니다.
</Notice>

<Notice tone="info">
  새 대화는 **먼저 확인** 권한으로 시작합니다. Butler가 파일을 수정하거나 명령을 실행하기 전에 허용 여부를 묻습니다. **전체 권한**으로 바꾸면 묻지 않고 파일을 읽고 쓰고 명령을 실행합니다. 기본값은 **설정 → 모델**의 **접근 권한**에서 바꿉니다.
</Notice>
