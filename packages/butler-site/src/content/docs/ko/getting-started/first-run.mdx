Butler를 처음 열면 메인 화면 대신 첫 실행 설정이 나타납니다. 환영 화면에서 시작하고 이용 동의 화면에 동의한 뒤 함께 일할 AI를 하나 연결하면 Butler를 쓸 수 있습니다.

## 진행 순서

<Steps>
  1. 환영 화면에서 **시작하기**를 누릅니다.
  2. 이용 동의 화면의 안내를 확인하고 **동의하고 시작**을 누릅니다.
  3. **어떤 AI와 일할까요?** 화면에서 AI를 하나 고릅니다.
  4. 로그인하거나 API 키를 붙여 넣어 고른 AI에 연결합니다.
  5. 연결이 끝나면 새 대화 화면이 열립니다.
</Steps>

그동안 Butler는 백그라운드에서 준비를 마칩니다. 준비가 끝나기를 기다리지 않고 다음 화면으로 넘어가도 됩니다.

## 환영 화면

환영 화면에는 제목, 설명, 인터페이스 언어 선택, **시작하기** 버튼이 표시됩니다. **자세히**를 누르면 브라우저에서 이 문서가 열립니다.

## 이용 동의

**시작하기**를 누르면 이용 동의 화면이 열립니다. 무료 오픈소스 제공, 파일 변경과 명령 실행, AI 제공자의 데이터 처리, 로컬 저장 위치를 안내합니다. Butler는 "있는 그대로" 제공되며 사용자의 지시로 컴퓨터에서 하는 작업은 사용자의 책임입니다.

**동의하고 시작**을 누르면 동의 버전과 시각을 저장하고 [AI 고르기](#ai-고르기) 화면으로 넘어갑니다. **동의하지 않음**을 누르면 동의를 저장하지 않고 환영 화면으로 돌아갑니다. 동의하지 않으면 Butler를 사용할 수 없습니다.

## AI 제공자와 데이터

AI 제공자를 사용하면 요청의 대화 내용과 처리에 필요한 문맥이 해당 제공자에게 전송됩니다. 문맥에는 요청에 포함된 파일 내용, 기억, 도구 실행 결과 등이 포함될 수 있습니다. 전송된 내용에는 각 제공자의 이용 약관과 개인정보 처리방침이 적용됩니다. Butler는 제공자의 데이터 처리에 책임지지 않습니다.

| 제공자 | 공식 안내 |
| --- | --- |
| OpenAI | [개인정보 처리방침](https://openai.com/policies/privacy-policy/) · [이용 약관](https://openai.com/policies/terms-of-use/) |
| Anthropic | [개인정보 처리방침](https://www.anthropic.com/legal/privacy) · [이용 약관](https://www.anthropic.com/legal/consumer-terms) |
| Google | [개인정보 처리방침](https://policies.google.com/privacy) · [이용 약관](https://policies.google.com/terms) |

이 컴퓨터에서 실행하는 로컬 모델을 사용하면 모델 요청은 이 컴퓨터 안에서 처리됩니다. Butler 자체는 대화, 기억, 설정을 이 컴퓨터의 `~/.butler`에만 저장합니다. 원격 App에서 접속할 때는 Butler Agent가 실행되는 컴퓨터가 저장 위치이며, 브라우저가 실행되는 컴퓨터가 아닙니다.

## 언어

환영 화면의 **인터페이스 언어**에서 **한국어**와 **English** 중에서 고릅니다.

- 처음에는 시스템 언어를 따릅니다. 시스템의 선호 언어에 한국어가 있으면 한국어, 없으면 영어가 선택되어 있습니다.
- 언어를 바꾸면 설정 화면이 바로 그 언어로 바뀝니다.
- 고른 언어는 설정을 마칠 때 앱 언어로 저장됩니다. 나중에 **설정 → 일반**의 **언어**에서 바꿀 수 있습니다.

## Butler 준비

환영 화면이 열리면 Butler가 백그라운드에서 준비를 시작합니다. 따로 누를 것은 없습니다. 준비하는 동안 **시작하기** 아래에 **Butler 준비 중**과 끝낸 단계 수가 표시되고, 끝나면 **준비됨**이 표시됩니다.

준비하지 못하면 **Butler를 시작하지 못했습니다.** 메시지 아래에 멈춘 이유가 표시되고, **시작하기**를 누를 수 없습니다. **다시 시도**를 누르면 준비를 다시 실행합니다. **더보기**에는 다음 메뉴가 있습니다.

- **초기화 후 다시 시작** — 실행 중인 Butler Agent를 멈추고 상태를 초기화한 뒤 다시 시작합니다.
- **문제 보고용 정보 복사** — 준비 단계별 결과와 오류 정보를 클립보드에 복사합니다. 문제를 보고할 때 붙여 넣습니다.
- **종료** — 앱을 종료합니다.

이유별 설명은 [문제 해결](/help/troubleshooting/#butler-agent를-준비하지-못할-때)을 참고합니다.

## AI 고르기

**어떤 AI와 일할까요?** 화면에서 Butler가 쓸 AI를 하나 고릅니다. 위쪽에는 자주 쓰는 서비스가 표시됩니다.

- **ChatGPT** — ChatGPT 계정으로 로그인합니다. API 키가 필요 없어 **키 필요 없음** 표시가 붙습니다.
- **Claude** — Anthropic API 키로 연결합니다.
- **Gemini** — Google AI Studio 키로 연결합니다.
- **이 컴퓨터** — Ollama나 LM Studio가 실행 중일 때 나타납니다. 이 Mac에서 실행하는 모델을 쓰며 **무료 · 비공개** 표시가 붙습니다.

**다른 서비스 8개**를 누르면 나머지 서비스가 펼쳐집니다. 펼친 뒤에는 이 버튼이 **접기**로 바뀝니다.

| 서비스 | 연결 방법 |
| --- | --- |
| **OpenAI API** | OpenAI API 키 |
| **Grok** | xAI API 키 |
| **Qwen** | Qwen Cloud API 키 |
| **Kimi** | Moonshot API 키 |
| **Z.AI 코딩 플랜** | 코딩 플랜 키 |
| **Z.AI API** | Z.AI API 키 |
| **OpenCode Go** | OpenCode Go 키 |
| **기타 (OpenAI 호환)** | 서버 주소 직접 입력 |

- Butler는 기본 포트(Ollama `11434`, LM Studio `1234`)에서 실행 중인 서버를 찾습니다.
- 두 서버가 모두 꺼져 있으면 **이 컴퓨터**는 펼친 목록 맨 앞에 흐리게 표시됩니다. 서버를 켠 뒤 이 항목을 누르면 다시 찾습니다.
- 서버에 받은 모델이 없으면 **받은 모델이 없습니다**가 표시되고 고를 수 없습니다.
- 인터넷에 연결되어 있지 않으면 안내가 표시되고 **이 컴퓨터**만 고를 수 있습니다.
- **이전**을 누르면 이용 동의 화면으로 돌아갑니다.

Butler 준비가 아직 끝나지 않았으면 **Butler 준비가 끝나면 바로 연결합니다**가 표시됩니다. 이때 AI를 고르고 연결하면 **Butler 준비가 끝나면 바로 시작합니다** 화면에서 기다렸다가 이어집니다.

## 연결하기

연결 화면에서 **다른 서비스**를 누르면 AI 목록으로 돌아갑니다. 연결을 마치지 못하면 **연결을 마치지 못했습니다. 다시 시도하세요.** 메시지가 나옵니다. 이때는 **다시 시도**를 누릅니다.

### ChatGPT

<Steps>
  1. **ChatGPT**를 누릅니다. 브라우저에 로그인 페이지가 열리고 Butler에는 **브라우저에서 로그인하세요** 화면이 표시됩니다.
  2. 브라우저에서 ChatGPT 계정으로 로그인합니다.
  3. Butler로 돌아옵니다. 로그인을 마치면 Butler가 자동으로 연결을 이어갑니다.
</Steps>

- 브라우저가 열리지 않으면 **브라우저가 열리지 않았나요? 링크 복사**를 눌러 주소를 복사하고 브라우저에 직접 붙여 넣습니다.
- 로그인을 그만두려면 **취소**를 누릅니다. 5분 안에 로그인을 마치지 않아도 로그인이 취소됩니다.
- **로그인이 취소되었습니다**나 **로그인하지 못했습니다** 화면에서는 **다시 시도**로 다시 로그인하거나 **다른 서비스 고르기**로 다른 AI를 고릅니다.

### API 키로 연결하는 서비스

**Claude**, **Gemini**, **OpenAI API**, **Grok**, **Qwen**, **Kimi**, **Z.AI 코딩 플랜**, **Z.AI API**, **OpenCode Go**는 API 키로 연결합니다.

<Steps>
  1. 서비스를 누릅니다. **Claude 연결**처럼 서비스 이름이 붙은 화면이 열립니다.
  2. 키가 없으면 **키 발급받기**를 눌러 서비스의 키 발급 페이지에서 키를 만듭니다.
  3. **API 키** 칸에 키를 붙여 넣습니다. Butler가 바로 서비스에 키를 확인합니다.
  4. 확인이 끝나면 **연결되었습니다**가 표시되고 연결이 이어집니다. 따로 누를 버튼은 없습니다.
</Steps>

- **키 발급받기**는 키 발급 페이지가 알려진 서비스에만 표시됩니다.
- 서비스에 키를 확인할 모델 목록이 없으면 확인 없이 키를 저장하고 **저장했습니다**를 표시합니다.
- 키를 쓸 수 없으면 칸 아래에 이유가 표시됩니다. 네트워크 오류나 요청 한도처럼 다시 시도해서 해결될 수 있는 오류에는 **다시 시도**가 함께 나옵니다.
- 확인한 키는 바로 저장됩니다. 저장 위치는 [클라우드 모델](/help/models/cloud/#인증-정보-저장-위치)을 참고합니다.

### 이 컴퓨터

<Steps>
  1. **이 컴퓨터**를 누릅니다. **이 컴퓨터의 모델** 화면에 Ollama와 LM Studio에서 찾은 모델이 표시됩니다.
  2. 쓸 모델을 고릅니다. 처음에는 첫 번째 모델이 선택되어 있습니다.
  3. **이 모델로 시작**을 누릅니다.
</Steps>

로컬 모델은 첫 응답이 조금 느릴 수 있습니다. 연결한 모델은 [Custom 모델](/help/models/custom/)로 등록됩니다.

### 기타 (OpenAI 호환)

<Steps>
  1. **다른 서비스 8개**를 펼치고 **기타 (OpenAI 호환)** 항목을 누릅니다.
  2. **OpenAI 호환 서버** 화면의 **서버 주소**에 서버 주소를 입력합니다.
  3. 서버에 인증이 필요하면 **API 키 (선택)** 칸에 키를 입력합니다.
  4. **연결**을 누릅니다. 서버에서 찾은 모델이 표시됩니다.
  5. 쓸 모델을 고르고 **이 모델로 시작**을 누릅니다.
</Steps>

연결한 모델은 [Custom 모델](/help/models/custom/)로 등록됩니다.

## 기본 모델

연결한 모델이 Butler의 기본 모델이 되고, Worker 프로필도 같은 모델을 씁니다.

- ChatGPT나 API 키로 연결하는 서비스를 고르면 서비스마다 정해 둔 일상 작업용 모델을 씁니다. 추론 강도는 중간(**Medium**)입니다.
- **이 컴퓨터**나 **기타 (OpenAI 호환)** 항목에서는 고른 모델을 씁니다.

모델과 추론 강도는 나중에 **설정 → 모델**의 **버틀러 모델**에서 바꿉니다. 자세한 내용은 [클라우드 모델](/help/models/cloud/#기본-모델-고르기)을 참고합니다.

## 설정을 마친 뒤

메인 화면이 열리고 새 대화 화면이 나타납니다. 연결한 서비스는 **ChatGPT에 연결했습니다** 같은 알림으로 표시됩니다.


첫 대화 온보딩을 마치기 전에는 새 대화 화면에 **반갑습니다. 당신을 모시게 되어 기쁩니다.** 인사와 **버틀러와 알아가기** 제안이 나옵니다. 제안을 누르면 Butler가 대화로 이름, 호칭, 응대 방식 같은 기본 정보를 한 번에 하나씩 묻습니다. 원하지 않는 질문은 건너뛸 수 있습니다.

**버틀러 닉네임**, **내 이름**, **나를 부를 호칭**, **페르소나 프리셋**은 나중에 **설정 → 개인화**에서 바꿀 수 있습니다. 자세한 내용은 [개인화](/help/personalization/)를 참고합니다.

## 설정 다시 실행하기

환영 화면과 AI 연결은 나중에 다시 진행할 수 있습니다. 등록한 모델과 대화는 그대로 남습니다.

<Steps>
  1. **설정 → 일반 → 앱 동작**에서 **설정 다시 실행**의 **다시 실행**을 누릅니다.
  2. 환영 화면에서 **시작하기**를 누릅니다. 바꾸지 않고 나가려면 **취소**를 누릅니다.
  3. 이용 동의 화면에서 **동의하고 시작**을 누릅니다.
  4. AI를 고르고 연결합니다. 지금 쓰는 AI에는 **사용 중** 표시가 붙습니다.
</Steps>

- ChatGPT나 API 키로 연결하는 서비스에서 지금 쓰는 AI를 다시 고르면 모델, 추론 강도, Worker 프로필 설정을 그대로 둡니다.
- 다른 AI를 고르면 [기본 모델](#기본-모델)이 새 AI의 모델로 바뀝니다.

## 주의 사항

<Notice tone="info">
  첫 실행 설정은 건너뛸 수 없습니다. 중간에 앱을 닫으면 다음에 열 때 환영 화면부터 다시 시작합니다.
</Notice>

<Notice tone="info">
  이용 동의 안내가 바뀌면 설정을 마친 Butler에서도 다음에 열 때 이용 동의 화면이 다시 나타납니다. **동의하고 시작**을 누르면 AI 연결 화면으로 이동합니다.
</Notice>

<Notice tone="info">
  새로 설치한 Butler에서는 새 대화가 **먼저 확인** 권한으로 시작합니다. Butler가 파일을 수정하거나 명령을 실행하기 전에 허용 여부를 묻습니다. 첫 대화 온보딩에서 답한 내용은 묻지 않고 저장합니다. **전체 권한**으로 바꾸면 묻지 않고 파일을 읽고 쓰고 명령을 실행합니다. 기본값은 **설정 → 모델**의 **접근 권한**에서 바꿉니다. 자세한 내용은 [대화와 컴포저](/help/basics/conversation/#권한)를 참고합니다.
</Notice>
