설정에서는 앱 동작, 모델, 확장 기능, 시스템 정보를 관리합니다. 섹션과 항목은 앱에 표시되는 순서를 따르며, 따로 설명한 문서가 있는 항목은 그 문서로 연결합니다.

## 설정 열기

<Steps>
  1. 사이드바에서 **설정**을 누릅니다. [명령 팔레트](/help/basics/command-palette/)(<span data-mod-key><Kbd keys={["⌘", "K"]} label="Command K" /></span>)에서 설정 항목을 찾아 열 수도 있습니다.
  2. 왼쪽 목록에서 섹션을 고릅니다.
  3. 항목을 바꿉니다.
</Steps>

- **설정 검색**에 입력하면 섹션 이름, 설명, 별칭으로 섹션을 거릅니다. 일치하는 섹션이 하나뿐이면 바로 열립니다.
- 대부분의 항목은 바꾸는 즉시 저장되고 **저장됨** 알림이 나타납니다. **개인화**는 **적용**을 눌러야 저장됩니다.
- **돌아가기**를 누르거나 <Kbd keys={["Esc"]} label="Escape" />를 누르면 설정을 닫습니다.

섹션은 세 그룹으로 나뉩니다.

| 그룹 | 섹션 |
| --- | --- |
| **환경 설정** | 일반, 모양, 개인화, 기억, 모델 |
| **앱 및 시스템** | 업데이트, 사용량, 로그, 브라우저, 보안, 시스템 이벤트, 아카이브, 정보 |
| **고급** | MCP, 훅, 스킬, 서버 |

## 일반

언어, 시간대, 대화 입력, 사이드바 정리, 기본 권한, 알림, 웹 검색의 기본값을 설정합니다.

| 영역 | 항목 | 설명 |
| --- | --- | --- |
| **언어 및 지역** | **언어** | 앱 인터페이스 언어입니다. **영어** 또는 **한국어**를 고릅니다. |
| | **시간대** | 버틀러가 현재 시간과 일정 맥락을 해석할 때 쓰는 시간대입니다. 목록에서 검색해 고릅니다. |
| **대화 입력** | **후속 요청 처리** | 버틀러가 작업 중일 때 보낸 메시지를 다루는 방식입니다. **작업 중이면 대기열에 추가**는 메시지를 대기열에 넣고 지금 작업이 끝나면 보냅니다. |
| | **메시지 보내기** | **<span data-mod-key><Kbd keys={["⌘", "Enter"]} label="Command Enter" /></span> 전송, Enter 줄바꿈** 또는 **Enter 전송, Shift Enter 줄바꿈**을 고릅니다. [보내기 키](/help/basics/conversation/#보내기-키)를 참고합니다. |
| | **기본으로 계획 모드 사용** | 켜면 새 프로젝트 대화가 계획 모드로 시작합니다. |
| **사이드바** | **스마트 그룹** | 새 대화를 같은 주제의 그룹으로 자동 정리합니다. 직접 옮긴 대화는 그대로 둡니다. |
| **기본 권한** | **새 대화** | 새 대화가 시작할 때의 권한입니다. 대화마다 컴포저의 **권한** 메뉴에서 바꿀 수 있습니다. [대화와 컴포저](/help/basics/conversation/#권한)를 참고합니다. |
| | **새 예약 작업** | 새 예약 작업이 실행될 때의 권한입니다. 기본값은 **알아서 진행**입니다. [예약 작업](/help/scheduled-tasks/#권한)을 참고합니다. |
| | **명령 격리** | 켜면 **알아서 진행**일 때 파일을 바꾸는 명령을 격리된 환경에서 실행합니다. 끄면 실행 전에 확인합니다. 이 기기에서 쓸 수 없으면 바꿀 수 없고 **이 기기에서는 사용할 수 없습니다** 안내가 표시됩니다. |
| **알림** | **데스크톱 알림** | 앱이 뒤에 있을 때 새 답변이나 작업 완료를 운영체제 알림으로 보냅니다. |
| | **AI 메시지 알림** | 새 답변이 도착하면 알립니다. 알림에는 안전한 미리보기만 표시합니다. |
| | **작업 완료 알림** | 작업이 완료, 실패, 취소되면 알립니다. |
| **알림 권한** | **OS 알림 상태** | 운영체제 알림 권한 상태입니다. **테스트**로 테스트 알림을 보냅니다. 운영체제 알림 설정을 열 수 있는 환경에서는 그 설정을 여는 버튼도 표시됩니다. |
| **앱 동작** | **창을 닫아도 앱 아이콘 표시** | 켜면 창을 닫아도 버틀러가 계속 실행됩니다. 앱 메뉴에서 새 대화와 최근 대화를 열 수 있습니다. |
| | **로그인 시 시작** | 켜면 컴퓨터에 로그인할 때 버틀러가 열립니다. 데스크톱 앱에서만 표시됩니다. |
| | **설정 다시 실행** | **다시 실행**을 누르면 환영 화면과 AI 연결을 다시 진행합니다. 등록한 모델과 대화는 그대로 남습니다. [첫 실행](/help/getting-started/first-run/#설정-다시-실행하기)을 참고합니다. |
| **검색 공급자** | **검색 제공자** | 웹 검색 결과를 가져올 곳입니다. **DuckDuckGo HTML**, **자동**, **Brave Search**, **Tavily**, **OpenAI 웹 검색**, **ChatGPT 플랜 검색**, **비활성화** 중에서 고릅니다. 키가 필요한 제공자에 키가 없으면 기본 검색으로 내려갑니다. |
| | **API 키** | 키가 필요한 제공자를 고르면 나타납니다. 키를 입력하고 **저장**을 누르면 비밀값으로 저장되며 화면에 다시 표시하지 않습니다. |
| **검색 동작** | **페이지 읽기** | 검색 결과 원문을 읽을 리더입니다. 기본값 **버틀러 브라우저**는 앱의 브라우저로 읽고, 앱이 없을 때만 내장 헤드리스 브라우저를 씁니다. **버틀러 브라우저**, **경량 리더**, **자동**, **Lightpanda**, **Jina 호스팅**, **비활성화** 중에서 고릅니다. |
| | **스마트 검색계획 사용** | 켜면 검색 전에 모델을 한 번 호출해 의도, 깊이, 검증 필요성, 쿼리 묶음을 계획합니다. |
| | **기본 검색 깊이** | **스마트 검색계획 사용**을 켰을 때만 보입니다. **빠르게**, **균형**, **깊게** 중에서 고릅니다. |
| **전체 초기화** | **모든 데이터 지우기** | **초기화**를 누르고 확인 문구를 입력하면 채팅, 기억, 예약 작업, 설정, 저장된 키를 모두 지우고 앱을 다시 시작합니다. 프로젝트 폴더와 내려받은 모델은 남습니다. 데스크톱 앱에서만 할 수 있습니다. |

새로 설치한 버틀러에서 **새 대화**의 기본값은 **먼저 확인**입니다. 이전 버전부터 쓰던 버틀러는 이 값을 저장한 적이 없으면 **전체 권한**을 그대로 씁니다. 저장한 값은 업데이트해도 바뀌지 않습니다.

## 모양

앱의 테마, 홈 화면과 입력창을 설정합니다.

| 영역 | 항목 | 설명 |
| --- | --- | --- |
| **테마** | **테마** | **시스템**, **라이트**, **다크** 중에서 고릅니다. 실시간 월페이퍼가 밝기를 정하는 동안에는 바꿀 수 없습니다. |
| | **글자 크기** | **기본**, **크게**, **아주 크게** 중에서 고릅니다. |
| | **투명 사이드바** | 사이드바를 반투명하게 표시합니다. |
| **홈 화면** | **월페이퍼** | 새 채팅 화면의 배경입니다. 목록에서 월페이퍼를 고르거나 **없음**을 고릅니다. **이미지 추가**로 JPEG, PNG, WebP 이미지를 25MB까지 올려 배경으로 쓸 수 있습니다. |
| | **움직임** | 월페이퍼를 골랐을 때 보입니다. 켜면 배경을 천천히 움직입니다. |
| | **배터리 사용 시 멈춤** | **움직임**을 켰을 때 보입니다. 켜면 전원이 연결되지 않았을 때 움직임을 멈춥니다. |
| **대화창** | **생각 내용 표시** | 켜면 버틀러가 답하기 전에 생각한 내용을 대화에 보여 줍니다. |
| | **대화창 배경** | 단색, 리소 프린트, 월페이퍼 또는 공유 이미지를 고릅니다. 월페이퍼와 이미지의 **배경 불투명도**는 0–95%이며, 홈 화면과 별도로 저장됩니다. |
| **입력창** | **입력창 접기** | 입력하지 않을 때 입력창을 한 줄로 줄입니다. |
| | **입력창 배경** | 글자 뒤에 그림을 깝니다. |
| | **캐릭터** | 입력창 위에 작은 친구가 앉습니다. |
| **접근성** | **동작 줄이기** | 앱의 움직임을 멈춥니다. 끄면 시스템 설정을 따릅니다. |

## 개인화

버틀러가 쓸 이름, 말투, 사용자 정보를 관리합니다. 다른 섹션과 달리 바꾼 뒤 **적용**을 눌러야 저장됩니다. 항목별 설명은 [개인화](/help/personalization/)를 참고합니다.

| 영역 | 항목 |
| --- | --- |
| **프로필** | **버틀러 닉네임**, **내 이름**, **나를 부를 호칭** |
| **응답 스타일** | **답변 언어**, **페르소나 프리셋**, **페르소나**, **얼** |
| **알아가기** | **범위**, **알아가기 모델**, **추론**, **기억** |
| **다른 AI에서 가져오기** | **기억 가져오기** |

## 기억

버틀러가 기억하는 내용을 종류별로 보고 관리합니다.

| 영역 | 설명 |
| --- | --- |
| **지침** | 채팅에서 추가한 지침 목록입니다. 지침은 하나씩 삭제할 수 있습니다. |
| **버틀러가 알아챈 것** | 대화에서 버틀러가 알아챈 습관입니다. **먼저 말 걸기**와 **조용한 시간**도 여기서 정합니다. |
| **대화 기억** | 대화에서 버틀러가 스스로 기억한 내용입니다. **대화 기억 지우기**로 지웁니다. |
| **기억 정리** | 기억 정리에 쓸 **대화 기억 정리 모델**, **추론**, **실행 시간**을 정합니다. **지금 실행**으로 바로 실행합니다. |
| **기억 모델** | **기억 모델 사용**으로 기억 모델을 켜거나 끄고 상태를 확인합니다. 준비가 끝나면 **준비되었습니다**가 표시됩니다. 받지 못했으면 **다시 시도**로 다시 받습니다. [첫 실행](/help/getting-started/first-run/#기억-모델)을 참고합니다. |
| **프로필** | 대화에서 알게 된 사용자 정보입니다. **프로필 지우기**로 알아낸 항목과 후보를 지웁니다. |
| **프로젝트 기억** | 프로젝트를 골라 그 프로젝트의 기억을 확인합니다. **프로젝트 기억 지우기**로 지웁니다. |

## 모델

버틀러와 작업자가 쓸 모델, 예비 모델, 이미지 모델을 관리합니다.

| 영역 | 항목 | 자세히 |
| --- | --- | --- |
| **버틀러 모델** | **모델**, **모델 관리**, **추론**, **컨텍스트 한도**, **로컬 추론 예산** | [클라우드 모델](/help/models/cloud/#기본-모델-고르기), [Custom 모델](/help/models/custom/#로컬-추론-예산) |
| **예비 모델** | 예비 모델 요약, **편집**, **예비 모델 사용**, **예비 모델 추가** | [예비 모델](/help/models/backup/) |
| **이미지 모델** | **모델**, **저장된 인증**, **API 키**, **기본 품질** | [이미지 모델](#이미지-모델) |
| **고급** | **작업자 설정** | 아래 표 |

저장한 API 키는 **설정 → 보안 → API 키**에서, 새 대화의 기본 권한과 **기본으로 계획 모드 사용**은 **설정 → 일반**에서 관리합니다.

**설정 → 모델 → 모델 관리**에서 ChatGPT 모델을 **편집**하면 로그인 상태와 계정을 확인합니다. **다른 계정 사용**으로 계정을 바꾸거나 **로그아웃**을 누릅니다. **사용량 관리**는 ChatGPT 사용량 설정을 엽니다.

**예비 모델**에는 예비 모델이 이어받는 순서가 한 줄로 표시됩니다. **편집**을 누르면 예비 모델을 켜고 고르는 항목이 펼쳐집니다.

**고급**의 **작업자 설정**은 처음에 접혀 있습니다. 누르면 버틀러가 작업을 맡길 작업자를 정하는 항목이 펼쳐집니다.

| 항목 | 설명 |
| --- | --- |
| **작업당 최대 작업자 수** | 작업 하나에 쓸 작업자 수의 상한입니다. 1부터 10까지 입력합니다. |
| **작업자 추가** | 작업자 프로필을 추가합니다. 최대 12개까지 등록합니다. |
| **이름**, **사용** | 프로필 이름과 사용 여부입니다. 기본 프로필은 끄거나 삭제할 수 없습니다. |
| **작업**, **사용자 지정 작업** | **코딩**, **리서치**, **디버깅**, **리뷰**, **글쓰기**, **사용자 지정** 중에서 고릅니다. **사용자 지정**이면 작업을 직접 적습니다. |
| **도메인**, **작업자 프롬프트** | 프로필이 맡을 분야와 작업자에게 줄 지시입니다. 비워 둘 수 있습니다. |
| **모델**, **추론** | 이 프로필이 쓸 모델과 추론 강도입니다. |

### 이미지 모델

**이미지 모델**에서 버틀러가 이미지를 만들고 편집할 때 쓸 모델을 고릅니다. 바꾸면 바로 저장됩니다.

- **모델** — 기본값은 **사용 안 함**입니다. 이미지 모델을 고르지 않으면 버틀러는 이미지를 만들지 않습니다.
- **저장된 인증**, **API 키** — 고른 제공자의 API 키를 이미 저장했다면 그 키가 바로 선택됩니다. 없으면 **API 키**를 입력하고 **추가**를 누릅니다.
- **기본 품질** — 이미지를 만들 때 쓰는 기본 품질입니다. 키를 고른 뒤에 바꿀 수 있고, 모델이 지원하는 값만 표시됩니다.

| 제공자 | 모델 |
| --- | --- |
| OpenAI | GPT Image 2.6 Sunburst, GPT Image 2.6 Flare, GPT Image 2.5 Sunburst, GPT Image 2.5 Flare, GPT Image 2 |
| Google | Nano Banana 2.1, Nano Banana Pro, Nano Banana 2 Lite |

이미지 모델에는 API 키만 쓸 수 있습니다. ChatGPT 로그인으로는 이미지 모델을 쓸 수 없습니다. 이미지 모델은 대화의 모델 목록에 나타나지 않습니다. 사용량은 [사용량](#사용량)의 **이미지 모델**에서 확인합니다.

## 업데이트

버틀러의 새 버전을 확인하고 설치합니다.

| 항목 | 설명 |
| --- | --- |
| **미리보기 버전 받기** | 켜면 정식 출시 전 버전도 업데이트로 받습니다. 프리뷰 빌드에서는 처음부터 켜져 있습니다. |
| **확인** | 새 버전이 있는지 확인합니다. 확인하는 동안 **확인 중**으로 표시됩니다. |
| **버틀러** | 현재 버전과 앱에 포함된 Butler Agent 버전을 보여 줍니다. 새 버전이 있으면 `현재 버전 -> 새 버전`으로 표시합니다. |
| **업데이트** | 새 버전이 있을 때 누릅니다. 새 버전을 내려받아 체크섬을 확인하고, 앱과 앱에 포함된 Butler Agent를 새 버전으로 바꾼 뒤 버틀러를 다시 엽니다. 진행하는 동안 **적용 중**, 새 버전이 없으면 **최신**으로 표시되고 누를 수 없습니다. |

<Notice tone="info" title="데이터는 그대로 남습니다">
  업데이트는 앱만 바꾸고 데이터 폴더는 건드리지 않습니다. Linux에서 DEB 패키지로 설치한 앱은 업데이트를 적용할 때 관리자 인증을 요청합니다.
</Notice>

## 사용량

모델 토큰 사용량, 이미지 모델 사용량, 남은 한도를 확인합니다. 컨텍스트 창 용량과는 별도로 기록됩니다.

| 항목 | 설명 |
| --- | --- |
| **최근 사용량** | 기간별 토큰 사용량과 추정 비용입니다. **24시간**, **7일**, **30일** 중에서 기간을 고르고, **새로고침**으로 다시 불러옵니다. |
| **사용 기록** | **누적 토큰**, **가장 많이 쓴 날**, **가장 긴 작업**, **최장 연속 사용**, **연속 사용 중**과 날짜별 사용 기록입니다. |
| **이미지 모델** | 이미지 모델별 **생성**, **편집** 횟수와 **추정 비용**, **합계**입니다. **7일**과 **30일** 중에서 고릅니다. 이미지 모델을 골랐거나 최근 30일 안에 이미지 사용 기록이 있을 때만 나타납니다. |
| **남은 한도** | 제공자별 남은 사용 한도입니다. 한도를 알려 주는 제공자가 있을 때만 나타납니다. |

## 로그

개발자 모드(**정보 → 개발자 모드**)에서만 나타납니다.

- **기록** — **최소**, **기본**, **자세히**, **전체** 중 하나를 고릅니다. **전체**는 프롬프트, 응답, 요청 본문을 이 기기에 저장하고 60분 뒤 꺼지며, **끄기**로 먼저 끌 수 있습니다. **분류별 수준**으로 분류마다 수준을 정합니다.
- **목록** — 최신 항목이 위에 옵니다. 검색어, 수준, 출처, 분류, 기간으로 거릅니다. **실시간**을 켜면 새 항목이 바로 추가되고, **더보기**로 이전 항목을 불러옵니다. 항목을 열면 필드와, HTTP 항목이면 **요청**, **응답**, **JSON** 탭이 나옵니다.
- **저장 공간** — 저장소별 사용량, 한도, 보관 기간입니다. **내보내기…** 버튼으로 zip을 저장하고(본문 포함 선택), **모두 삭제…** 버튼으로 저장된 로그를 지웁니다.

## 브라우저

버틀러 브라우저의 방문 기록과 사이트 데이터, 버틀러가 입력할 로그인과 결제 정보를 관리합니다. 브라우저 사용법은 [브라우저](/help/basics/browser/)를 참고합니다.

| 영역 | 항목 | 설명 |
| --- | --- | --- |
| **브라우징** | **브라우징 에이전트** | 버틀러가 페이지를 다루는 작업에 쓸 모델입니다. 기본값은 자동 선택이며 `자동 · <모델>`로 표시됩니다. **사용 안 함**이나 등록한 모델을 고를 수도 있습니다. |
| **방문 기록** | **방문한 페이지** | **보기**로 방문 기록을 열고, **지우기**로 지웁니다. |
| **사이트 데이터** | **쿠키 및 캐시** | **지우기**를 누르고 확인하면 모든 사이트에서 로그아웃됩니다. 저장한 로그인, 결제 수단, 방문 기록, 북마크는 남습니다. 데스크톱 앱에서만 지울 수 있습니다. |
| **로그인** | 저장한 로그인 | **추가**로 **사이트**, **아이디**, **비밀번호**를 저장합니다. 로그인마다 **버틀러 로그인**(**항상**, **묻기**, **안 함**)과 **모든 대화에서 사용**을 정합니다. 비밀번호는 화면에 표시하지 않습니다. |
| **결제 수단** | 저장한 카드 | **추가**로 카드를 저장합니다. 카드마다 **확인 없이 입력할 사이트**를 정합니다. **번호 보기**는 Touch ID나 Windows Hello 같은 확인을 거쳐 번호를 잠시 보여 줍니다. |
| **내 정보** | 저장한 프로필 | 이름, 연락처, 주소 같은 정보를 프로필로 저장합니다. 프로필마다 **확인 없이 입력할 사이트**를 정합니다. |
| **확인 없이 결제** | 사이트 목록 | 목록의 사이트에서는 버틀러가 결제 직전에 다시 묻지 않습니다. 목록이 비어 있으면 **결제할 때마다 확인해요**가 표시됩니다. |
| **다른 브라우저에서 가져오기** | **브라우저 데이터** | **브라우저 가져오기**를 눌러 다른 브라우저의 **북마크**, **비밀번호**, **방문 기록**을 가져옵니다. **파일에서 가져오기**로 북마크 HTML 파일이나 비밀번호 CSV 파일을 가져올 수도 있습니다. |

**로그인**, **결제 수단**, **내 정보**와 비밀번호 가져오기는 시스템 암호 저장소가 있어야 쓸 수 있습니다. 저장소가 없으면 **추가**가 비활성화되고 **시스템 암호 저장소가 있어야 쓸 수 있어요** 안내가 표시됩니다.

- macOS 앱은 키체인을 씁니다.
- Windows와 Linux에서는 같은 데이터 폴더를 쓰는 CLI에서 아래 명령으로 시스템 저장소를 켭니다. Windows는 자격 증명 관리자, Linux는 시스템 키링을 씁니다.

```bash
butler config set secrets.store system
```

이 설정을 켜면 API 키도 시스템 저장소에 저장됩니다.

## 보안

다른 기기의 접속, 허용한 작업, API 키, 연결된 계정을 관리합니다. 원격 접속 항목은 호스트 컴퓨터에서만 쓸 수 있으며, 다른 컴퓨터에서 열면 **호스트 컴퓨터에서만 사용할 수 있습니다.** 메시지가 표시됩니다. 연결 절차는 [원격 접근](/help/advanced/remote-access/#앱에서-기기-연결하기)을 참고합니다.

| 영역 | 항목 | 설명 |
| --- | --- | --- |
| **원격 접속** | **다른 컴퓨터에서 접속 허용** | 켜면 같은 네트워크의 기기에서 연결 코드를 입력해 접속합니다. 처음에는 꺼져 있습니다. |
| | **접속 주소** | 접속을 허용했을 때 나타납니다. 다른 컴퓨터에서 열 주소이며, **주소 복사**로 복사합니다. 주소를 열지 못하면 **포트 사용 중**, **포트 권한 없음**, **주소 사용 불가**, **주소 열기 실패** 중 하나가 표시됩니다. |
| **기기 연결** | **코드** | 접속을 허용했을 때 나타납니다. **기기 연결**을 누르면 8자리 코드와 남은 시간이 표시됩니다. 코드는 60초 동안 한 번만 쓸 수 있고, 만료되면 새 코드를 발급합니다. |
| **연결된 기기** | 기기 목록 | 접속을 허용했을 때 나타납니다. 연결된 기기의 이름, IP 주소, 마지막 접속 시각입니다. **연결 끊기**로 기기 하나의 연결을, **모두 끊기**로 모든 기기의 연결을 끊습니다. 연결된 기기가 없으면 **연결된 기기 없음**이 표시됩니다. |
| **허용한 작업** | 작업 목록 | 묻지 않고 실행하도록 허용한 작업입니다. **허용한 작업 검색**과 **종류**로 거르고, **허용 해제**로 허용을 거둡니다. |
| **API 키** | 저장한 키 목록 | 모델에 쓰는 API 키입니다. **교체**나 **삭제**를 누릅니다. [클라우드 모델](/help/models/cloud/#api-키-관리)을 참고합니다. |
| **연결된 계정** | ChatGPT 로그인 | 로그인한 ChatGPT 계정입니다. **로그아웃**을 누르면 버틀러에 저장된 인증 정보를 지웁니다. |
| **고급** | **터널·프록시용 허용 호스트** | 누르면 **호스트 이름**과 **결과물 호스트**가 펼쳐집니다. 터널이나 프록시가 쓰는 이름은 **호스트 이름**에, 결과물을 원격에서 열 때 쓰는 터널 이름은 **결과물 호스트**에 입력하고 **추가**를 누릅니다. |

## 시스템 이벤트

정기 정리, 알아가기, 유지보수 작업이 언제 어떻게 끝났는지 확인합니다.

- 이벤트 종류는 **대화 기억 정리**, **알아가기**, **대화 기록 반영**, **컨텍스트 정리**, **정기 기억 정리**입니다.
- 상태는 **성공**, **완료**, **실패**, **실행 중**, **아직 실행 전**, **상태 확인 필요** 중 하나로 표시됩니다.
- **새로고침**으로 다시 불러오고, **더보기**로 20개씩 더 불러옵니다.

## 아카이브

보관한 프로젝트와 대화를 복원하거나 삭제합니다.

- **아카이브 취소** — 항목을 보관에서 꺼내 원래 목록으로 되돌립니다.
- **삭제** — 확인 창에서 **삭제**를 누르면 항목을 영구 삭제합니다.
- **더보기** — 20개씩 더 불러옵니다.

## 정보

버틀러 버전과 앱 정보를 확인합니다.

- **앱 정보** — **앱 이름**, **버전**, **GitHub 저장소**, **프로토콜**을 보여 줍니다.
- **진단** — **진단 내보내기**로 로그를 zip으로 저장합니다. 대화 내용은 빠집니다.
- **개발자**
  - **개발자 모드** — 이 앱 창의 Chrome DevTools와 [**로그**](#로그) 섹션을 켭니다.

## MCP

외부 MCP 서버와 연결 정보를 관리합니다. **MCP 서버 추가**로 서버를 등록하고, 서버마다 **연결 확인**, **활성화** / **비활성화**, **수정**, **삭제**를 씁니다. 항목별 설명은 [MCP 서버](/help/extensions/mcp-servers/)를 참고합니다.

## 훅

버틀러가 정해진 시점에 실행할 명령을 등록합니다. **내 훅**에서 **훅 추가**로 훅을 만들고, 훅마다 **편집**, **테스트**, **삭제**를 씁니다. 명령 훅만 지원합니다.

- **이벤트** — `SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `Stop`, `SubagentStop` 중에서 고릅니다. **도구**는 `PreToolUse`와 `PostToolUse`에서만 나타납니다.
- **명령**, **인수 (JSON)** — 실행할 명령입니다. 둘 중 하나를 입력합니다.
- **제한 시간 (ms)** — 기본값은 30000입니다.
- **오류 시 차단**, **백그라운드**, **사용** — 훅이 실패했을 때 작업을 막을지, 기다리지 않고 실행할지, 훅을 쓸지 정합니다.
- **최근 실행** — 훅이 실행된 기록입니다. **새로고침**으로 다시 불러옵니다.

## 스킬

**기본 스킬**, **내 스킬**, **프로젝트 스킬**을 관리합니다. **내 스킬**과 **프로젝트 스킬**에서 **가져오기**나 **대화해서 만들기**로 스킬을 추가합니다. 항목별 설명은 [스킬](/help/extensions/skills/)을 참고합니다.

## 서버

버틀러 서버 연결과 새 프로젝트 폴더를 설정합니다.

| 영역 | 항목 | 설명 |
| --- | --- | --- |
| **연결** | **서버 URL** | 버틀러 서버 주소입니다. 입력란에서 벗어나면 저장됩니다. |
| **프로젝트** | **기본 프로젝트 폴더** | [새 프로젝트](/help/projects/#프로젝트-만들기)에 쓸 기본 폴더입니다. 현재 폴더가 표시되고, **폴더 선택**으로 바꿉니다. |

## 주의 사항

<Notice tone="warning">
  - **아카이브**에서 삭제한 프로젝트와 대화는 되돌릴 수 없습니다.
  - **모든 데이터 지우기**는 되돌릴 수 없습니다.
  - **전체** 기록에는 대화 내용이 담기며, 60분 뒤 꺼집니다.
  - **로그**를 보는 중에 개발자 모드를 끄면 **정보**로 이동합니다.
  - **개인화**에서 바꾼 내용은 **적용**을 누르기 전까지 저장되지 않습니다.
  - **다른 컴퓨터에서 접속 허용**은 믿을 수 있는 네트워크에서만 켭니다.
</Notice>
