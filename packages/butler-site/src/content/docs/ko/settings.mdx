설정에서는 앱 동작, 모델, 확장 기능, 시스템 정보를 관리합니다. 섹션과 항목은 앱에 표시되는 순서를 따르며, 따로 설명한 문서가 있는 항목은 그 문서로 연결합니다.

## 설정 열기

<Steps>
  1. 사이드바에서 **설정**을 누릅니다. [명령 팔레트](/help/basics/command-palette/)(<span data-mod-key><Kbd keys={["⌘", "K"]} label="Command K" /></span>)에서 설정 항목을 찾아 열 수도 있습니다.
  2. 왼쪽 목록에서 섹션을 고릅니다.
  3. 항목을 바꿉니다.
</Steps>

- **설정 검색**에 입력하면 섹션 이름, 설명, 별칭으로 섹션을 거릅니다. 일치하는 섹션이 하나뿐이면 바로 열립니다.
- 대부분의 항목은 바꾸는 즉시 저장되고 **저장됨** 알림이 나타납니다. **개인화**는 **적용**을 눌러야 저장됩니다.
- **돌아가기**를 누르거나 <Kbd keys={["Esc"]} label="Escape" />를 누르면 설정을 닫습니다.

섹션은 세 그룹으로 나뉩니다.

| 그룹 | 섹션 |
| --- | --- |
| **환경 설정** | 일반, 모양, 개인화, 모델 |
| **앱 및 시스템** | 업데이트, 사용량, 로그, 개인정보, 보안, 시스템 이벤트, 아카이브, 정보 |
| **고급** | MCP, 스킬, 서버 |

## 일반

언어, 시간대, 대화 입력, 알림, 웹 검색의 기본값을 설정합니다.

| 영역 | 항목 | 설명 |
| --- | --- | --- |
| **언어 및 지역** | **언어** | 앱 인터페이스 언어입니다. **영어** 또는 **한국어**를 고릅니다. |
| | **시간대** | Butler가 현재 시간과 일정 맥락을 해석할 때 쓰는 시간대입니다. 목록에서 검색해 고릅니다. |
| **대화 입력** | **후속 요청 처리** | Butler가 작업 중일 때 보낸 메시지를 다루는 방식입니다. **작업 중이면 대기열에 추가** 또는 **현재 작업 방향 조정**을 고릅니다. |
| | **메시지 보내기** | **Command/Ctrl Enter 전송, Enter 줄바꿈** 또는 **Enter 전송, Shift Enter 줄바꿈**을 고릅니다. [보내기 키](/help/basics/conversation/#보내기-키)를 참고합니다. |
| **알림** | **데스크톱 알림** | 앱이 뒤에 있을 때 새 답변이나 작업 완료를 운영체제 알림으로 보냅니다. |
| | **AI 메시지 알림** | 새 답변이 도착하면 알립니다. 알림에는 안전한 미리보기만 표시합니다. |
| | **작업 완료 알림** | 작업이 완료, 실패, 취소되면 알립니다. |
| **알림 권한** | **OS 알림 상태** | 운영체제 알림 권한 상태입니다. **테스트**로 테스트 알림을 보냅니다. 운영체제 알림 설정을 열 수 있는 환경에서는 그 설정을 여는 버튼도 표시됩니다. |
| **메모리 모델** | 준비 상태 | 기억 기능에 쓰는 메모리 모델의 상태입니다. 준비가 끝나면 **준비되었습니다**가 표시됩니다. 받지 못했으면 **다시 시도**로 다시 받습니다. [첫 실행](/help/getting-started/first-run/#메모리-모델)을 참고합니다. |
| **앱 동작** | **트레이 및 메뉴바에 표시** | 켜면 창을 닫아도 앱이 트레이 또는 메뉴바에 남고, 메뉴에서 새 대화와 최근 대화를 열 수 있습니다. |
| | **로그인 시 시작** | 켜면 컴퓨터에 로그인할 때 Butler가 열립니다. 데스크톱 앱에서만 표시됩니다. |
| | **설정 다시 실행** | **다시 실행**을 누르면 환영 화면과 AI 연결을 다시 진행합니다. 등록한 모델과 대화는 그대로 남습니다. [첫 실행](/help/getting-started/first-run/#설정-다시-실행하기)을 참고합니다. |
| **검색 공급자** | **검색 제공자** | 웹 검색 결과를 가져올 곳입니다. **DuckDuckGo HTML**, **자동**, **Brave Search**, **Tavily**, **OpenAI Web Search**, **Codex 구독 검색**, **비활성화** 중에서 고릅니다. 키가 필요한 제공자에 키가 없으면 기본 검색으로 내려갑니다. |
| | **API 키** | 키가 필요한 제공자를 고르면 나타납니다. 키를 입력하고 **저장**을 누르면 비밀값으로 저장되며 화면에 다시 표시하지 않습니다. |
| **검색 동작** | **페이지 읽기** | 검색 결과 원문을 읽을 리더입니다. **경량 리더**, **자동**, **Lightpanda**, **Jina Hosted**, **비활성화** 중에서 고릅니다. |
| | **스마트 검색계획 사용** | 켜면 검색 전에 모델을 한 번 호출해 의도, 깊이, 검증 필요성, 쿼리 묶음을 계획합니다. |
| | **기본 검색 깊이** | **스마트 검색계획 사용**을 켰을 때만 보입니다. **빠르게**, **균형**, **깊게** 중에서 고릅니다. |

## 모양

앱의 테마와 화면 표시 방식을 설정합니다.

| 영역 | 항목 | 설명 |
| --- | --- | --- |
| **테마** | **테마** | **시스템**, **라이트**, **다크** 중에서 고릅니다. 실시간 월페이퍼가 밝기를 정하는 동안에는 바꿀 수 없습니다. |
| | **투명 사이드바** | 사이드바를 반투명하게 표시합니다. |
| **사이드바** | **스마트 그룹** | 새 대화를 같은 주제의 그룹으로 자동 정리합니다. 직접 옮긴 대화는 그대로 둡니다. |
| **홈 화면** | **월페이퍼** | 새 채팅 화면의 배경입니다. 목록에서 월페이퍼를 고르거나 **없음**을 고릅니다. **이미지 추가**로 JPEG, PNG, WebP 이미지를 25MB까지 올려 배경으로 쓸 수 있습니다. |
| | **움직임** | 월페이퍼를 골랐을 때 보입니다. 켜면 배경을 천천히 움직입니다. |
| | **배터리 사용 시 멈춤** | **움직임**을 켰을 때 보입니다. 켜면 전원이 연결되지 않았을 때 움직임을 멈춥니다. |

## 개인화

Butler가 쓸 이름, 말투, 사용자 정보를 관리합니다. 다른 섹션과 달리 바꾼 뒤 **적용**을 눌러야 저장됩니다. 항목별 설명은 [개인화](/help/personalization/)를 참고합니다.

| 영역 | 항목 |
| --- | --- |
| **프로필** | **버틀러 닉네임**, **내 이름**, **나를 부를 호칭** |
| **응답 스타일** | **답변 언어**, **페르소나 프리셋**, **페르소나**, **EOL** |
| **학습** | **사용자 정보 분석**, **사용자 정보 분석 모델**, **추론** |
| **가져오기** | **외부 AI 기억 가져오기** |
| 화면 아래 | **프로필 데이터 삭제** |

## 모델

Butler와 Worker가 쓸 모델, 예비 모델, 저장한 API 키, 권한을 관리합니다.

| 영역 | 항목 | 자세히 |
| --- | --- | --- |
| **버틀러 모델** | **모델**, **모델 관리**, **추론**, **컨텍스트 한도**, **로컬 추론 예산** | [클라우드 모델](/help/models/cloud/#기본-모델-고르기), [Custom 모델](/help/models/custom/#로컬-추론-예산) |
| **예비 모델** | 예비 모델 요약, **편집**, **예비 모델 사용**, **예비 모델 추가** | [예비 모델](/help/models/backup/) |
| **API 키** | 저장한 키 목록, **교체**, **삭제** | [클라우드 모델](/help/models/cloud/#api-키-관리) |
| **권한** | **접근 권한**, **기본으로 계획 모드 사용** | [대화와 컴포저](/help/basics/conversation/#권한) |
| **고급** | **기억 정리 모델과 Worker 프로필** | 아래 표 |

**예비 모델**에는 예비 모델이 이어받는 순서가 한 줄로 표시됩니다. **편집**을 누르면 예비 모델을 켜고 고르는 항목이 펼쳐집니다.

**고급**의 **기억 정리 모델과 Worker 프로필**은 처음에 접혀 있습니다. 누르면 다음 두 영역이 펼쳐집니다.

| 영역 | 항목 | 자세히 |
| --- | --- | --- |
| **기억 정리** | **대화 기억 정리 모델**, **추론** | [예비 모델](/help/models/backup/#대화-기억-정리-모델) |
| **Worker 프로필** | **최대 동시 Worker 수**, **Worker 프로필 추가**, 프로필별 항목 | 아래 표 |

새로 설치한 Butler에서 **접근 권한**의 기본값은 **먼저 확인**입니다. 이전 버전부터 쓰던 Butler는 **접근 권한**을 저장한 적이 없으면 **전체 권한**을 그대로 씁니다. 저장한 값은 업데이트해도 바뀌지 않습니다.

**Worker 프로필**에서는 Butler가 작업을 맡길 Worker를 정합니다.

| 항목 | 설명 |
| --- | --- |
| **최대 동시 Worker 수** | 동시에 실행할 Worker 수입니다. 1부터 10까지 입력합니다. |
| **Worker 프로필 추가** | 프로필을 추가합니다. 최대 12개까지 등록합니다. |
| **이름**, **사용** | 프로필 이름과 사용 여부입니다. 기본 프로필은 끄거나 삭제할 수 없습니다. |
| **작업**, **사용자 지정 작업** | **코딩**, **리서치**, **디버깅**, **리뷰**, **글쓰기**, **사용자 지정** 중에서 고릅니다. **사용자 지정**이면 작업을 직접 적습니다. |
| **도메인**, **Worker 프롬프트** | 프로필이 맡을 분야와 Worker에게 줄 지시입니다. 비워 둘 수 있습니다. |
| **모델**, **추론** | 이 프로필이 쓸 모델과 추론 강도입니다. |

## 업데이트

Butler의 새 버전을 확인하고 설치합니다.

| 항목 | 설명 |
| --- | --- |
| **미리보기 버전 받기** | 켜면 정식 출시 전 버전도 업데이트로 받습니다. 처음에는 꺼져 있습니다. |
| **확인** | 새 버전이 있는지 확인합니다. 확인하는 동안 **확인 중**으로 표시됩니다. |
| **버틀러** | 현재 버전과 앱에 포함된 Butler Agent 버전을 보여 줍니다. 새 버전이 있으면 `현재 버전 -> 새 버전`으로 표시합니다. |
| **업데이트** | 새 버전이 있을 때 누릅니다. 새 버전을 내려받아 체크섬을 확인하고, 앱과 앱에 포함된 Butler Agent를 새 버전으로 바꾼 뒤 Butler를 다시 엽니다. 진행하는 동안 **적용 중**, 새 버전이 없으면 **최신**으로 표시되고 누를 수 없습니다. |

<Notice tone="info" title="데이터는 그대로 남습니다">
  업데이트는 앱만 바꾸고 데이터 폴더는 건드리지 않습니다. Linux에서 DEB 패키지로 설치한 앱은 업데이트를 적용할 때 관리자 인증을 요청합니다.
</Notice>

## 사용량

모델 토큰, 프롬프트 캐시, 웹 검색, 도구 호출을 확인합니다. 컨텍스트 창 용량과는 별도로 기록됩니다.

| 항목 | 설명 |
| --- | --- |
| **개요** | 전체 사용량 요약입니다. **24시간**, **7일**, **전체** 중에서 기간을 고르고, **새로고침**으로 다시 불러옵니다. |
| **API 프로바이더 사용량** | 제공자별 사용량과 잔여량입니다. |
| **스코프별 토큰** | 스코프별 토큰 사용량입니다. |
| **모델별 토큰** | 모델별 토큰 사용량입니다. |
| **컨텍스트 섹션별 추정** | 프롬프트 섹션별 추정 토큰입니다. 많은 순으로 12개까지 표시합니다. |
| **도구별 호출** | 도구별 호출 수입니다. 많은 순으로 8개까지 표시합니다. |

## 로그

개발자 모드에서 모델 요청과 응답 로그를 확인합니다. **정보**의 **개발자 모드**와 **개인정보**의 **진단**이 모두 켜져 있을 때만 섹션 목록에 나타납니다.

- 위쪽 입력란으로 모델, 세션, 섹션, 응답을 검색하고, 세션 ID로 거릅니다.
- 종류 선택에서 **전체**, **모델 턴**, **실패한 모델 턴** 중 하나를 고릅니다. **새로고침**으로 다시 불러옵니다.
- 로그를 펼치면 **컨텍스트**, **요청**, **응답**, **메타데이터** 탭으로 내용을 봅니다.
- **더보기**로 로그를 30개씩 더 불러옵니다.

## 개인정보

진단 정보 수집을 설정합니다.

- **진단** — 켜면 모델 요청과 응답을 개발자 로그로 기록합니다. 로그는 `~/.butler/app/developer-logs/model-turns.jsonl`에 저장됩니다. 끄면 **로그** 섹션이 사라집니다. 로그를 읽는 방법은 [문제 해결](/help/troubleshooting/#로그-확인)을 참고합니다.

## 보안

다른 기기의 접속과 연결 코드를 관리합니다. 호스트 컴퓨터에서만 쓸 수 있으며, 다른 컴퓨터에서 열면 **호스트 컴퓨터에서만 사용할 수 있습니다.** 메시지가 표시됩니다. 연결 절차는 [원격 접근](/help/advanced/remote-access/#앱에서-기기-연결하기)을 참고합니다.

| 영역 | 항목 | 설명 |
| --- | --- | --- |
| **원격 접속** | **다른 컴퓨터에서 접속 허용** | 켜면 같은 네트워크의 기기에서 연결 코드를 입력해 접속합니다. 처음에는 꺼져 있습니다. |
| | **접속 주소** | 접속을 허용했을 때 나타납니다. 다른 컴퓨터에서 열 주소이며, **주소 복사**로 복사합니다. |
| **기기 연결** | **코드** | 접속을 허용했을 때 나타납니다. **기기 연결**을 누르면 8자리 코드와 남은 시간이 표시됩니다. 코드는 60초 동안 한 번만 쓸 수 있고, 만료되면 새 코드를 발급합니다. |
| **연결된 기기** | 기기 목록 | 접속을 허용했을 때 나타납니다. 연결된 기기의 이름, IP 주소, 마지막 접속 시각입니다. **연결 끊기**로 기기 하나의 연결을, **모두 끊기**로 모든 기기의 연결을 끊습니다. 연결된 기기가 없으면 **연결된 기기 없음**이 표시됩니다. |
| **고급** | **터널·프록시용 허용 호스트** | 누르면 **허용 호스트**가 펼쳐집니다. 터널이나 프록시가 쓰는 이름을 **호스트 이름**에 입력하고 **추가**를 누릅니다. |

## 시스템 이벤트

정기 정리, 사용자 정보 분석, 유지보수 작업이 언제 어떻게 끝났는지 확인합니다.

- 이벤트 종류는 **대화 기억 정리**, **사용자 정보 분석**, **대화 기록 반영**, **컨텍스트 정리**, **정기 기억 정리**입니다.
- 상태는 **성공**, **완료**, **실패**, **실행 중**, **아직 실행 전**, **상태 확인 필요** 중 하나로 표시됩니다.
- **새로고침**으로 다시 불러오고, **더보기**로 20개씩 더 불러옵니다.

## 아카이브

보관한 프로젝트와 대화를 복원하거나 삭제합니다.

- **아카이브 취소** — 항목을 보관에서 꺼내 원래 목록으로 되돌립니다.
- **삭제** — 확인 창에서 **삭제**를 누르면 항목을 영구 삭제합니다.
- **더보기** — 20개씩 더 불러옵니다.

## 정보

Butler 버전과 앱 정보를 확인합니다.

- **앱 정보** — **앱 이름**, **버전**, **GitHub 저장소**, **프로토콜**을 보여 줍니다.
- **개발자**
  - **개발자 모드** — 켜면 DevTools 창이 열리고, 이 앱 창에서 Chrome DevTools를 쓸 수 있습니다. 끄면 Electron 기본 메뉴와 DevTools 단축키가 차단됩니다. 켜고 끌 때 **개인정보**의 **진단**도 함께 바뀝니다. 개발자 모드와 **진단**이 모두 켜져 있으면 [오른쪽 패널](/help/basics/right-panel/)에 **맥락**과 **Worker** 탭이 나타납니다.

## MCP

외부 MCP 서버와 연결 정보를 관리합니다. **MCP 서버 추가**로 서버를 등록하고, 서버마다 **연결 확인**, **활성화** / **비활성화**, **수정**, **삭제**를 씁니다. 항목별 설명은 [MCP 서버](/help/extensions/mcp-servers/)를 참고합니다.

## 스킬

기본 스킬과 프로젝트 스킬을 관리합니다. **기본** 탭과 **프로젝트** 탭에서 스킬 목록을 보고, **가져오기**나 **대화해서 만들기**로 스킬을 추가합니다.

## 서버

Butler 서버 연결과 새 프로젝트 폴더를 설정합니다.

| 영역 | 항목 | 설명 |
| --- | --- | --- |
| **연결** | **서버 URL** | Butler 서버 주소입니다. 입력란에서 벗어나면 저장됩니다. |
| **프로젝트** | **기본 프로젝트 폴더** | [새 프로젝트](/help/projects/#프로젝트-만들기)에 쓸 기본 폴더입니다. 현재 폴더가 표시되고, **폴더 선택**으로 바꿉니다. |

## 주의 사항

<Notice tone="warning">
  - **아카이브**에서 삭제한 프로젝트와 대화는 되돌릴 수 없습니다.
  - **진단**을 켜 두면 모델 요청과 응답이 로컬 로그 파일에 계속 기록됩니다. 필요할 때만 켭니다.
  - **로그** 섹션을 보는 중에 개발자 모드나 진단을 끄면 **정보** 섹션으로 이동합니다.
  - **개인화**에서 바꾼 내용은 **적용**을 누르기 전까지 저장되지 않습니다.
  - **다른 컴퓨터에서 접속 허용**은 믿을 수 있는 네트워크에서만 켭니다.
</Notice>
