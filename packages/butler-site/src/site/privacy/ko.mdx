## 요약

- 버틀러는 내 컴퓨터에서 실행되는 앱입니다. 회사는 사용자 데이터를 받는 서버를 운영하지 않습니다.
- 사용 통계, 광고, 오류 보고 도구가 없습니다.
- 대화, 기억, 파일, API 키는 사용자의 컴퓨터에 저장됩니다.
- 답을 만들 때는 사용자가 연결한 AI 모델 서비스에만 필요한 내용을 보냅니다.

## 1. 적용 범위

헥스피게임즈(HexpyGames, 이하 "회사")가 만드는 버틀러 앱에 적용됩니다.

## 2. 컴퓨터에 저장되는 정보

대화와 첨부 파일, 기억, 설정, 예약 작업, 로그는 버틀러 데이터 폴더에 저장됩니다. API 키와 로그인 정보는 그 폴더에 사용자 계정만 읽을 수 있게 저장되며, 버틀러 금고를 쓰면 암호화됩니다. 웹사이트 비밀번호와 결제 카드는 운영체제의 암호 저장소에 보관합니다.

## 3. 컴퓨터 밖으로 나가는 정보

- **사용자가 연결한 AI 모델 서비스**: 대화와 답에 필요한 파일 내용·기억. 각 서비스의 방침을 따릅니다([OpenAI](https://openai.com/policies/privacy-policy/), [Anthropic](https://www.anthropic.com/legal/privacy), [Google](https://policies.google.com/privacy) 등).
- **웹 검색 서비스**: 검색어(기본 DuckDuckGo).
- **업데이트 확인**: Store 설치판은 Microsoft Store, 그 밖에는 GitHub에 새 버전을 묻습니다.
- **구성 요소 내려받기**: 배경 브라우저, 기억 모델(켠 경우).
- **사용자가 연결한 메일 서버, MCP 서버, 플러그인**: 그 기능에 필요한 내용.

인터넷 요청이므로 받는 쪽에는 IP 주소가 보입니다.

## 4. 버틀러가 사용자를 대신해 하는 일

버틀러는 사용자의 요청에 따라 사용자 계정의 권한으로 명령을 실행하고, 파일을 고치고, 웹 페이지를 엽니다. 기본 설정에서는 실행 전에 먼저 묻습니다. 버틀러가 연 웹사이트나 실행한 명령이 다른 서비스와 주고받는 정보는 그 서비스의 방침을 따릅니다.

## 5. 개인정보 보호법에 따른 고지

- **처리 목적과 항목**: 회사는 앱 사용자의 개인정보를 처리하지 않습니다. 문의나 신고 때 보내 주신 이메일 주소와 내용만 답변을 위해 처리합니다.
- **보유 기간과 파기**: 문의 처리가 끝나면 지체 없이 파기합니다. 법령에 보관 의무가 있으면 그 기간만 보관합니다.
- **제3자 제공과 처리 위탁**: 없습니다.
- **국외 이전**: 회사는 개인정보를 국외로 이전하지 않습니다. AI 모델 서비스로 가는 내용은 사용자가 고른 서비스로 사용자의 컴퓨터에서 직접 보내지며, 회사는 그 전송의 당사자가 아닙니다.
- **안전성 확보**: 회사 서버에 사용자 데이터를 두지 않으며, 키는 사용자의 컴퓨터에만 저장합니다.
- **정보주체의 권리**: 문의 정보의 열람, 정정, 삭제, 처리 정지는 아래 연락처로 요청할 수 있습니다. 앱 데이터는 앱에서 지우거나 데이터 폴더를 지우면 삭제됩니다.
